## What's new

### First release

Cairn is a local-first project management app with AI and MCP built in.

**Notes**
- Full markdown editor with live preview
- AI text actions on any selection — Rephrase, Summarize, Expand, Fix Grammar, Change Tone, Custom
- Notes stored as plain `.md` files with YAML frontmatter

**AI PRD Generator**
- Describe a feature in plain language → generates a full structured PRD as a note
- One-click Spawn Tasks — AI reads the PRD and creates task cards on the board
- Bidirectional note ↔ task linking

**Kanban board**
- Drag-and-drop cards across Backlog, Todo, In Progress, Review, Done
- Per-card priority, description, and due date

**AI Chat**
- Chat panel with full tool access — read notes, manage tasks, create PRDs
- Live tool call activity feed so you can see exactly what the AI is doing
- Works with OpenAI, Ollama, LM Studio, or any OpenAI-compatible endpoint

**MCP Server**
- Bundled stdio MCP server — connect Claude Desktop, OpenCode, Cursor, or any MCP client
- Changes appear in the UI instantly via file watcher and WAL polling

**Workspace**
- Local folder of your choice — `cairn.db` + one `.md` file per note
- External edits to `.md` files sync back automatically
