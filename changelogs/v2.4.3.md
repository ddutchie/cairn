## What's new

A small fix release for due-date display, plus a notes convenience.

### Fixes

- **Due dates render on the correct day**: A task's due date could display one day earlier than set — e.g. a date of **July 7** showed as **Overdue · July 6** on the card. Date-only due dates were being interpreted as UTC midnight and then shown in your local timezone, shifting them back a day in western timezones. Due dates are now parsed as local calendar days everywhere they're displayed, so the day shown matches the day you picked.

### Changes

- **Notes remember your last view mode**: The note editor now remembers whether you last used **Write** or **Read** mode and opens notes that way — so if you prefer reading, notes stay in Read mode without toggling each time. New users still start in Write mode.
