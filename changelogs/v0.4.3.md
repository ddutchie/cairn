# v0.4.3

## New MCP tools — agent ergonomics

Four new tools aimed at eliminating the most common friction points reported by AI agents (Cursor, Claude) working with Cairn projects.

### `resolve_project` (read)
Find a project by name — exact match, then starts-with, then contains — and return its `projectId` and all column IDs. Agents no longer need to call `get_cairn_context` or hardcode IDs just to look up a project by name.
```json
{ "name": "My Project" }
→ { "id": "...", "name": "My Project", "columns": [...] }
```

### `get_project_context_pack` (read)
Single-call bundle that replaces the common pattern of `get_project_summary` + `list_tasks` + `list_notes`. Returns:
- Project metadata + all column IDs
- Pinned notes with **full content** (useful context-setting docs)
- Open (non-done) tasks only — done tasks are omitted as noise
- Recent activity (last 10 notes + tasks by updatedAt)

Reduces a typical agent "orient on project" flow from 4–5 tool calls to 1.

### `ensure_note` (write)
Idempotent create-or-update: matches by `title` + `projectId`, updates content if found, creates if not. Returns `{ action: "created" | "updated" }`. Prevents duplicate notes when agents re-run (e.g. syncing a README or re-running a setup script).

### `append_to_note` (write)
Append content to an existing note without fetching and re-sending the full body. Accepts an optional `separator` (default: blank line). Useful for agents that build notes incrementally across multiple turns.
