## What's new in Cairn 3.0.13

### New

- **Neighbourhood mode in the Knowledge Graph.** Select any note, task, tag or project and choose **Show neighbourhood** in the side panel to see only what's within 1, 2 or 3 links of it. Pick the number of links from the chip in the toolbar, and press Esc or the chip's close button to go back to the whole graph. Projects and tags are shown when they connect to what you're looking at, but the view doesn't spread out through them, so it stays focused instead of pulling in an entire project.

### Improved

- **The Knowledge Graph lays itself out in the background.** Working out where each node goes used to run on the same thread as the rest of the app, so a large graph settling could make typing, scrolling and panels feel sluggish for a few seconds. It now runs separately, and the app stays responsive while it settles.
- **The Knowledge Graph remembers its layout.** Leaving the graph and coming back used to rebuild the layout from scratch. It now starts from where you left it (until you restart Cairn), so it settles almost at once.

- **Much lower memory use in large workspaces.** The app no longer keeps the full text of every note in memory. It keeps each note's title, preview and details, and loads a note's text when you open it or when something needs it, such as templates, AI context or backlinks. The most recently used notes stay cached, so switching between them is still instant. In our tests with 10,000 notes averaging 3–8 KB each, the memory the app holds for notes dropped from about 40–90 MB to about 7 MB. Most of what's left is titles and previews, so larger notes add little. Search, backlinks and Export data still cover the full text of every note.
- **"What's new" highlights survive restarts and catch changes made while Cairn was closed.** When an agent, the AI, Device Sync or an edited `.md` file changes a note, Cairn now remembers how the note looked before that change, even after a restart. The next time you open the note, the lines that changed are highlighted, however long ago the change happened. Before, highlights only appeared for changes that arrived while the app was open, and they were lost when you quit. Your own edits are never highlighted.

### Fixed

- **Saving a note no longer stalls the app in large workspaces.** Every save used to re-read and re-analyse every note in the workspace to update the Knowledge Graph's automatic links. In our tests with 5,000 notes, that took about 0.8 seconds per save and blocked the rest of the app while it ran. Now only the note you changed, and notes that mention it, are looked at again, which takes under 0.1 seconds. The first save after starting Cairn still takes about as long as before, because it has to read every note once.
- **Automatic links stay correct after edits.** Editing a note could drop a "mentions" link from another note that referred to it, and could miss a keyword link to some related notes until the next full recompute. Both are fixed.
- **The Knowledge Graph and Insights load quickly again in large workspaces.** A change in 3.0.12 made loading the graph slow down sharply as a workspace grew. In our tests with 5,000 notes, a load took about 13 seconds, and every background refresh after an edit took the same time again. It now takes about 0.2 seconds (1,000 notes: 0.5 to 0.04 seconds).
