## What's new in Cairn 3.1.5

### Added

- **Board cards now render `[[wikilinks]]` as clickable links.** Collapsed card descriptions use a lightweight wikilink-only scan instead of the full markdown pipeline, so linked notes and tasks show as accent pills without the previous Board mount cost. Full markdown still renders when a card is expanded.
- **Card detail surfaces notes mentioned in the description.** `[[Wikilinks]]` that resolve to a note but aren't explicitly linked yet appear under Linked Notes as "Mentioned in description", with one-click link and open actions. Mentions stay derived — nothing is auto-written to the card.
- **Live chats pin in the sidebar.** Threads with a running turn or unseen replies appear under Workspace as "Live chats" (spinner = running, dot = unread), from any workspace — one click jumps to the right workspace, project, and thread.

### Fixed

- **Switching threads mid-turn no longer loses the turn.** Live conversation state is now tracked per session: the orphaned turn completes in the background into its own thread, the loading flag follows the visible thread, and staged suggestion cards can't leak across threads. Thread selection also no longer snaps back after a project switch, and a foreign-workspace thread is never left mounted.
- **Suggested connections no longer render as blank cards.** The model sometimes omits the `type` discriminator (IDs/titles/reason only), and the card renderer had no fallback — blank label, no icon, just Apply. Cards now infer the action type from the fields present (e.g. `cardId` + `targetNoteId` → note-to-card link, with alias IDs canonicalized so Apply performs the link), resolve missing titles from the workspace by ID, and show a generic label for truly unknown types instead of nothing. The executor also validates `suggest_connections` args now and tells the model to retry with `type` set, so future calls arrive well-formed.
