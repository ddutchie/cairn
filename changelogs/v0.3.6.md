# v0.3.6

## What's new

### MCP — real-time notifications
Cairn now surfaces every change made by an AI agent through the MCP server, so you always know what happened without having to switch back to the app.

**OS toast notifications** — a native system notification fires within one second of any MCP write tool completing, showing exactly what changed (e.g. "Task created — 'Fix login bug' added to Cairn Project Management"). Works on macOS, Windows, and Linux, and appears even when the Cairn window is minimised or hidden.

**Menu bar tray icon** — Cairn now lives in the macOS menu bar. A badge count on the tray icon tracks unread MCP updates when the window is in the background. Clicking the tray icon brings Cairn to front and clears the badge. Right-clicking shows the unread count, an Open Cairn option, and Quit.

The following MCP tools trigger notifications: `create_task`, `update_task`, `update_task_status`, `create_note`, `update_note`, `link_note_to_task`, `create_project`, `update_project`, `delete_task`, `delete_note`, `delete_project`.

## Fixes

- **GitHub Actions release workflow** — `scripts/generate-licenses.js` was not running before `next build` in CI, causing the build to fail with a missing `@/generated/licenses.json` module. All three platform jobs (macOS, Windows, Linux) now run the license generation step first.

## Internals

- `mcp_notifications` table added to SQLite schema — lightweight side-channel written by the MCP server after each successful mutation and polled by the Electron main process. Rows are marked `read` after the toast fires; the badge clears on window focus.
- `electron/db/queries.ts` — `insertMcpNotification`, `getUnreadMcpNotifications`, `markMcpNotificationsRead` helpers added.
- `scripts/generate-tray-icon.js` added — converts `public/icon_tray.png` to properly formatted macOS template images (`trayTemplate.png` + `trayTemplate@2x.png`, black + transparent, 22 and 44px). Run via `npm run generate-tray-icon` whenever the source icon changes.
