## What's new in Cairn 3.0.19

### Fixed

- **Context Ring shows real conversation and tool-output usage again.** The harness now reports cached prompt tokens separately from new ones, and the ring was only counting the new ones — so with prompt caching on, a long session looked almost empty and Conversation / Tool outputs read 0. The ring now measures the full prompt (new + cached), reads the system prompt and skill catalogs from where the harness now records them, and updates live after every step and tool result in coding sessions instead of only after a reload.
- **The permission picker (workspace-write / danger-full-access) shows up on new agent sessions right away.** It used to stay hidden until you sent the first message. You can now pick a preset before the first message or between turns; the choice is applied when the next turn starts.

### Changed

- **Agent approvals now work like the DeepSeek harness: the permission picker is the only control.** Coding sessions no longer stop to ask before every note, task, file edit or command. Under **workspace-write**, the agent works freely inside the project, and you're only asked when it needs to go beyond that (e.g. a command that needs wider file or network access). Under **danger-full-access** nothing asks. Cairn tools (notes, tasks, boards, idea flow) always run without a prompt. Reading protected secret files (like `.env`) still asks. The old "Auto-approve tool execution" setting has been removed; automations keep their own approval setting.
