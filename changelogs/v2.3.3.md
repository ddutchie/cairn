## What's new

A quality release that hardens the test suite around the v2.3.2 features and adds a React component-testing harness, plus two Markdown bug fixes.

### Bug fixes

- **Clickable checkboxes inside tables**: Task-list checkboxes (`[ ]` / `[x]`) placed inside a Markdown table cell now render as real, clickable checkboxes and toggle the underlying source — previously they stayed as plain text. (GFM doesn't emit checkboxes inside table cells, so the preview now recovers them via custom `td`/`th` rendering, with toggling mapped back to source in document order across both list-item and table-cell checkboxes.)
- **Ordered-list numbering in the editor**: The note editor now auto-continues and renumbers ordered/bulleted lists on Enter, exits the list cleanly from an empty item, and renumbers correctly on Backspace. Previously breaking the numbering left the list out of order.

### Changes

- **Shared "What's New" gate**: Extracted the duplicated "unseen latest features" logic (previously copy-pasted in `NewFeatureModal` and the boot path in `page.tsx`) into a single pure `getUnseenLatestFeatures(registry, seenFeatures, forceOpen?)`. Both call sites now share one implementation, eliminating drift between the modal and the tour-deferral gate. No behavior change.

### Tests

- **Component test harness**: Added a second vitest project (`component`) running **jsdom + Testing Library** alongside the existing `node` project, plus `npm run test:unit` / `npm run test:component` scripts and a jest-dom setup file. Component tests live in `*.component.test.tsx`.
- **Onboarding component tests**: `StepCreateProject` — submit gating on empty/whitespace names, icon picker selection and `aria-pressed` state, accessible labels on icon-only buttons, and all controls (back, skip, icon picker) disabled while a create is in flight.
- **What's New modal component tests**: boot gating (unseen shows, seen hidden), "Done" marks the feature seen and closes, and — via the `forceOpen` (Settings) path — pagination dots, Next navigation, and "Skip All" marking every displayed feature seen.
- **Feature-gate unit tests**: full coverage of `getUnseenLatestFeatures` (forceOpen, empty registry, latest-version-only filtering, seen filtering, order-derived latest version).
- **Store & pure-logic unit tests**:
  - `createProject` — icon persistence (the v2.3.2 onboarding fix), icon omitted when absent, the 5 optimistic columns with correct types/orders, and append-not-replace semantics.
  - UI slice tour/seen-feature actions — `markFeatureAsSeen` (append/idempotent), `setTutorialActive` (with its step-index reset), `setTutorialStepIndex`.
  - Board slice — `moveCard` (same/cross-column reindex, index clamping, untouched columns) and `getReadyCards` (blocker resolution, done/archived handling, orphan blockers, project scoping).
  - `buildFolderTree` — folder-path normalization edge cases (undefined vs empty, leading/trailing/double slashes, deep nesting, alphabetical sort).
  - `searchAll` — empty-query, title/content/description matching, snippet length, archived skipping, 50-result cap.
  - Date helpers — `formatRelative` thresholds and `getDueDateStatus` (timezone-robust day comparison).
