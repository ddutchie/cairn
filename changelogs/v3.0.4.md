## What's new in Cairn 3.0.4

### Fixed

- **Chat expand/collapse is one motion now.** "Expand to central view" snapped the same panel between two incompatible geometries with a `transition-all` that smeared borders, shadows, and widths, while the page margin animated on its own clock — background stretched, chat blinked in on top. Both modes now pin explicit `left`+`width`, so the switch interpolates a single 300ms slide on the same timing as the content margin: panel and background travel together, and the fluid centered transcript reflows into place mid-slide. The slide-arming flag lives in the store and commits atomically with the geometry change — a component-state flag landed a frame late via effects, after the snap had already happened (`src/components/chat/UnifiedChatPanel.tsx:46`, `src/store/slices/ui.ts:764`).
- **Exiting the central chat view can't strand the overlay anymore.** The topbar Chat button, `⌘/`, and sidebar navigation called `setView(lastContentView)` without resetting the presentation, leaving the fullscreen chat panel covering the content it just navigated to. Any navigation to a content view now restores the drawer presentation in the same store update, and expand/collapse are single `setView` calls instead of paired presentation+view updates (`src/store/slices/ui.ts:1259`, `src/components/agent/SessionPane.tsx:377`).
- **Fullscreen chat aligns to the real sidebar edge.** The center panel guessed the sidebar width per shell and had the collapsed dock wrong (4rem vs the actual `w-12`/3rem — a 16px phantom gap on the left whenever the sidebar was closed, while open happened to match). It now measures the sidebar live via `ResizeObserver`, so the edge stays glued through collapse/expand animations and any future width changes (`src/components/chat/UnifiedChatPanel.tsx:73`).
- **Fullscreen offset survives drawer visits and font scaling.** Two follow-ups to the measurement above: React dropped the measured CSS variable every time the panel returned to drawer mode (and `ResizeObserver` won't refire without a size change, so re-entering center fell back to the guess), and the `rem` guesses for px-based sidebars only hold at a 16px root while the app runs `14px × font-scale` — so expanded was still off after collapsed was fixed. The fallback is now set in both modes (never dropped) and the measurement re-syncs on every mode switch.
