## What's new

### Fixes

- **Windows arm64 build failure**: `@xenova/transformers` depends on `sharp` (native image processing library) which has no prebuilt binary for Windows arm64. The build attempted to compile `libvips-cpp` from source and failed with 108 unresolved linker symbols. Replaced `sharp` with a minimal stub (`electron/sharp-stub/`) that exports `null` — Cairn only uses text tokenization from transformers.js, never image processing, so the stub is a no-op. Transformers.js gracefully skips the image-loading path when `sharp` is falsy. Applied via npm `overrides` in `package.json` + `package-lock.json` so `npm ci` resolves correctly on CI.

- **Embeddings support on Intel macOS**: `onnxruntime-node` dropped the `darwin-x64` prebuilt binary starting in v1.24.0. Pinned to `1.23.2` (the last version shipping prebuilts for all six platform/arch combinations: darwin-arm64/x64, linux-arm64/x64, win32-arm64/x64). None of the changes in 1.24–1.27 affect Cairn's use case (running Nomic-Embed-Text-v1.5 quantized on CPU) — they're primarily CUDA/WebGPU EP work, new ops for newer LLM models, and security hardening on operators not exercised by the embedding pipeline. **This is the final release with Intel macOS support**; a future version will bump onnxruntime-node and drop the `darwin-x64` electron-builder target.

- **Benchmark ceilings bumped for CI**: CPU-bound embeddings benchmarks (`topK`, `cosine`, `chunkLongText`, `averageVectors`) had p95 ceilings of 1ms that flaked on GitHub Actions runners (measured ~1.57ms). Raised ceilings to 2-10ms depending on operation — still catches catastrophic regressions while accommodating slower CI hardware.

### Tests

- **Native-deps guard** (`electron/native-deps-guard.test.ts`): A new test that prevents the Windows arm64 build failure from recurring. Scans `package-lock.json` for any package with `hasInstallScript: true` or a `binding.gyp` — every such package must appear on an explicit `ALLOWED_NATIVE_DEPS` allowlist with a justification comment, OR be stubbed via npm `overrides` (like sharp). Catches new transitive native deps at PR time before they reach CI. Also enforces that macOS-only deps (`fsevents`, `iconv-corefoundation`) keep their `"os": ["darwin"]` filter — if an upgrade drops it they'd silently start running on Windows.

### Build

- **`.npmrc` with `install-links=true`**: Ensures `npm ci` resolves the `sharp` stub consistently across all environments (macOS/Linux/Windows CI runners). Without this flag, `file:` deps create symlinks which fail on Windows CI runners that lack symlink permissions, causing `ENOENT: no such file or directory, stat 'node_modules\sharp'` in electron-builder.
