## What's new in Cairn 3.0.17

### Added

- **Watch the coding agent's terminals.** Shells the agent opens with its terminal tools now appear as read-only "Agent" tabs in the bottom terminal, with everything they printed before you opened the tab. Closing an Agent tab only hides it; the agent keeps its shell.

### Fixed

- **A second approval for the same tool call no longer gets stuck.** When the coding agent asked to run a shell command outside the sandbox after you had already allowed the command, the approval card kept showing "Allowed — running…" with no buttons, so it looked like the command was running when it was actually still waiting for your answer. Each new ask now shows a fresh card you can answer.
- **Sandbox escalations always ask, and say why.** A request to run one command outside the sandbox now always shows its own card, with the agent's reason and only Allow once / Deny. "Allow for session" or "Always allow" on the shell no longer approves these silently, and answering one never saves a standing grant.
- **The coding agent's permission dropdown is back.** The workspace-write / danger-full-access switcher in the coding header had disappeared. The latest agent runtime stopped sending the list of choices along with the current setting, and Cairn hid the dropdown when the list was missing. It now builds the list itself and shows the switcher as soon as a coding turn starts, including in resumed sessions.
