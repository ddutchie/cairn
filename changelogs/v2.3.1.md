## What's new

### Features

- **Node.js & Electron Engine Upgrades**: Fully upgraded the desktop wrapper to **Electron v42.5.0** (running Node v24.15.0 internally) and updated the development Node types to **v22.20.0** to match compilation environments.
- **MCP Server Node 24 Sync**: Upgraded the standalone packaged MCP server compiler target to **Node 24** (via `@yao-pkg/pkg`), aligning execution engines and eliminating duplicate/nested native dependencies in the lockfile.
- **ESLint & TypeScript Major Upgrades**: Upgraded TypeScript to **v6.0.3** and ESLint to **v10.6.0**. Configured ESLint with explicit React version mappings to bypass the removal of deprecated `context.getFilename()` APIs in ESLint 10.
- **Dependency Version Upgrades**: Bumped several core packages to their latest major releases, including the Vercel AI SDK to **v7.0.4**, `react-day-picker` to **v10.0.1**, `concurrently` to **v10.0.3**, and `katex` to **v0.17.0**.

### Fixes

- **Windows CI/CD Build Stalls**: Resolved the sporadic GHA build hangs on Windows runners by skipping the redundant `postinstall` rebuild during `npm ci` (now handled once by `npm run rebuild`). Added a 5-minute timeout with automatic cleanup retry logic for `node-pty` compilation to fail fast on MSVC stalls.
- **Redundant packaging rebuilds**: Set `npmRebuild: false` in `electron-builder.yml` to prevent duplicate native rebuild tasks during application packaging, speeding up the build cycle.
- **TypeScript 6 module deprecations**: Added `ignoreDeprecations: "6.0"` to the Electron compiler configuration, allowing esbuild-bundled CommonJS processes to compile without type-checking errors.
