## What's new in Cairn 3.0.5

### Fixed

- **Deleted notes no longer linger in the Knowledge Graph.** Notes are soft-deleted (the row is kept as a sync tombstone), but the graph loader only filtered `archived_at` — so a deleted note stayed visible until a full recompute. The loader, neighbour traversal, auto-relationship computation, and semantic-neighbour lookup now all exclude `deleted_at` tombstones, and deleting a note also purges its relationship-cache rows + embeddings (`electron/db/graph-queries.ts`, `electron/ipc/db-handlers.ts`, `electron/mcp/tools/notes.ts`, `electron/file-watcher.ts`). Fixes #141.
- **Automation deletes are retry-safe now.** The row was removed first and the on-disk folder + keychain secrets cleaned up best-effort afterwards — a failed cleanup left orphans with no way to retry. Cleanup now runs first via `deleteAutomationWithCleanup` (`electron/lib/automation-delete.ts`): secrets are purged, then the folder is removed, and only then is the row deleted. A cleanup failure throws, the row is kept, and a later delete retries from scratch. Fixes #133.
