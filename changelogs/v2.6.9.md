## What's new

### Fixed

- **Subagent tool chips no longer leave stuck "running" duplicates.** A tool call inside a coding-agent subagent emits multiple `pi-agent:tool` events with the same call id (streaming "pending", then "start" at execution, then a label update per `bash` output chunk), and the renderer appended a new chip each time instead of updating the existing one — the parent agent de-duplicated, subagents didn't. The result was one resolved chip plus one or more permanently spinning duplicates after the subagent finished (worst for bash-heavy subagents). Subagent chips now update in place, exactly like the parent's.
- **Subagent context rings now show the coding agent's context limit, not the chat model's.** The agent's subagents run on the agent's model, but their context ring read the *chat* AI config's context limit — so a 200K-context chat model capped every agent-subagent ring at 200K even when the agent model had a much larger window. The ring now uses the agent's own context limit (same value as the parent agent's ring).
- **The agent's context pruner now trims at the model's real context window.** The sliding-window pruner (and manual `/compact`) previously always used a hardcoded 128K threshold — a model with a larger window would start trimming long histories far earlier than it needed to, and the ring and the actual behaviour disagreed. The agent's context limit (auto-detected from models.dev, or your manual value) is now sent to the main process, so the pruner, compaction, and the context ring all agree on the same limit.
- **Navigating away from the Agent view no longer yanks you off a live agent conversation.** Leaving the Agent tab (e.g. popping into Settings or switching views) used to force the session panel back onto AI Chat; the agent session is now left where you had it and restored automatically when you return to the Agent view. Opening the chat panel from a non-agent view still shows AI Chat.
- **The app stays responsive while the agent works.** The agent's file tools (`grep`, `find`, `ls`, `read`) ran fully synchronously on the main process thread — a `grep` across a large repository blocked IPC to the UI, freezing it until the search finished. They now use async I/O, so the main thread yields between files and the UI stays live during big searches. Verbose `bash` commands also no longer spam the UI: live tool-chip output updates are throttled instead of firing a full IPC event per output chunk.
- **Streaming is now batched — a smoother UI while the agent or chat replies.** Token and reasoning deltas were shipped to the renderer as one IPC event per streamed chunk (hundreds per second for reasoning models, doubled by subagents), each triggering a UI re-render. Deltas are now coalesced to ~20 flushes per second, cutting IPC + render churn by an order of magnitude with no perceptible streaming latency.
- **Agent session-history saves no longer stall the turn-complete event.** Persisting the full LLM history after each agent turn was a synchronous write of every message; it now happens off the done/error delivery path (with rapid back-to-back saves coalesced), so the UI resolves the turn immediately.
- **A crashed agent/chat/subagent loop can no longer leave the UI stuck loading.** If the tool loop throws (rather than reporting via its done/error callbacks), the agent, chat, and subagent paths now flush buffered tokens, persist/release state, and send a terminal error event so the input resolves and the subagent block doesn't hang "running".
- **The agent's file tools stay inside the workspace.** `read`/`grep`/`find`/`ls` now reject paths that escape the working directory — absolute paths outside it, `..` parent traversal, and symlinks pointing out — so a prompt can't read arbitrary system files (or hang on special files like `/dev/random`). Valid in-workspace paths, including symlinks that resolve inside, keep working.
- **Context rings and the pruner now agree on one context limit.** A shared normalizer (finite, floored, ≥1, else 128K) is used by the agent's sliding-window pruner and the parent/subagent context rings, so a bad value can't zero a ring or disable pruning.
- **The Usage "Estimates" toggle no longer hides calls.** Toggling estimates off previously dropped every estimated-cost call from the history and shrank the token/request stats. It now keeps **all** line items and usage stats visible — it only hides the estimated dollar figures (shown as —) and counts only provider-reported costs in the cost totals, so the view stays complete without the models.dev guesses.
- **The chat panel can be made much wider.** The chat sidebar's maximum width is increased from 600px to 1000px, so the transcript can use more of the screen on large displays.
