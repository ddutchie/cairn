## What's new in Cairn 3.1.3

### Removed

- **Dashboards have been removed.** The live HTML dashboards in Notes were rarely used, so the New Dashboard button, the template picker, the in-app HTML editor and the `window.cairn` live-data bridge are gone. The AI (chat, the coding agent and the MCP server) also no longer offers `create_dashboard`, `update_dashboard` or `get_dashboard_constants`. That's three fewer tools, about 230 fewer tokens, sent with every request.
- **Your existing dashboards are kept as notes.** On first launch, each dashboard is turned into a regular note with the same title, project and folder. Its HTML is kept in a code block, with a short line explaining what happened, and the note gets its `.md` file like any other note. To see the page again, save the code block as an `.html` file and open it in a browser; it can no longer pull live Cairn data. Dashboards synced from another device still on an older Cairn are converted the next time this one starts.

### Changed

- **The AI's Cairn tools are consolidated: 54 → 19 for external agents (MCP), 56 → 20 in chat.** Each tool now covers one job, with options in place of near-duplicate tools. `search_tasks` takes a `filter` (ready / overdue / due) instead of three list tools. `update_tasks` moves, edits, tags, links and blocks one or many cards. `update_notes` renames, moves, tags, pins and links notes. `task_progress` claims a card or logs progress, `edit_idea_flow` applies a batch of canvas changes in one call, and one `delete` tool replaces five. Tool descriptions sent with every request shrink from about 6.6k tokens to about 3k. In side-by-side tests on three models, the new set picked the right tool with the right arguments at least as often as the old one.
- **External agents need the new names.** MCP clients with saved prompts or skills that mention old tools (`get_cairn_context`, `claim_task`, `add_task_progress`, `list_ready_tasks`, …) should switch to `get_context`, `task_progress`, `search_tasks filter:"ready"` and so on. The tool list the server sends always has the current names. Automation "always allow" rules saved for old tools keep working.
- **In chat, Safe mode now also asks before deleting Idea Flow nodes and connections**, because all deletes go through the one `delete` tool.
- **Leaner AI tool definitions.** The MCP server now sends the same trimmed tool schemas the in-app chat uses. That drops a per-tool header, a long date-format pattern, number limits and defaults, which only cost tokens. The writing-style tool's description is also much shorter.
- **The codebase index tools are no longer offered in chat.** Chat can't read files, so `codebase_reindex` and `codebase_query` stay with the coding agent and the MCP server.

### Fixed

- **Search tools no longer make the AI fill in optional fields.** `search_notes` and `search_tasks` marked `limit` and `offset` as required, so the model had to invent values on every search. They're optional again, with the usual defaults.
