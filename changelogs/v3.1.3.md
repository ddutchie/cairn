## What's new in Cairn 3.1.3

### Removed

- **Dashboards have been removed.** The live HTML dashboards in Notes were rarely used, so the New Dashboard button, the template picker, the in-app HTML editor and the `window.cairn` live-data bridge are gone. The AI (chat, the coding agent and the MCP server) also no longer offers `create_dashboard`, `update_dashboard` or `get_dashboard_constants`. That's three fewer tools, about 230 fewer tokens, sent with every request.
- **Your existing dashboards are kept as notes.** On first launch, each dashboard is turned into a regular note with the same title, project and folder. Its HTML is kept in a code block, with a short line explaining what happened, and the note gets its `.md` file like any other note. To see the page again, save the code block as an `.html` file and open it in a browser; it can no longer pull live Cairn data. Dashboards synced from another device still on an older Cairn are converted the next time this one starts.
