## What's new

Intel Mac support is back, plus platform-aware keyboard shortcut hints.

### Intel Mac support restored

- **Cairn runs on Intel Macs again**: Support for Intel (x64) Macs was dropped when a dependency stopped shipping an Intel build of its inference engine. The embeddings stack is now pinned to a version that ships prebuilt binaries for every platform and architecture, so the macOS release is once again universal — covering both Apple Silicon and Intel, with full LLM chat *and* semantic search on both.
- **Faster, leaner builds**: Native SQLite binaries are now downloaded as prebuilts per architecture instead of being compiled from source during release, and node-pty reuses its shipped prebuilt binaries — so release builds are quicker. Cross-platform binaries that don't belong in a given build (e.g. Windows PTY binaries in the macOS app) are pruned, trimming download size.

### Fixes

- **Keyboard shortcut hints match your platform**: On Windows and Linux, tooltips and hints still showed the macOS **⌘** symbol in several places — Overview, Notes, Search, AI Chat, the sidebar chips, the agent panel, Save, Bold/Italic, file search, and the onboarding cards — even though the actual key is **Ctrl**. Every shortcut hint now shows the correct modifier for your platform, resolved from a single shared source so the labels can't drift apart again. (The shortcuts themselves already worked on all platforms; only the displayed hints were wrong.)
