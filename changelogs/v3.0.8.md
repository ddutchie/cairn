## What's new in Cairn 3.0.8

### Fixed

- **Coding-agent shell tools work on Windows again.** Every sandboxed command (`ls`, `echo`, `grep`, …) failed with `import_meta2.resolve is not a function`: `dsh-sandbox-local` locates its Windows ACL runner via `import.meta.resolve()`, which esbuild stubs out in the CJS bundle (same family as the `koffi` `import.meta.dirname` breakage in 3.0.7). The runner now ships as a standalone `dist-electron/windows-acl-runner.cjs` beside the bundle and is pinned via `internals.windowsAclRunnerEntry`, plus an `import.meta.resolve` banner/define shim and a bundle-guard test so it can't regress. `scripts/build.js` also gains the missing `--external:koffi` flag to match `scripts/compile-electron.js`.
- **Answers to `ask_questions` reach the model again (coding agent).** The agent's question form rendered, but submitting silently dropped the answer: the coding path broadcast the raw `session:ask-questions` push that no renderer listens to, so the nonce never arrived and the answer was rejected. The coding path now emits the same `question` projection (with nonce) the chat path already sent, and a dropped answer logs a warning instead of vanishing.
- **The session todo dock populates again.** The bridge parsed the `todo_write` tool's *rendered text* ("Updated todo list: …") as JSON, which always threw, so todos were never saved or emitted. It now reads the `todo/write` snapshot event directly.

### Changed

- **dsh packages updated to 0.1.5-rc.3** (cordis pinned at 4.0.2 per the dsh peer requirements). This line removes the `assistant/chunk` session event — live token streaming now arrives as `agent/assistant-stream` dispatch frames, which Cairn bridges in chat, coding, and subagent traces. Folds keep honoring chunks so pre-0.1.5 logs replay exactly.
