## What's new in Cairn 3.1.7

### Changed

- **Changed notes are marked in the sidebar.** Notes with unseen external edits (the ones that show the "lines changed" banner when opened) now carry an accent dot in the notes hierarchy, and folders with changed notes inside show a dot too — so the change stays visible even when the folder is collapsed.
- **Force-directed graph settles faster and stays smooth on large workspaces.** Hull outlines recompute at most ~5x/s while settling instead of every tick, auto-fit is throttled, large graphs (>400 nodes) render at reduced DPR and settle at 30fps, label halos are skipped past 80 visible labels, and edge hover no longer scans all edges per mousemove.

### Fixed

- **Local MCP server test shows why it failed.** When a stdio MCP server exits before connecting, "Test connection" used to report only "Connection closed". It now appends the tail of the server's own error output (for example a sign-in or missing-runtime message), shown wrapped in Settings → Tools.
- **Local MCP servers find Node when Cairn is launched from the Start menu or Dock.** Servers installed through npm shims (for example `workiq`) failed with "Connection closed" in the installed app because it didn't inherit the `node` that fnm, Volta or nvm add to your terminal's PATH. Cairn now also searches the registry PATH on Windows and the default fnm, Volta, nvm, asdf and Homebrew locations.
- **Smoother pan, zoom and hover on large 2D graphs.** The force graph now keeps its edge and node geometry between frames and only rebuilds it when nodes move, the selection changes or the theme changes, so navigating a settled graph no longer redoes that work every frame.
- **Cluster hulls in the 3D graph.** The Hulls toggle now works in the 3D layout too, wrapping each project cluster in a translucent hull that follows the nodes as they move.
- **No more blank projects in the project filter.** Projects deleted on another device (sync keeps a blank placeholder row) no longer show up as nameless entries in project pickers.
- **3D graph no longer throws after a node drag is cancelled.** Fixes a "Cannot read properties of undefined (reading x)" error when a drag ended through a cancelled pointer.
