## What's new in Cairn 3.1.7

### Changed

- **Changed notes are marked in the sidebar.** Notes with unseen external edits (the ones that show the "lines changed" banner when opened) now carry an accent dot in the notes hierarchy, and folders with changed notes inside show a dot too — so the change stays visible even when the folder is collapsed.

### Fixed

- **Local MCP server test shows why it failed.** When a stdio MCP server exits before connecting, "Test connection" used to report only "Connection closed". It now appends the tail of the server's own error output (for example a sign-in or missing-runtime message), shown wrapped in Settings → Tools.
- **Local MCP servers find Node when Cairn is launched from the Start menu or Dock.** Servers installed through npm shims (for example `workiq`) failed with "Connection closed" in the installed app because it didn't inherit the `node` that fnm, Volta or nvm add to your terminal's PATH. Cairn now also searches the registry PATH on Windows and the default fnm, Volta, nvm, asdf and Homebrew locations.
