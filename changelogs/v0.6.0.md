# v0.6.0 — Idea Flow

Each project now has a **Flow** view — a freeform node canvas for visually structuring ideas, connecting them, and attaching existing notes and tasks. The AI assistant and MCP agents can read and write the canvas as first-class authors.

## Idea Flow canvas

A new fifth tab in every project (`⌘4`), built with `@xyflow/react` v12.

**Interactions**
- Double-click the canvas background to add an idea node at that position
- Drag handles between nodes to create connections (bezier curves with a hover-delete button)
- Double-click a node to open the edit modal
- Delete / Backspace removes selected nodes or edges
- Pan and zoom with standard React Flow gestures

**Node types**

| Type | Content |
|------|---------|
| `idea` | Title + optional body |
| `note_ref` | Links to an existing note — live title shown, click to open |
| `task_ref` | Links to an existing task — priority + column shown, click to navigate to Board |
| `group` | Resizable colour-coded container |
| `url` | URL with optional title and description |
| `ai_summary` | AI-authored read-only text block |

**Note / Task integration**
- Edit modal has live search pickers for note and task refs — no ID copy-pasting
- `note_ref` and `task_ref` nodes are deep-linked: clicking them opens the target note or navigates to the Board view
- Drag an existing note or task from the sidebar onto the canvas to create a reference node

**Persistence**
- Node positions are saved on drag-stop
- Edges are deduplicated at the database level (`UNIQUE INDEX` on `flow_id, source_node_id, target_node_id`)
- Reloads triggered by `onDbChanged` merge positions rather than replacing them — the viewport is never reset mid-interaction
- Own writes suppress the reload listener for 1.5 s to prevent feedback loops during drag and connect

## MCP + AI chat tools

Six new tools available to both the in-app AI assistant and external MCP agents:

| Tool | Category | Description |
|------|----------|-------------|
| `get_idea_flow` | read | Full graph: nodes (with resolved note/task content) + edges |
| `create_idea_flow_node` | write | Add any node type to the canvas |
| `update_idea_flow_node` | write | Update node data and/or position (data fields are merged, not replaced) |
| `create_idea_flow_edge` | write | Connect two nodes with an optional label |
| `delete_idea_flow_node` | delete | Remove a node and its connected edges |
| `delete_idea_flow_edge` | delete | Remove a connection |

MCP writes trigger the existing WAL poller → `db:changed` IPC → the Flow view re-fetches automatically, so the canvas updates in real time while an agent is working.

## Database

Three new tables added via additive migrations (no changes to existing tables):

```sql
idea_flows         (id, project_id, created_at, updated_at)
idea_flow_nodes    (id, flow_id, type, x, y, width, height, parent_id, data JSON, created_at, updated_at)
idea_flow_edges    (id, flow_id, source_node_id, target_node_id, label, created_at)
```

`parent_id` on nodes supports group/container nesting via React Flow's `parentId` sub-flow system.

## Settings

MCP Settings panel now lists the six Idea Flow tools with correct read / write / delete colour coding.
