## What's new

### Features
- **Mobile Responsive Layouts**: Complete mobile support across all major application panels. Viewports under `768px` automatically trigger:
  - Collapsed mini-sidebar hides and expanded sidebar converts to a touch-dismissible slide-over drawer with a smooth slide-in animation.
  - Chat panel displays in full-screen modal mode, hiding desktop-specific divider resize handles.
  - Topbar breadcrumbs truncate gracefully and show a mobile view-selector dropdown containing the active view name.
  - Project Overview scales to a stacked 1-column format for stats, 2-column layout for priority metrics, and contains all content inside viewport width boundaries.
  - Settings screen stacks navigation vertically above settings cards and renders categories as a swipable horizontal tabstrip.
  - Notes view collapses to hide list panels while editing a note, optimizing layout space.
- **Tabbed Mobile Agent Workspace**: Upgraded the agent views (`AgentView.tsx`, `AgentBottomTerminal.tsx`) to render a responsive tabstrip. Selecting tabs stretches the terminal, file-tree, editor, diff, or console to occupy the full viewport width and height, triggering layout refits automatically.
- **Electron Title Bar Exclusions**: Draggable Electron title bars are hidden on browser/mobile clients, returning `null` when running outside the native Electron desktop container to conserve vertical space.
- **Mobile PDF Export & Web Share**: Patched the backend PDF print generator (`handlers.ts`, `preload.ts`) to support returning the printed note directly as a Base64-encoded PDF buffer. When triggered on a mobile browser client, the app decodes the response, constructs a standard Web `File` object, and opens the native device share sheet (`navigator.share`) directly on iOS/Android.
- **Unified Note & Dashboard Headers**: Standalone mobile back headers were removed, and the back buttons were embedded directly next to the header controls inside `NoteEditor` and `DashboardView`.
- **Responsive Note Header Wrapping**: The main `NoteEditor` header wrapper uses `flex-wrap`, stretching the first row full width and aligning the Write/Read toggle to the right and the back button to the left. This pushes note metadata (word count, read time, updated timestamps, pin buttons) to wrap cleanly onto subsequent lines.
- **Responsive Table Formatting**: All markdown tables in note reads and previewers (`NoteEditor`, `NoteMarkdownPreview`) are wrapped inside scrollable `w-full overflow-x-auto` HTML containers, allowing them to remain responsive on mobile instead of breaking layout grids.

### Fixes
- **Mobile Configuration Cache Syncing**: Added a persistent cache (`ai-settings-cache.json`) inside the main process to synchronize settings (AI providers, custom model endpoints, API keys) between the Electron host and browser/mobile clients.
- **Next.js HMR WebSocket Upgrade Proxy**: Configured custom HTTP header rewriting for Next.js Turbopack upgrade proxy handshakes in `mobile-server.ts`. This pipes socket traffic immediately, preventing Next.js from rejecting HMR WebSocket connections on origin mismatches.
- **Proxy Methods & Header Support**: Upgraded the mobile proxy server to support non-GET HTTP methods (e.g. POST for Next.js build analytics) and automatically rewrite `Host`, `Origin`, and `Referer` headers on static asset fetches to prevent CORS or dev-server 403 blocks.
- **Persistent Mobile Cookie Sessions**: Mobile authentication sessions are written to `mobile-sessions.json` to persist user logins across Electron dev reboots.
- **iOS Safari Input Auto-Zoom Prevention**: Overrode viewport scaling properties (`initial-scale=1.0, maximum-scale=1.0, user-scalable=no`) on layout views to prevent iOS Safari from automatically zooming into the page when text fields receive focus.
- **iOS Safari Shadow & Gradient Resets**: Striped iOS Safari default inset shadows on text inputs and applied linear gradients via CSS `color-mix` to prevent WebKit from interpolating raw transparent stops into muddy grey midpoints in light mode.
- **Favicon & Apple Touch Icons**: Configured static icons routing and apple-touch-icon aliases to bypass PIN authentication checks, allowing browsers to render favicons cleanly when bookmarked.
- **Pointer Capture Crash Fix**: Injected an Element prototype release pointer capture override inside the document head to catch and swallow unmounted `NotFoundError` exceptions triggered during click transitions.
