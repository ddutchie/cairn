## What's new

### Features
- **Mobile Companion Service**: Introduce local-network mobile access to Cairn. Scan the QR code or enter the display PIN in Settings to securely access, read, and write notes, manage kanban boards, and chat with AI agents directly from your mobile browser:
  - **Local PIN Authentication**: Secure single-use PIN entry with persistent sessions (`mobile-sessions.json`), so mobile clients stay logged in across app updates.
  - **Automated Configuration Syncing**: AI providers, model endpoints, and API credentials sync instantly from the desktop's main process configuration cache to client browsers on load.
  - **Native PDF Export & Sharing**: Exporting notes on mobile generates a print-layout PDF and presents it directly in the native device **share sheet** (utilizing the Web Share API), falling back to browser downloads.
  - **HMR WebSocket & Proxy Support**: Upgraded dev server route handling and WebSocket proxy pipes to support non-GET routes and Hot Module Reloading (HMR) seamlessly on remote mobile browsers.
- **Mobile Responsive Layouts**: Designed and optimized responsive CSS flex grids across all panels:
  - Sidebar folds into a touch-dismissible slide-over drawer with a backdrop overlay.
  - Breadcrumbs auto-truncate and show a clean viewport-selector dropdown at phone sizes.
  - Chat panel expands to occupy `100vw` / `100dvh` full-screen modal mode, hiding manual resize drag handles.
  - Project Overview tiles stack into 1-column lists with description word-wrapping to prevent layout stretch.
  - Settings navigation converts to a swipable horizontal category strip.
  - Notes view hides notes list panel while reading/writing a note to maximize viewport width.
- **Tabbed Mobile Agent Workspace**: Replaced absolute desktop split-panes in `AgentView` with a mobile tabstrip, allowing developers to switch between terminal, files, editor, diff, and console in full screen with auto-refitting layouts.
- **Mobile-Friendly Note Headers**: Standalone back headers were removed, and the back buttons were embedded next to the editor controls. NoteEditor headers use flex-wrapping, stretching controls to occupy the top row with the Write/Read toggle aligned to the right and the back button to the left, wrapping note metadata cleanly to the next line.
- **iOS Safari & Mobile Browser Compatibility**: Implemented compatibility patches specifically for mobile clients:
  - Viewport metadata disables scaling limits to prevent auto-zooming when focus shifts to text inputs.
  - Default iOS Safari three-dimensional inner shadows on inputs and textareas are reset.
  - Layout gradients use HSL `color-mix` to prevent muddy transparent black midpoint interpolation on Safari WebKit.
  - Bookmarked clients automatically load served favicons and apple-touch-icon aliases bypassing login redirects.
  - Safety shim catches and swallows pointer-release errors from unmounted targets to prevent UI crashes.
- **Responsive Table Layouts**: Markdown tables in read modes and preview panels are rendered inside scrollable HTML containers (`w-full overflow-x-auto`), allowing wide tables to scroll horizontally instead of breaking layout grids.
