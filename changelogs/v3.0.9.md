## What's new in Cairn 3.0.9

### Fixed

- **Coding-agent shell commands run on Windows again.** The sandbox runner was spawned with Cairn's own executable, which launched a second copy of the app instead of running the command, so shell output was just Chromium cache errors. The runner now starts in Node mode, and the variable that enables this is cleared before your command runs.
- **Agent subprocesses run properly contained.** Every command the agent runs (shell, search, language servers) goes through a helper that tracks the whole process tree, so stopping a command also stops anything it started. In development builds that helper started another copy of Cairn instead; in the installed app it was missing, so commands ran without tree tracking. It now ships with the app and runs as a lightweight Node process on both.
- **Workflows can start their worker.** The workflow engine's worker file wasn't part of the build, so starting a workflow failed. It's now built beside the app.
- **Glob and Grep work in the installed app.** The ripgrep binary these tools run wasn't included in packaged builds, so every search failed. It now ships unpacked beside the app, and the tools point at that copy.
- **Agent session logs save reliably on macOS and Linux.** The native helper that locks a session's log file before writing wasn't included in installed builds, so dsh's session logs could fail to save without any error. It now ships for both Apple Silicon and Intel Macs and for Linux, which also fixes the Linux command sandbox.
- **Terminal tool output is readable.** Model terminal sessions no longer show raw escape codes (`[?25l`, `[K`, colour codes) from the Windows console. Pagers are also turned off there, so `git log` can't hang waiting for `q`.
- **Subagents render in the coding agent pane.** Subagent traces were dropped because nothing created the subagent block they update. The block now appears as soon as a subagent starts, and its running state clears when it finishes.
- **Diff preview renders as a diff.** The side-panel diff preview now shows coloured, themed hunks instead of raw unified-diff text.
