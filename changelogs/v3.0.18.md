## What's new in Cairn 3.0.18

### Fixed

- **Typing in a chat is fast again.** Every keystroke used to re-render the whole conversation (and its queue, header and pickers), which made the input lag badly in long threads. The draft text now lives in the input itself, so typing only re-renders the input box. Slash-command and @-mention lookups also stop re-running on every key event.
- **Running chats can't be deleted.** Deleting a chat or "Clear all" now checks with the main process whether a reply is live and refuses if so; the delete buttons are also disabled (with a tooltip) for running chats and coding sessions. Stop the reply first.
