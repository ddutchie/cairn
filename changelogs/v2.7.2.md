## What's new

### Added

- **Chat threads keep their chain-of-thought across restarts.** The raw Responses reasoning items (plus the reasoning field and model that produced them) are now persisted on chat messages, so a resumed thread round-trips the prior reasoning to the same model — keeping multi-turn tool loops on GPT‑5.x/Luna consistent after an app restart, not just mid-session.

### Changed

- **Condensed reasoning summaries are now requested for reasoning models.** Chat and the coding agent ask the Responses API for a concise summary (`reasoning.summary`) on reasoning models, so the collapsed Thinking panel shows a real summary instead of an empty one.

### Fixed

- **Reasoning items are replayed with their `summary` field intact.** When the previous turn's reasoning carried a summary array (even an empty one), the round-trip now sends it back — strict Responses providers reject a reasoning item that omits `summary` when encrypted reasoning content is replayed.
- **Strict Responses endpoints that reject optional fields are retried stripped.** Chat and the agent loop now retry a 400/422 once without `temperature`, `reasoning.effort`, and `reasoning.encrypted_content` — matching compaction — so models that refuse those fields still respond.
