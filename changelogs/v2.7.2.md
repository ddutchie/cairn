## What's new

### Added

- **Queue messages while the assistant is working.** When a reply (or coding-agent run) is in progress, the composer stays active — sending adds your message to a queue instead of being blocked. Queued messages show inline with a "Queued" tag and a Remove button, then send automatically (in order) when the current reply finishes. Stopping only cancels the in-flight turn; queued messages still go through, and a failed turn still lets the queue continue.

### Changed

- **The coding agent's transcript is now virtualized.** Only the messages near the viewport are mounted, so a session with thousands of persisted messages (each with reasoning, tool chips, and subagent traces) stays smooth — you can scroll from the newest message all the way back to the start and the render cost never grows.
