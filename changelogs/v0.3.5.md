# v0.3.5

## What's new

### Date picker
Native `<input type="date">` replaced with a custom `DatePicker` component (`src/components/ui/date-picker.tsx`) backed by react-day-picker v9. A calendar popover opens on click, fully styled with CSS vars (works in light and dark mode). Shows a formatted date string when set, with a clear button. Used in both the column quick-create form and the card detail sidebar.

### Settings — open to General by default
Settings now opens on the General tab instead of AI & Chat.

### Settings — shared header
The Cairn logo and version number now appear in a persistent header strip above all settings pages, rather than only on the About tab.

### Settings — About page overhaul
- Hardcoded stack list replaced with auto-generated data (real installed versions, accurate license identifiers)
- Open Source Licenses section added — collapsible list of all installed dependencies with name, version, and license identifier
- Stack grid now shows version numbers next to each entry

## Fixes

- **Release script** — `scripts/release.sh` was computing the next version with `node -p`, which caused `process.stdout.write()` to append its return value (`true`) to the version string (e.g. `0.3.4true`). Fixed by switching to `node -e`.

## Internals

- `scripts/generate-licenses.js` added — walks `node_modules` at build time and writes `src/generated/licenses.json` containing a curated stack list and a full dependency license inventory. Runs automatically before `next build` and on `npm run dev`. `src/generated/` is `.gitignore`d.
- `ROLE_MAP` in `generate-licenses.js` controls which packages appear in the Settings stack grid — add an entry there when adding a new UI-facing dependency (documented in README).
- README updated: stack table corrected and expanded, `update_task` added to MCP tools table, license generation workflow documented.
