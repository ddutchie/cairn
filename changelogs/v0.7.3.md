# v0.7.3 — Knowledge Graph polish

## Force graph

**Simulation stability**
- `fgData` is now memoised by node/edge ID fingerprints — clicking a node or changing selection no longer re-runs the simulation
- `filteredGraph` in `KnowledgeGraphView` is memoised on `graphData` + `graphFilters` only, so unrelated store updates don't create new prop references and trigger re-simulation
- Forces configured via `onEngineStart` (synchronous, before first tick) instead of a racing `useEffect` + `setTimeout`

**Layout quality**
- Charge repulsion set to `−120`, variable link distances (`70px` project-member, `50px` tag-member, `35px` other) — nodes spread into a proper 2D cluster instead of collapsing vertically
- Collision force (`forceCollide`) prevents node overlap

**Visuals**
- Labels rendered at fixed screen-space size (`screenPx / globalScale`) — consistent 10–11px at all zoom levels
- Non-project labels gated at `globalScale ≥ 1.2` — overview stays clean, detail reveals on zoom
- Edge colours by type: note-note=info, note-card=success, tag-member=warning, project-member=accent, flow-edge=accent solid, auto-edges=border dashed
- Selected node glow ring (3-pass arc with decreasing opacity)

**Zoom controls**
- Zoom in / zoom out / fit buttons rendered as an inset overlay (bottom-right)
- `onEngineStop` auto-fits the viewport once simulation settles

## Radial tree

- Cross-edges (non-hierarchy connections) reduced to `0.1–0.2` opacity, dashed, `0.75px` stroke — tree structure reads clearly as primary; cross-edges as contextual hints
- Previously cross-edges were `0.5` opacity solid lines, visually competing with tree links

## Timeline

- Timed and undated card sections centred with `mx-auto` — no more large empty right gutter

## Matrix

**Layout overhaul — CSS container queries, no JS measurement**
- Removed all JS-based sizing (`useRef`, `useState(containerWidth)`, `useEffect`, `ResizeObserver`, debounce timers)
- Scrollable wrapper uses `containerType: "inline-size"` making it a CSS container query context
- Grid template uses `clamp(44px, calc((100cqw - 140px) / n), 80px)` — browser computes cell size natively on every layout pass; cells grow smoothly with the window with zero JS involvement and no jelly artefacts
- Column header widths and row heights use the same `clamp()` expression so everything stays in sync

**Interaction**
- Hover previews the intersection panel on the right; click pins it open; click same cell again or press ✕ to dismiss
- Intersection panel always rendered at `w-72` — no layout shift when hovering
- Clicking an item in the intersection panel calls `onNodeClick` → opens `GraphDetailPanel` for that node

**Visuals**
- Column headers replaced with `−45deg` angled labels — readable and compact
- Blended tag colours for off-diagonal cells; diagonal cells show tag colour with count
- Axis highlight dims non-hovered rows/columns to `opacity-30`

## Table

- `typeFilter` changed from single-select (`GraphNodeType | "all"`) to multi-select (`GraphNodeType[]`) — consistent with node type toggles in Force/Radial
- Filter logic: empty selection = show all; one or more active = show matching types
- `showPriority` column visibility updated for multi-select logic

## Toolbar — unified search and filters

- Search input and type toggle pills now appear for Force, Radial, and Table views in a consistent layout: search left, type toggles right
- All three views use the same coloured pill toggle style (active = coloured background + border, inactive = dimmed border)
- No "All" button — deselecting all pills implicitly resets to showing everything
- Search in Force/Radial filters nodes by title and retains parent project nodes of any match, so child nodes are never orphaned in the Radial hierarchy
- Refresh button moved to far right of toolbar, icon-only, adjacent to the node/item count

## Bug fixes

- Fixed `tableTypeFilter` state type mismatch between `KnowledgeGraphView` (now `GraphNodeType[]`) and `TableCanvas` prop
- Removed unused `DEFAULT_GRAPH_FILTERS` import from `KnowledgeGraphView`
- Fixed `blendHex` `padStart` second argument (was `"00"`, should be `"0"`)
- `filteredNodes` / `filteredEdges` aliases restored after `filteredGraph` memo refactor to avoid reference errors in toolbar stat count
