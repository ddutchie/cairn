## What's new in Cairn 3.1.6

### Changed

- **Streaming replies no longer re-render the whole chat.** The in-flight reply's text lives in a small store that only the live bubble subscribes to, so the chat panel, pop-out window and composer stop re-rendering on every streamed frame. Long replies stay smoother and typing in the composer mid-stream is no longer competing with token updates.
- **Long assistant messages re-parse only their newest section.** Replies over a page long are split at section headings into memoized chunks while they stream, so completed sections are not re-parsed on every token. Splitting is skipped for content where it could change the output (code fences, link reference definitions, footnotes, raw HTML blocks).
- **Model picker includes reasoning effort.** For reasoning-capable models the provider/model popover now has a Thinking row (Auto, Off, Low, Medium, High), so model and effort can be set in one place. The separate effort pill still works.
