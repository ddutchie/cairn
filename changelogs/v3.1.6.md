## What's new in Cairn 3.1.6

### Changed

- **Streaming replies no longer re-render the whole chat.** The in-flight reply's text lives in a small store that only the live bubble subscribes to, so the chat panel, pop-out window and composer stop re-rendering on every streamed frame. Long replies stay smoother and typing in the composer mid-stream is no longer competing with token updates.
- **Long assistant messages re-parse only their newest section.** Replies over a page long are split at section headings into memoized chunks while they stream, so completed sections are not re-parsed on every token. Splitting is skipped for content where it could change the output (code fences, link reference definitions, footnotes, raw HTML blocks).
- **Model picker includes reasoning effort.** For reasoning-capable models the provider/model popover now has a Thinking row (Auto, Off, Low, Medium, High), so model and effort can be set in one place. The separate effort pill still works.

- **3D knowledge graph.** A new 3D option in the graph layout toggle renders the graph as a rotatable, zoomable WebGL scene (drag to orbit, scroll to zoom, drag nodes). It shares colours, spacing and selection highlighting with the Force view, and the 3D engine only loads when you open it.

- **Right-click menus across the app.** Tasks now have one shared menu on the board and everywhere they appear in the calendar (grid, overdue/unscheduled trays, day detail): Mark done / Reopen, Move to column, Priority, Due date, Move to project, Duplicate, Archive and Delete. Kanban columns, archived cards, Agent sessions, the file tree (reveal in Finder, copy path), git file rows, chat messages (copy as markdown, retry), Idea Flow nodes and connections, and Force/Radial/3D graph nodes, the automations list, the sidebar project card, and the terminals (Copy, Paste, Select all, Clear) all gained context menus. The Flow canvas menu is now the shared Radix menu, with long-press on touch.
- **Cut / copy / paste in text fields, plus spellcheck.** Right-clicking any text field, editor or selection now opens a menu with Cut, Copy, Paste and Select all, "Copy link address" on links, and spelling suggestions with "Add to dictionary" on misspelled words.

- **Find inside a note.** ⌘F (Ctrl+F) now opens a find bar in the open note in both Edit and Read mode, with match highlighting, an "n of N" counter, next/previous (↵ / ⇧↵), Match case and Whole word. The sidebar filter moved to ⌥⌘F (Ctrl+Alt+F), and still takes ⌘F when no note is open.
- **Search shows where it matched.** Global search results now ranked by relevance (title hits first), show an excerpt around the match with the terms highlighted, and opening a result jumps into the note with the find bar already on the match. Search also understands "exact phrases" and -excluded words, in global search and the sidebar filter.

### Fixed

- **No more automatic "OpenAI" provider.** Finishing onboarding without entering an API key no longer files the prefilled OpenAI endpoint as a saved provider.
- **Usage panel adapts to its own width.** Layout now follows the panel's size rather than the window's, so in a narrow pane the toolbar controls wrap, stat cards reflow instead of overflowing, and the chart and model breakdown stack.
- **Wikilinks with brackets resolve.** `[[Title [WIP]]]` links now parse and navigate like any other wikilink instead of rendering as dead text.
