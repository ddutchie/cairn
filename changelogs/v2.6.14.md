## What's new

### Added

- **The model picker now shows a price for every model that has one.** Models.dev lists some model ids with no pricing of their own while a sibling id carries the price (e.g. bare `deepseek-v4-flash` has no entry, but `deepseek/deepseek-v4-flash` is priced). The picker now resolves those — plus gateway and region variants like `opencode-go/deepseek-v4-flash`, `deepseek-v4-flash-gcp`, or `deepseek-v4-flash:thinking` — to the priced entry, so the dropdown shows the price instead of nothing. Genuinely free models still show "free".

### Changed

- **Writing Style replicates to your devices.** Your style guide (persona, full guide, cheat sheet) now syncs through Device Sync so mobile chat can draft in your voice too. The sync protocol is bumped to v2 for this, so a paired device on an older version shows a "device needs updating" hint until it's updated.

### Fixed

- **Usage cost estimates work for region/date/reasoning-suffixed model ids.** When a provider reports no cost, the estimate now strips trailing qualifiers (`-gcp`, `-0731`, `:thinking`) and matches the underlying model's pricing — so a request on such a model gets an estimated cost (`~`) in the Usage view instead of showing nothing.
