## What's new in Cairn 3.1.1

### Fixed

- **Task tool calls no longer show as "failed" when they worked.** Creating a task, logging progress, claiming or updating a task from chat or a coding session made the change but showed a "failed" chip, and the agent was told the call had errored (which could make it retry and create a duplicate card). These calls now report success.
- **Chats with an image can be continued after restarting Cairn.** Images you paste into a chat used to be kept only while Cairn was running, so continuing that chat after a restart failed every time with "Turn ended: error". Images are now saved alongside your chat history (and cleaned up after 90 days without use, like old sessions). If an older chat still points at an image that's gone, the agent is told an image was there and the conversation carries on.
- **Chat errors say what went wrong.** "Turn ended: error" now includes the underlying error message.
- Fixed old chat and agent sessions sometimes being deleted by the 90-day cleanup even though you had used them recently.
