## What's new in Cairn 3.0.21

### Improved

- **Usage history groups requests by thread.** Each chat thread, agent session or automation run is now one expandable row showing its title, request count, models, total tokens and total cost. Click a row to see the individual requests underneath. One-shot calls with no thread (commit messages, explain, etc.) still appear as single rows. Thread totals follow the range, source and "estimated costs" filters.
