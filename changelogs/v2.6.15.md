## What's new

### Changed

- **Dependency refresh — TypeScript 7, KaTeX 0.18, jest-dom 7, better-sqlite3 13, Transformers.js 4.** The renderer type-checks on TypeScript 7 while the codebase still lints on 6; KaTeX rendering moves to 0.18 (math in notes, dashboards and chat); the test setup moves to jest-dom 7; and SQLite moves to better-sqlite3 13, the first N-API release — one binary now serves Electron, the packaged `cairn-mcp`, and tests, with the MCP binary's native sidecar re-signed on macOS so it survives dyld's code-signature enforcement. Embeddings move to Transformers.js v4 with onnxruntime-node pinned to 1.23.0 — the last release with a macOS x64 (Intel) prebuilt — so embeddings, note/task semantic search, and knowledge-graph projection keep working on both arm64 and Intel Macs.
