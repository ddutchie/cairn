## What's new

### Changed

- **Dependency refresh — TypeScript 7, KaTeX 0.18, jest-dom 7, better-sqlite3 13, Transformers.js 4, Electron 43.** The renderer type-checks on TypeScript 7 while the codebase still lints on 6; KaTeX rendering moves to 0.18 (math in notes, dashboards and chat); the test setup moves to jest-dom 7; and SQLite moves to better-sqlite3 13, the first N-API release — one binary now serves Electron, the packaged `cairn-mcp`, and tests, with the MCP binary's native sidecar re-signed on macOS so it survives dyld's code-signature enforcement. Embeddings move to Transformers.js v4 with onnxruntime-node pinned to 1.23.0 — the last release with a macOS x64 (Intel) prebuilt — so embeddings, note/task semantic search, and knowledge-graph projection keep working on both arm64 and Intel Macs. Electron moves to 43 (Chromium 150), which is ABI-neutral for the N-API addons and keeps both the arm64 and x64 macOS targets.

### Fixed

- **Chat panel resize no longer snaps.** Dragging the chat sidebar resize handle now reflows the main content area live as you drag, instead of waiting for mouse-up. (The drag writes the width straight to a CSS variable so both the panel and the content reflow instantly, then commits the final width to the store once you let go.)
- **Chat input footer wraps when narrow.** In a narrow chat sidebar the "Shift+Enter for new line · Enter to send" hint now drops onto its own line below the provider/model dropdowns instead of squeezing beside them.
- **Done/archived blockers no longer linger as stale dependencies.** A card that moved to a Done column or was archived now gets removed from every other card's `blockedByIds` — previously the drag-and-drop path (restored after a regression) and archiving (single and bulk, desktop UI and MCP) left the resolved blocker behind, so `get_task` and `list_ready_tasks` reported outdated dependencies. A data-repair migration also sweeps existing stale refs on upgrade.
