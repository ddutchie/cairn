# v0.5.1 — UI Polish

A thorough visual polish pass across cards, notes, settings, search, chat, and the entire design token system. No new features — just a tighter, more consistent UI.

## Kanban cards

- **Card title is now `13px`** (up from `12px`) with tighter line-height, creating a clear size hierarchy between title and description text.
- **Footer icons bumped from `size-9` to `size-11`** — the calendar and linked-note icons were nearly invisible at 9px. They now match the `10px` text beside them.
- **Card overdue chip** uses `var(--danger)` instead of hardcoded `text-red-400`.
- **Drag-to-action zones** (Archive / Delete portal overlay) replaced all hardcoded amber/red hex values with `color-mix(in srgb, var(--warning|--danger) %, transparent)` — now adapts correctly to light mode.

## Card detail

- **Tag toggle buttons** use `ring-[var(--accent)]/40` instead of `ring-white/20` for the active state (the white ring was invisible in non-dark themes).
- **Linked note action buttons** (open/unlink) now have `aria-label` instead of `title`, use `var(--danger)` for the unlink hover, and are visible on `focus-visible` not just hover.
- **Sidebar label icons** bumped from `size={9}` to `size={10}`.
- **Column `<select>`** now has a proper `id`/`htmlFor` association with its `<label>`.

## Notes list

- **Removed stacked opacity on timestamp** — the note timestamp was using `opacity-60` on top of `text-tertiary`, pushing it below readable contrast. Now uses `text-tertiary` alone.
- **Archived note rows no longer dim the entire row** — the `opacity-50` wrapper was making the restore and delete buttons inside hard to see. Text is now `text-tertiary` at full opacity; controls remain fully legible.
- **Delete menu items** use `var(--danger)` instead of `text-red-400`.

## Note editor

- **Backlinked notes are now clickable** — linked note rows in the backlinks panel were non-interactive `div`s. They are now `button` elements that navigate to the note.
- **Emoji `📄` replaced with `<FileText>` icon** — the only emoji in the codebase, inconsistent with all other Lucide icon usage.
- **Preview empty state** now has an `Eye` icon instead of bare italic text.
- **"Add tag" button icon** bumped from `size={9}` to `size={11}`.

## Project overview

- **Replaced hardcoded `rgba()` colours** with `color-mix(in srgb, var(--token) %, transparent)` throughout the stats cards and priority breakdown grid, so they correctly respond to theme changes.
- **Pinned note title hover** changed from `text-white` (broken in light mode) to `text-[var(--accent)]`.
- **ColumnPill empty dash** changed from `text-[var(--border)]` (wrong token, near-invisible) to `text-[var(--text-tertiary)]`.
- **DueCard** removed unreliable Tailwind fractional opacity hacks (`/[0.03]`, `/[0.07]`) from overdue/today row backgrounds.

## Modals

`PrdModal` and `MoveNoteModal` were hand-rolled `div` overlays lacking focus trapping, Escape handling, `role="dialog"`, and `aria-modal`. Both are now built on the shared `<Dialog>` component.

- `MoveNoteModal` now shows project icons, has a proper empty state with icon, and closes automatically after selecting a project.
- `PrdModal` error state uses `var(--danger)`.

## Sidebar

- **"Due in 0 days" → "Due today"** — the due-date dot tooltip now correctly says "Due today" when a project is due on the current day.
- **Delete project dialog** now uses consistent `px-5 py-4` body padding, matching the column and note delete dialogs.
- **"Create one" link** changed from `hover:underline` to a proper `hover:bg` pill, consistent with every other interactive element.
- **Project more-menu button** now visible on `focus-visible`, not just hover.

## Topbar

- **View tab buttons** have `focus-visible:ring-1 ring-[var(--accent)]` and `aria-current="page"` on the active tab.
- **Status and priority pills** had inline `style` overrides fighting their `className` colours (setting `backgroundColor: "transparent"`). These are removed — the token-based text colours now apply cleanly.

## Settings

- **Active nav item** now shows a left-border accent (`border-l-2 border-[var(--accent)]`), matching the pattern used in the notes list and sidebar. Previously only a background change was used, which was very subtle.
- **Section switching** now triggers a fade animation — `key={section}` added to the content wrapper so `animate-fade-in` re-fires on every tab change.
- **Tags empty state** now has a `Tag` icon + two-line description instead of a bare `<p>`.
- **Tag usage counts** changed from cryptic `3n · 1c` to `3 notes · 1 card`.
- **Inactive theme option buttons** now have `hover:bg-[var(--surface-3)]`.
- **MCPSettings** sync status, tool category dots, and legend replaced `bg-red-400`, `bg-amber-400/500`, `bg-emerald-500` with `var(--danger)`, `var(--warning)`, `var(--success)`.

## AI Settings

- Merged duplicate `import { Eye, EyeOff }` into the main lucide import block.
- Fixed no-op `setTimeout` that always set state to `"idle"` regardless of branch.
- Error/status text uses `var(--danger)` instead of `text-red-400`.
- Fetch button no longer collapses width during loading (added `min-w` + `"…"` label).
- Show/hide API key button has `aria-label`.
- Fetch models button has `aria-label`.

## Search

- **No-results empty state** now shows a `SearchX` icon above the message instead of bare text.

## AI Chat

- **ToolCallIndicator avatar** now uses the `Bot` icon matching the assistant message bubble, replacing the plain `"AI"` text label.
- **`search_result` context chip** now shows a `Search` icon instead of the `Kanban` icon (which implied a task context).
- **Copy/retry actions** on message bubbles are now also revealed on `focus-within`, making them accessible to keyboard users.

## Design system

- **`button.tsx` danger variant** now uses `var(--danger)` throughout instead of raw `red-500` Tailwind classes. Accent button uses `var(--accent-fg)` fallback instead of hardcoded `text-white`.
- **`badge.tsx`** replaced the `color + "18"` hex-append opacity hack with `color-mix(in srgb, ...)` — works correctly for any colour format (hex, rgb, hsl, CSS var).
- **`tooltip.tsx`** added missing `import * as React` for the `React.ReactNode` type reference.
- **Mermaid error state** uses `var(--danger)` instead of `text-red-400 / bg-red-400/10`.
- **Toast error icon** uses `var(--danger)` instead of `text-red-400`.

## Mermaid diagram modal

- Modal now uses `w-[90vw] h-[88vh]` and fills the space with `flex-1`, so diagrams scale to use the full viewport on large screens instead of rendering at a small fixed size.
