## What's new

### Features

- **Integrated Git Management UI**: Added a dedicated Git client tab within the agent coding view, enabling users to:
  - View working directory status with classified lists for Staged, Unstaged, and Untracked files.
  - Stage, unstage, or discard file changes (both individually and in bulk).
  - Draft commits with support for manual messages, conventional commit prefixes, and automatic AI-generated commit messages.
  - Switch, checkout, and create Git branches.
  - Push local branches to remote repositories with upstream tracking.
  - View full branch commit history (Git Log).
- **Inline Git Diff Viewer**: Added a rich, color-coded visual diff component directly in the Git interface. Users can click any modified file to view added and deleted lines side-by-side or inline.
- **AI Commit Message & PR Description Generator**: Integrated LLM helpers to:
  - Analyze staged changes and generate conventional commit messages (subject + body) with conventional commit categorization (`feat`, `fix`, `refactor`, etc.).
  - Analyze branch diffs and generate pull request descriptions (markdown summary, context, and detailed key changes list).
- **GitHub Pull Request Integration**: Added support for creating and checking pull requests:
  - Create a new PR directly from the Git UI targeting custom base branches.
  - Display active PR status (title, state, and URL link) for the current branch when one exists on GitHub.
- **Per-Project Configuration & Settings**: Added database support, IPC handlers, and a React settings view for configuring settings on a per-project basis (e.g., `autoStageOnCommit`, customized paths, custom Git variables) stored as a `project_settings` JSON column in SQLite.
- **Smarter Tooling Folder Discovery**: Added folder tree structure info return APIs, allowing the AI agent to navigate and locate note hierarchies and files more efficiently.

### Fixes

- **Project Settings Default Resets**: Resolved an issue where unchecking configuration options in React saved them as `null` or `undefined` instead of removing them, preventing defaults from re-applying. They are now deleted from database settings JSON on saving or resetting.
- **Git Status Rename and Path Parsing**: Refactored status line parsing to correctly extract source and destination file paths for renames (`R`) and copies (`C`) from porcelain-z outputs.
- **Git Untracked Diff Stats**: Fixed untracked file diff calculations, ensuring line statistics (added/deleted counts) are accurately computed even when comparing against empty HEAD refs.
- **Agent UI Warnings**: Suppressed React state-in-effect update warnings within `GitView`.

### Changes

- **Asynchronous Git Operations**: Replaced synchronous shell blocking executions in Electron with a promise-based `execFile` implementation, capped with a `20MB` `maxBuffer` to prevent main process lockups on massive repositories.
- **Path Escape & Symlink Protection**: Hardened workspace containment checks with absolute path resolution (`fs.realpathSync`) to block symlink-based directory traversal exploits.
- **Pathspec Literal Filtering**: Changed single-file Git commands to use literal pathspecs (`--`) and strict validation to reject pathspec magic patterns like `:`, guarding against parameter injection.
- **Host Verification for Local Endpoints**: Updated API-key exception loop checks to parse and validate endpoint hostnames strictly (e.g., `localhost`, `127.0.0.1`) rather than loose substring matches.
- **Preload API Contract Alignment**: Refactored `preload.ts` types to reject/throw natively on error envelopes, adjusting notes store slice calls to use a structured try-catch handler.
