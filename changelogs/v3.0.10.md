## What's new in Cairn 3.0.10

### Fixed

- **No more console windows flashing on Windows.** Each time the coding agent ran a command (Glob, Grep, git, shell), a terminal window briefly popped up. Agent subprocesses now start without a console window.
- **Sandboxed shell commands work on Windows machines with WSL installed.** In workspace-write and read-only sessions, `bash` resolved to the WSL launcher in `System32` instead of Git Bash, so every command failed with `Access is denied. Error code: Bash/Service/CreateInstance/E_ACCESSDENIED`. The sandbox now runs commands with Git Bash.
- **Cleaner, hang-free quits.** Quitting now gracefully shuts down the agent runtime (aborting in-flight turns, stopping plugin watchers, clearing pending approvals) instead of killing it mid-write, with a fail-open timeout so a stuck turn can never wedge the quit.
