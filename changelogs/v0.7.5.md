# v0.7.5 — AI context & contributor improvements

## AI chat: longer context window

The conversation history sent to the model on each message has been raised from **9 messages to 40**. Previously, after ~5 back-and-forth exchanges the agent would lose the start of the conversation and re-call `get_active_context` to re-orient itself. With a 40-message window the agent retains ~20 full turns of context before anything is dropped.

## AI chat: configurable max steps

A new **Max steps** setting in **Settings → AI & Chat** controls how many tool-call rounds the agent is allowed per message.

- Default raised from 8 → **20** — complex tasks (pushing notes, building out a board, writing to the Idea Flow) now have headroom to complete without hitting the limit
- Quick-pick buttons for **5 / 10 / 20** for fast adjustment
- Description note: "Lower values reduce API costs" — useful for users on metered API plans
- Persisted as part of the AI config in `localStorage`
