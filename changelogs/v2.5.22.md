## Improvements

- **Human-readable agent decisions.** Cairn's native agent transcript now summarizes tool calls in plain English, presents confirmations as risk-shaped cards with bounded previews, and lets users choose interactive or automatic execution when approving a plan.
- **Community connector context.** Installed cairn-community MCP servers and HTTP services now contribute their branded identity to external agent tool cards, with registry metadata and safe fallbacks.
- **Regular Chat transcript polish.** AI Chat now uses the same human-readable tool summaries and displays installed community connectors with their registry branding in both live and persisted tool cards.
- **Connector-aware project tools.** Project Overview now shows each attached MCP server or HTTP service with its community logo, brand color, and safe generic fallback.
- **Safer agent transcripts and scoped approvals.** Persisted native-agent tool arguments now redact secret-like fields and assignments. Interactive sessions also support command-scoped shell grants and session-scoped tool grants without persisting permissions.
- **Reliable task edits from MCP clients.** Active task updates no longer fail when a client supplies the wrapper's default `archived=false`; the flag restores only genuinely archived cards.
- **Agent review hardening.** Approval grants are scoped to their target, nested subagent transcripts and connector outputs are redacted and bounded, and optional registry APIs no longer break browser or E2E startup.
- Use the canonical MCP connector mark across desktop and mobile fallback logos.
- Connector tool cards are now collapsed by default and expandable on desktop and mobile.
- Connector tool details now hide internal connector IDs and pretty-print structured results.
- Expanded connector results now show up to three discovered links with a Show more control.
