## Improvements

- **Human-readable agent decisions.** Cairn's native agent transcript now summarizes tool calls in plain English, presents confirmations as risk-shaped cards with bounded previews, and lets users choose interactive or automatic execution when approving a plan.
- **Community connector context.** Installed cairn-community MCP servers and HTTP services now contribute their branded identity to external agent tool cards, with registry metadata and safe fallbacks.
- **Regular Chat transcript polish.** AI Chat now uses the same human-readable tool summaries and displays installed community connectors with their registry branding in both live and persisted tool cards.
- **Connector-aware project tools.** Project Overview now shows each attached MCP server or HTTP service with its community logo, brand color, and safe generic fallback.
