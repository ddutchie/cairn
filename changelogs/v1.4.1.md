# v1.4.1

## What's new

### Features

- **Split Monolithic MCP Server** — Completely restructured the monolithic ~1,500 line `electron/mcp-server.ts` into a clean, highly modular architecture under `electron/mcp/`. Database connections are centralized in `db.ts`, and individual tool handlers are isolated into separate, domain-specific files (`projects.ts`, `notes.ts`, `tasks.ts`, `flow.ts`, `graph.ts`, `dashboards.ts`, `tags.ts`, `metadata.ts`). This greatly improves maintainability, type-safety, and testability.

- **Unified Global Chat & Panel Consolidation** — Consolidated the localized Knowledge Graph assistant panel (`GraphAIPanel.tsx`, ~560 lines) into the global application-wide Chat Panel (`chat-panel.tsx`). This resolves interface confusion by giving the user a single, powerful AI panel across all workspace views while introducing unified suggestion lists (`SuggestedPrompts.tsx`) and actionable item overlays (`ActionsList.tsx`).

- **Reusable Centralized `<ChatInput />`** — Created a highly polished, reusable `<ChatInput />` component (`src/components/chat/ChatInput.tsx`) to unify the input typing experience, prompt attachments, speech-to-text integration, and auto-growing textareas. Integrated this uniform input seamlessly across both the global chat panel and the Pi agent chat pane.

- **Design System HSL Token Compliance** — Completely eliminated raw, hardcoded Tailwind colors in visual badges and stripes across Kanban views (`card.tsx`, `column.tsx`, `board.tsx`), binding them to semantic theme variables like `var(--warning)` and `var(--danger)` through a newly standardized HSL-based `PRIORITY_CSS_COLORS` mapping in `constants.ts`.

- **Radix Dialog Migration** — Converted all manual overlay modals and custom fullscreen portals to Radix-based `<Dialog />` wrappers, introducing fully native backdrop transitions, accessible screen-reader contexts (`aria-describedby`), and unified Escape key dismissals across the app (`NodeEditModal.tsx`, `MermaidDiagram.tsx`, `DashboardApiModal.tsx`, `DashboardTemplateModal.tsx`).

- **Chat & Agent Message Primitives** — Extracted highly reusable visual components `<MessageAvatar />` and `<StreamingCursor />` into a central `message-ui.tsx` file, eliminating markup duplication between user, assistant, and agent message bubbles.

- **Reusable `<SegmentedControl />`** — Created a generalized, high-performance `<SegmentedControl />` visual selector component in `@/components/ui/segmented-control`, integrating it across the Settings view and the coding agent launch modal.

- **Dynamic Radial SVG Font Scaling** — Successfully wired typography in the SVG-based Radial Tree canvas (`RadialTreeCanvas.tsx`) to dynamically scale text sizing via the `useFontScale()` hook, maintaining text ratios across visual font scales.

### Fixes

- **Zero-Warning ESLint Compliance** — Resolved all lingering TypeScript and import warnings in `SpawnAgentModal.tsx` and `NoteMarkdownPreview.tsx`, bringing the entire project's ESLint count to absolute **zero warnings and zero errors**.
