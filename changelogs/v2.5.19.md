## Fixes

- **Gateway `provider:` prefixes and word-suffixed model ids now resolve their real context window.** The models.dev context-window lookup normalizes proxy/gateway model ids before matching, but two id shapes fell through: a leading `provider:` prefix (e.g. `merge:deepseek-v4-flash` or `merge:gpt-5.6-luna`) was mistaken for the model name, and the trailing version-tag stripper (`-v\d+.*`) was greedy — it swallowed everything after `-vN`, collapsing `deepseek-v4-flash` to `deepseek`. Cairn now strips a leading `provider:` prefix first (whether or not the id also has a `/` path), and only strips a *pure* trailing version tag (`-v1`, `-v1:0`) so descriptive suffixes like `-flash` and `-luna` survive. Added unit tests for `normalizeId` covering these cases.

- **Community connector logos stay legible on both themes.** Browse Community now renders each entry's logo on a fixed light "chip" (like an app-store icon tile), so a dark monochrome brand mark — e.g. a charcoal provider logo — no longer disappears against the dark theme's near-black card. Connectors without a logo show a theme-safe generic glyph (a plug for services/providers, the MCP mark for MCP servers) on a subtle neutral tile, instead of being tinted with a `brandColor` that could vanish on one theme. Logos are also a bit larger and better aligned.

- **"Refresh" in Browse Community now forces a true re-download.** The registry Refresh sent a conditional request with the cached ETag, so a stale CDN edge could answer "304 Not Modified" and keep serving the old catalog even right after an update (e.g. a newly-added provider icon). An explicit Refresh now skips the ETag and cache-busts the request, so it always pulls the latest `manifest.json` / `providers.json`. Background revalidation still uses the efficient conditional request.

- **Model picker: tighter favourite rows.** Removed the empty check-mark spacer column that pushed model names far to the right of the favourite star; the active-model check now renders inline, so names sit right next to the star.

## Features

- **Browse and install community AI providers.** A new **Browse Community** button in both **Settings → AI & Chat** and **Settings → Coding Agent** (OpenAI-compatible provider) installs ready-made provider presets from the cairn-community catalog with one click — you just enter your API key, which is stored in your OS keychain (never in the database or synced). Each preset ships an endpoint base URL and a default model, so there's no more copy-pasting gateway URLs. Installed providers are added to your shared provider list (used by both AI Chat and the coding agent); pick one in the provider switcher to use it. Community providers live in a **separate `providers.json` manifest** from the tools/commands catalog, are fetched cache-first (instant/offline, background-revalidated), and re-installing a preset reuses the existing entry (matched by community id or name) instead of duplicating it. Each preset's endpoint base URL (and the optional "get a key" link) must be a valid HTTPS URL, and the default model is validated separately as a model identifier before install.
