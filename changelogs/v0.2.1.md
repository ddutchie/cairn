## What's new

### Bug fixes

- **Auto-updater fixed** — macOS builds now ship a `.zip` alongside the `.dmg`. `electron-updater` requires the zip to apply in-place updates; previously the updater would download the DMG but never successfully install it.
- **Update banner** — the "Downloading…" → "Ready to install" transition now works correctly regardless of which IPC event (`update-available` vs `update-downloaded`) arrives first.
