## What's new

_Planned scope for the v2.5.0 release. Theme: **the AI stops reading and starts doing.** Entries are filled in as each feature lands; see the "v2.5.0 Release Plan — Persona Synthesis" note for rationale._

### Improvements

- **The assistant can now organize your workspace.** Ask it to tag your notes and tasks and it will actually apply the tags — not just create them. New `tag_note` and `tag_task` tools resolve tags by name (creating them if they don't exist) and support add / remove / set modes, available in the desktop assistant, the MCP tools, the coding agent, and on mobile.
- **Export a note or a whole project to markdown.** A note's export menu now offers **Markdown** alongside PDF, and every project in the sidebar has an **Export as Markdown** action. Desktop saves via a native file dialog; mobile shares the note through the system share sheet. Projects export as one document — metadata, the board grouped by column, and all notes folder-sorted.
- _(planned)_ **Reusable note templates.** Save a layout once (weekly review, meeting notes) and spin up a fresh copy — by hand or by asking the assistant.
- _(planned)_ **Ask what's due.** New "overdue" and "due this week" queries so the assistant and board surface time-sensitive work.
- _(planned)_ **Mobile assistant reaches parity on linking + triage.** The mobile assistant can now link notes to tasks and move a batch of cards at once.
- _(planned)_ **Choose your look on mobile.** Manual light/dark theme toggle and font-size control on mobile (previously followed the system only).
- _(planned)_ **Cleaner search results.** Semantic search now drops low-relevance tail results instead of always padding to a fixed count.

### Under the hood

- _(planned)_ Split the Electron graph-query and core database-query modules ahead of the tag/due-date work, following the same internal-reorganisation pattern as v2.4.14. No behaviour change.
- The codebase symbol indexer now captures exported `const`, `type`, `interface`, and `enum` declarations (previously only functions, classes, and methods), so the assistant's codebase-navigation tools can find tool registries, config objects, and type definitions.
