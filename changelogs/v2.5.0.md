## What's new

_Theme: **the AI stops reading and starts doing.**_

### Improvements

- **The assistant can now organize your workspace.** Ask it to tag your notes and tasks and it will actually apply the tags — not just create them. New `tag_note` and `tag_task` tools resolve tags by name (creating them if they don't exist) and support add / remove / set modes, available in the desktop assistant, the MCP tools, the coding agent, and on mobile.
- **Export a note or a whole project to markdown.** A note's export menu now offers **Markdown** alongside PDF, and every project in the sidebar has an **Export as Markdown** action. Desktop saves via a native file dialog; mobile shares the note through the system share sheet. Projects export as one document — metadata, the board grouped by column, and all notes folder-sorted.
- **Reusable note templates.** Notes can now be saved as templates and re-used to spin up a fresh note with the same layout — the note sidebar has a "New from template" menu (with a one-click **Add starter templates** for Meeting Notes, Weekly Review, and Daily Standup), plus **Save current note as template**. Templates support `{{date}}`, `{{time}}`, `{{weekOf}}`, `{{month}}`, `{{year}}`, and `{{title}}` placeholders that are filled in when you create a note from them. Templates are scoped per-project and kept out of the normal notes list. The assistant can also start a note from a template — just ask ("start my weekly review") — via the new `list_templates` and `instantiate_template` tools.
- **Ask what's due.** The assistant can now answer "what's overdue?" and "what's due this week?" with new `list_overdue_tasks` and `list_tasks_due` tools — they return open (non-done, non-archived) cards filtered by due date, soonest first, using the same overdue/due semantics as the board and calendar.
- **Mobile assistant reaches parity on linking + triage.** The mobile assistant can now link a note to a task (and unlink), and move a batch of cards to a column in one call — `link_note_to_task`, `unlink_note_from_task`, and `bulk_update_task_status` now work on mobile, matching the desktop assistant.

### Under the hood

- The codebase symbol indexer now captures exported `const`, `type`, `interface`, and `enum` declarations (previously only functions, classes, and methods), so the assistant's codebase-navigation tools can find tool registries, config objects, and type definitions.
