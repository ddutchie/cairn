## What's new

### Column reorder

Columns can now be dragged horizontally to reorder them. A grip handle appears on hover in the column header. The new order is persisted to SQLite immediately. The drag overlay renders a ghost column while dragging, consistent with the existing card drag behaviour.

### Card improvements

- **Assignee field** — text input in the card detail sidebar. Persisted on blur.
- **Move to column** — dropdown in the card detail sidebar listing all columns in the project. Replaces the previous workflow of dragging cards across the board.
- **Unlink note** — `×` button on each linked note row in card detail. Removes the link bidirectionally (card loses the note, note loses the card).
- **Duplicate** — copies title, description, and priority into a new card at the bottom of the same column.
- **Archive** — soft-deletes the card (sets `archivedAt`). Archived cards are hidden from the board. Replaces the one-click delete that was previously the only removal option.
- **Delete** now requires a two-step inline confirmation to prevent accidental data loss.

### Note improvements

- **Archive note** — available in the note list item dropdown. Sets `archivedAt` and selects the next note. Archived notes are hidden from the list.
- **Move to project** — available in the note list item dropdown. Opens a picker listing all other projects in the workspace. Updates the note's `projectId` in SQLite and moves the `.md` file to the correct folder on disk.

### Backlinks panel

A collapsible panel at the bottom of the note editor shows all notes and cards that link back to the current note. Displays the linked item's title and type (note) or column name (card). Only shown when at least one backlink exists. Data was already in the schema — this is a pure UI addition.

### Settings

- **Export** now serialises the live store state (hydrated from SQLite) rather than the localStorage cache. The filename includes the export date (`cairn-export-YYYY-MM-DD.json`).
- **Tag stats** — the Tags settings section now shows a note and card count per tag (e.g. `3n · 1c`), making it easy to see which tags are in use before renaming or deleting them.
- **Change workspace folder** — a new row in Settings → General lets you pick a different workspace folder without restarting the app. Calls the same `initWorkspace` flow used during first-time setup.

### Onboarding

- **Back button** on the workspace details step. When the flow started from step 1 (choose folder), a back arrow in the form header returns to the folder picker without restarting the app.

### Housekeeping

- `mcpEnabled` boolean removed from `AIConfig` entirely. The MCP server is a standalone process launched directly by the user's AI tool (Claude Desktop, Cursor, etc.) — Cairn has no lifecycle control over it, so the field was dead weight.
