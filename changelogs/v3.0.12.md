## What's new in Cairn 3.0.12

### Fixed

- **Idle Device Sync no longer refreshes the whole app.** A sync round that found nothing new still wrote bookkeeping to the database every 30 seconds and whenever the window regained focus. The app treated each write as an outside change: it reloaded all data, refreshed the graph, and cleared your undo history. Idle rounds now write nothing, so the app only refreshes when a peer actually sent changes. Overlapping sync rounds (interval, focus, and wake from sleep firing together) are also collapsed into one.

- **Background reads no longer trigger app-wide refreshes.** Several read-only requests were treated as data changes. These include the running-automations count, recent runs, run logs, and the notification count. Each call told every window that data had changed, and some of them are polled regularly.

- **Switching workspace no longer briefly shows the previous workspace's graph.** The Knowledge Graph and Insights views now show a loading state until the new workspace's graph arrives. A slow response for the workspace you just left can no longer overwrite the new one.
- **A failed background refresh no longer hides the graph.** Only a load you started yourself shows an error. Background refreshes keep the graph on screen if they fail.
- **Your last edits sync before the app quits.** Quitting now waits briefly (at most five seconds) for a final Device Sync publish, even if a sync was already running when you quit.

### Improved

- **Outside changes now refresh only what changed.** Before, when an agent, the AI, Device Sync, another window, or an edited `.md` file changed anything, the app reloaded the whole workspace: every note with its full text, plus all projects, columns, cards and tags. The database now keeps a small log of which rows changed, whichever process wrote them, and the app fetches just those rows. Writes to data the UI never shows (sync bookkeeping, usage records, automation runs, embeddings) no longer trigger a refresh at all. Your undo history is cleared only when something outside this window actually changed your data.
- **Knowledge Graph no longer flashes.** Any background database write (sync, automations, usage tracking) triggered a full graph reload that briefly covered the canvas with a "Loading graph…" overlay every few seconds. Background refreshes now keep the graph on screen and skip the update entirely when nothing in the graph changed. The Radial view also keeps its drilled-in branch through those refreshes instead of snapping back to the workspace root.
- **Faster Force graph on large workspaces.** Theme colours are read once per frame instead of once per node and edge. Edges and nodes are drawn in batches, off-screen items are skipped, cluster hulls are cached while the layout is at rest, and repaints are limited to one per animation frame. Panning and zooming thousands of nodes is much smoother, and adding a note no longer re-runs the whole layout from scratch.
- **Faster Radial drill-in.** The zoom animation no longer looks up styles for every wedge on every frame, and it only animates the wedges that move.
- **Faster graph loading.** Building tag connections on the backend no longer re-parses every note's and card's tags once per tag.
- **Smoother streaming chat replies.** Streamed text used to re-render the chat pane once per token, and the whole reply's markdown was re-parsed each time, so long answers got slower as they grew. Updates are now batched to one per frame.
- **Smoother Architecture view.** The architecture graph was painting twice per layout step while settling and now paints at most once per frame. The dependency matrix no longer reads theme colours inside its cell loop.
- **Leaner graph query.** Removed a per-flow query that read and parsed every Idea Flow note reference on each graph load and then discarded the result.
- **Snappier hovering in large Force graphs.** Finding the node under the pointer used to check every node on every mouse move. It now uses a spatial index. Labels also stay visible while their text is still on screen, even when the node itself is just off the edge.
- **Leaner relationship loading.** Loading the graph now only reads the cached relationships for nodes in view, instead of every cached relationship across all workspaces.
