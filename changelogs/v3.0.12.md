## What's new in Cairn 3.0.12

### Fixed

- **Idle Device Sync no longer refreshes the whole app.** A sync round that found nothing new still wrote bookkeeping to the database every 30 seconds and whenever the window regained focus. The app treated each write as an outside change: it reloaded all data, refreshed the graph, and cleared your undo history. Idle rounds now write nothing, so the app only refreshes when a peer actually sent changes. Overlapping sync rounds (interval, focus, and wake from sleep firing together) are also collapsed into one.

### Improved

- **Knowledge Graph no longer flashes.** Any background database write (sync, automations, usage tracking) triggered a full graph reload that briefly covered the canvas with a "Loading graph…" overlay every few seconds. Background refreshes now keep the graph on screen and skip the update entirely when nothing in the graph changed. The Radial view also keeps its drilled-in branch through those refreshes instead of snapping back to the workspace root.
- **Faster Force graph on large workspaces.** Theme colours are read once per frame instead of once per node and edge. Edges and nodes are drawn in batches, off-screen items are skipped, cluster hulls are cached while the layout is at rest, and repaints are limited to one per animation frame. Panning and zooming thousands of nodes is much smoother, and adding a note no longer re-runs the whole layout from scratch.
- **Faster Radial drill-in.** The zoom animation no longer looks up styles for every wedge on every frame, and it only animates the wedges that move.
- **Faster graph loading.** Building tag connections on the backend no longer re-parses every note's and card's tags once per tag.
