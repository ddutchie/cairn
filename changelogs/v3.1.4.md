## What's new in Cairn 3.1.4

### Fixed

- **Tool chips no longer claim a note was updated when it was only read.** After the tool consolidation, reads through the new `get_item` tool fell through to a generic fallback and rendered chips like "Updated note" for notes the AI merely opened. Read chips correctly say "Read note" / "Read task" again, and the same gap is closed for the other consolidated tools — deleting a note chips "Deleted note" instead of "Updated note", for example.
