## What's new

### Changed

- **Note bodies are no longer stored twice.** The derived `content_text` mirror column (a stripped plain-text copy of every note, kept for search and embeddings) is gone from the `notes` table on both desktop and mobile. Search now uses an FTS5 full-text index (`notes_fts`) over title + body — faster keyword matching with prefix support — and plain text for embeddings, snippets, and knowledge-graph relationships is derived on read via `stripMarkdown` from the single authoritative `content`. Because the column no longer exists, it also disappears from the Device Sync oplog payload, roughly halving the note-body size replicated to paired devices.

### Fixed

- **Writing Style settings now wrap instead of overflowing on narrow windows.** The Manage row's action buttons (Edit / Regenerate, Paste style, Regenerate cheat sheet, Clear) previously sat in a non-shrinking slot, so they clipped off the edge of the page rather than wrapping. The row now lets the buttons flow onto multiple lines when the settings pane is narrow.
