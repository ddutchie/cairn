## What's new

### Fixes

- **Diff Viewer UI Blocks**: Refactored the `agent:gitDiff` handler in the Electron main process to execute `git diff` commands asynchronously via `execFile` and to load untracked files asynchronously via `fs.promises.readFile` using concurrent requests. This prevents periodic (5-second) UI stuttering and thread blocking in the Agent View.
- **Git Error Propagation**: Fixed an issue in `agent:gitDiff` where non-zero git exit status codes (such as exit code 128 when a folder is not a git repository) were silently ignored and swallowed, leading to empty states in the UI. Errors are now properly propagated to the renderer.
- **NUL-Delimited Untracked File Parsing**: Refactored the `agent:gitDiff` untracked files parser to query files using `ls-files -z` and split on the NUL (`\0`) character, preventing filename corruption due to unexpected formatting, trailing spaces, or newline characters.

### Changes

- **Asynchronous Agent File Operations & Path Confinement**: Refactored all file, directory, and spawning IPC handlers (`agent:readDir`, `agent:searchFiles`, `agent:readFile`, `agent:readFileBase64`, `agent:writeFile`, `agent:validateDirectory`, `agent:spawn`, and `agent:spawnShell`) to be fully asynchronous. Refactored path resolution (`getRealPath`) and containment checks (`assertWithinCodeDirectory`) to use `fs.promises.lstat` and `fs.promises.realpath` asynchronously, ensuring no blocking filesystem I/O remains on the Electron main process event loop.
