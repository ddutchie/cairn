## What's new

### Added

- **Choose a font for your note text.** Pick between Sans (the default), Serif, or Mono for note content — the editor, the preview, and PDF exports all use the chosen font. UI chrome stays on the system font. Set it in Settings → General ("Note font") or the quick-settings popover next to font size. System font stacks are used throughout so exports render identically on every platform.
- **Chat themes.** Re-skin the chat surface with full distinct looks — each theme bundles its own chat font, a background treatment (solid, gradient, or scanline pattern), a bubble style (filled, glass, or outlined), and a dark/light palette. Five built-in themes ship out of the box (Default, Paper, Terminal, Midnight, Aurora), and more arrive over time from the cairn-community catalog — no app update needed. Pick one in Settings → General ("Chat theme") or the quick-settings popover. Accent colour and note font are independent of the chat theme.

### Fixed

- **Deleting an automation now removes its folder from disk.** Previously the automation's row (and run history) were deleted from the database, but its on-disk folder (`<project>/.automations/<id>/` — scripts, `out/`, `.env`, manifest, and every run's transcript + scratch) was left behind. Deleting an automation now also removes the folder and purges its keychain env secrets, so nothing orphaned lingers after the automation is gone.
