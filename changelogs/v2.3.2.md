## What's new

### Features

- **Interactive Workspace Tour**: Built a lightweight, custom tour overlay engine (`AppTutorial.tsx`) that guides users step-by-step through Cairn.
  - **Visual Mask Cutout**: Renders a dark screen backdrop with a dynamic CSS/SVG `clip-path` cutout (portal) highlighting active target elements with a subtle glow animation.
  - **Real-Time Layout Tracking**: Utilizes a `requestAnimationFrame` render loop to track target element coordinates in real time. The cutout and tooltip follow target elements smoothly during CSS panel transitions (like opening the AI chat) or window resizing.
  - **Dynamic View Navigation**: Automatically shifts the active workspace view (`setView`) as the user steps through Overview, Notes, Kanban Board, Idea Flow, and AI Chat, waiting for mounting before rendering tooltips.
- **What's New Highlight Modal**: Added a paginated highlights modal (`NewFeatureModal.tsx`) using `<ModalShell>` that displays recent release information from the registry.
  - **Seen Features Registry**: Compares a static array of unique version/feature IDs against a list of seen keys in `localStorage`, displaying the modal on app startup only when unseen features are found.
  - **Skip All Control**: Integrates a secondary "Skip All" button in the footer to let users instantly dismiss the entire slides queue and save their seen state.
- **Onboarding and Settings Entrypoints**:
  - **Onboarding Checkbox**: Added a checklist prompt on the onboarding completion done screen to launch the quick app tour on first boot.
  - **Settings Action Buttons**: Added manual trigger buttons inside Settings -> About to replay the app tour or review what's new on-demand.

### Changes

- **Image-Free Registry**: Removed raster screenshots from the feature highlights registry to optimize packaging sizes, resulting in a clean, lightweight, fully responsive, and text-focused CSS layout.
- **Types and Store Expansion**: Extended the Zustand UI slice (`src/store/slices/ui.ts`) and global type models (`src/types/index.ts`) to manage persistent seen feature lists and active tour step indexes.
