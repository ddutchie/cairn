## What's new

### Features

- **Interactive Workspace Tour**: Built a lightweight, custom tour overlay engine (`AppTutorial.tsx`) that guides users step-by-step through Cairn.
  - **Visual Mask Cutout**: Renders a dark screen backdrop with a dynamic CSS/SVG `clip-path` cutout (portal) highlighting active target elements with a subtle glow animation.
  - **Real-Time Layout Tracking**: Utilizes a `requestAnimationFrame` render loop to track target element coordinates in real time. The cutout and tooltip follow target elements smoothly during CSS panel transitions (like opening the AI chat) or window resizing.
  - **Dynamic View Navigation**: Automatically shifts the active workspace view (`setView`) as the user steps through Overview, Notes, Kanban Board, Idea Flow, and AI Chat, waiting for mounting before rendering tooltips.
- **What's New Highlight Modal**: Added a paginated highlights modal (`NewFeatureModal.tsx`) using `<ModalShell>` that displays recent release information from the registry.
  - **Seen Features Registry**: Compares a static array of unique version/feature IDs against a list of seen keys in `localStorage`, displaying the modal on app startup only when unseen features are found.
  - **Skip All Control**: Integrates a secondary "Skip All" button in the footer to let users instantly dismiss the entire slides queue and save their seen state.
- **Onboarding and Settings Entrypoints**:
  - **Onboarding Checkbox**: Added a 'Start a quick interactive app tour on launch' checkbox to the onboarding completion screen.
  - **Settings Action Buttons**: Added manual trigger buttons inside Settings -> About to replay the app tour or review what's new on-demand.

### Fixes

- **AI note edits now appear live in the open editor**: When the in-app Chat or the MCP server patched a note that was open in the editor, the change was invisible until you switched notes or reloaded. The renderer was skipping re-hydration (the surrounding chat IPC tripped the own-write guard) and the per-note merge preserved the stale in-memory copy. A new AI-write registry, fed by the existing `note:aiWriteStarted` / `note:aiWriteEnded` events, now overrides the own-write guard so AI edits are surfaced immediately in the open editor.
- **Linked note from a task card opens the correct note**: Clicking "Open note" on a card's linked note dispatched the selection event in the same tick as the view switch, before the Notes view had mounted its listener — so the event was dropped and the wrong (or first) note opened. The dispatch is now deferred so navigation lands on the intended note.
- **Onboarding project icon is now saved**: The icon picked while creating your first project was collected but never persisted. The selected icon is now passed through to project creation and shown in the sidebar and overview.
- **Onboarding accessibility and in-flight safety**: The create-project step now disables the back, skip, and icon-picker controls while a project is being created, adds accessible names to icon-only buttons, exposes selected state on the icon picker, and uses the accent foreground design token instead of a hardcoded colour.
- **Chat post-write refresh error handling**: The store refresh that runs after AI tool writes is now awaited/caught, preventing unhandled promise rejections when an IPC refresh fails.

### Changes

- **Image-Free Registry**: Removed raster screenshots from the feature highlights registry to optimize packaging sizes, resulting in a clean, lightweight, fully responsive, and text-focused CSS layout.
- **Types and Store Expansion**: Extended the Zustand UI slice (`src/store/slices/ui.ts`) and global type models (`src/types/index.ts`) to manage persistent seen feature lists and active tour step indexes.
- **Bounded write-guard registries**: The per-note own-write and AI-write tracking maps now prune expired entries so they stay bounded over long sessions.

### Tests

- **AI-write E2E coverage**: The Playwright IPC mock now supports emitting push events (`window.__cairnEmit`) and the store is exposed for automation, fixing previously silent no-op navigation in the smoke suite. Added end-to-end tests asserting the note editor's read-only "AI is editing" banner toggles on `onAiWriteStarted` / `onAiWriteEnded` and ignores events for other notes.
- **Write-guard unit tests**: Added unit coverage for the own-write and AI-write registries (window/tail boundaries, pruning, and the guard interaction that lets AI edits win).
