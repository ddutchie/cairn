## What's new

A new **Calendar** view for scheduling tasks by due date — see what's overdue at a glance and drag tasks to reschedule them.

### Features

- **Calendar view (`⌘4`)**: A project-scoped calendar that lays out task cards by their due date, with **Month** and **Week** layouts and prev / next / today navigation. Available from the sidebar (per-project), the topbar tabs, and the view-visibility toggle in Settings.
- **Drag to reschedule**: Drag any task onto a different day to change its due date — an optimistic update that persists and is fully undoable. Powered by `@dnd-kit` (the same engine as the Kanban board).
- **Overdue tray**: A banner at the top of the calendar lists every past-due task in `--danger` styling. Drag a task out of the tray onto a day to reschedule it.
- **Unscheduled tray**: A collapsible tray lists tasks with no due date. Drag one onto a day to schedule it; drag a dated task back onto the tray to clear its due date.
- **Day detail modal**: Packed days show a "+N more" affordance that opens a modal listing every task due that day. Clicking a task opens its full card detail.

### Changes

- **Calendar styling**: Day cells fill their full grid track (continuous column separators top-to-bottom), today gets a soft accent wash plus an AA-compliant accent pill, out-of-month days recede into the background, and task chips use per-priority dot colours (urgent / high / medium / low) for clearer scanning in both light and dark themes.

### Fixes

- **Agent file tree stays fresh**: The Agent view's file tree cached each folder's contents and never re-read them, so files created externally (e.g. by the agent or a terminal command) never appeared. The tree now re-reads a folder on every expand, gained a manual refresh button, and auto-refreshes when the Git panel's status poll detects a change in the working-tree file set (including new untracked files).


### Tests

- **Calendar pure-logic unit tests** (`calendar-utils`, `calendar-dnd`):
  - `buildMonthGrid` — fixed 6-week (42-cell) grid for stable height, Sunday-start padding, in-month / out-of-month flagging, and a single "today" cell.
  - `buildWeekGrid` — 7 Sunday-start cells with correct today marking.
  - `bucketByDate` — overdue / scheduled / unscheduled split, same-day grouping, and overdue tasks kept out of the day buckets.
  - `resolveDateDrop` — set-due-date on day drop, clear on unscheduled-tray drop, no-op on same-day / already-unscheduled / invalid drop targets.
