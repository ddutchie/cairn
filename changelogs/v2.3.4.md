## What's new

A new **Calendar** view for scheduling tasks by due date — see what's overdue at a glance and drag tasks to reschedule them. Plus **External Tools**: connect the AI chat and agent to remote MCP servers and any HTTP API, and build a working tool from a plain-English description with the new AI Tool Builder.

### Features

- **External Tools — MCP servers & custom HTTP services**: A new **Settings → Tools** section lets you connect the AI to remote **MCP servers** (SSE or streamable-HTTP) and expose any **HTTP API** as a single tool. Each tool has a per-row enable toggle and a **Test connection** button. Once enabled, attach tools per-project from the project **Overview → Tools** panel, so each project only sees the tools it needs. Enabled, attached tools become available to both the AI chat and the coding agent automatically.
- **AI Tool Builder ("Build with AI")**: Describe an endpoint in plain English and the builder probes it live (in the background), figures out the auth scheme and response shape, trims the response to just the useful fields to save tokens, and saves a ready-to-review tool. The endpoint probing and any credentials stay in the main process — they're never sent to the AI model, which only ever writes secret *placeholders*.
- **Secure credential storage**: API keys and tokens for external tools are stored in your operating system's keychain (Keychain / DPAPI / libsecret) via Electron `safeStorage` — never in the database or in plain text. The app only ever knows whether a secret is set, and decrypts it solely when making the actual request.
- **Calendar view (`⌘4`)**: A project-scoped calendar that lays out task cards by their due date, with **Month** and **Week** layouts and prev / next / today navigation. Available from the sidebar (per-project), the topbar tabs, and the view-visibility toggle in Settings.
- **Drag to reschedule**: Drag any task onto a different day to change its due date — an optimistic update that persists and is fully undoable. Powered by `@dnd-kit` (the same engine as the Kanban board).
- **Overdue tray**: A banner at the top of the calendar lists every past-due task in `--danger` styling. Drag a task out of the tray onto a day to reschedule it.
- **Unscheduled tray**: A collapsible tray lists tasks with no due date. Drag one onto a day to schedule it; drag a dated task back onto the tray to clear its due date.
- **Day detail modal**: Packed days show a "+N more" affordance that opens a modal listing every task due that day. Clicking a task opens its full card detail.

### Changes

- **Calendar styling**: Day cells fill their full grid track (continuous column separators top-to-bottom), today gets a soft accent wash plus an AA-compliant accent pill, out-of-month days recede into the background, and task chips use per-priority dot colours (urgent / high / medium / low) for clearer scanning in both light and dark themes.

### Fixes

- **Agent file tree stays fresh**: The Agent view's file tree cached each folder's contents and never re-read them, so files created externally (e.g. by the agent or a terminal command) never appeared. The tree now re-reads a folder on every expand, gained a manual refresh button, and auto-refreshes when the Git panel's status poll detects a change in the working-tree file set (including new untracked files).
- **All view toggles in one place**: The "Agent view" and "AI Chat view" visibility toggles were duplicated under AI & Chat settings, separate from the other view toggles in General. They now live alongside Board, Calendar, Idea Flow, Knowledge Graph, and Insights in **General → Views**. AI & Chat settings keep only the genuinely AI-specific "Enable inline AI" flag.


### Tests

- **External Tools unit tests** (`secure-store`, `mcp-client`, `custom-services`, `external-tools`, `tool-builder`, plus DB queries):
  - Secure store: secret ref/placeholder detection, encrypt/store/resolve round-trip, plaintext never written to disk, unresolved-ref dropping, and per-tool secret cleanup.
  - MCP client + services: tool-name namespacing round-trips (`mcp__…` / `svc__…`), OpenAI def conversion, GET/DELETE-vs-POST/PUT request shaping, and `responseKeys` deep-filtering.
  - Scoping: global + per-project attachment resolution (including explicit-disable suppression) and prefix-based execution routing.
  - AI Tool Builder: optimizer port (results/items-aware key extraction, `NOISY_KEYS` denylist), parameter synthesis, auth-hint parsing, and finalize validation.
- **Calendar pure-logic unit tests** (`calendar-utils`, `calendar-dnd`):
  - `buildMonthGrid` — fixed 6-week (42-cell) grid for stable height, Sunday-start padding, in-month / out-of-month flagging, and a single "today" cell.
  - `buildWeekGrid` — 7 Sunday-start cells with correct today marking.
  - `bucketByDate` — overdue / scheduled / unscheduled split, same-day grouping, and overdue tasks kept out of the day buckets.
  - `resolveDateDrop` — set-due-date on day drop, clear on unscheduled-tray drop, no-op on same-day / already-unscheduled / invalid drop targets.
