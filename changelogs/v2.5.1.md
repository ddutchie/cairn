## What's new

### Fixes

- **Codebase re-index now picks up indexer improvements automatically.** The codebase symbol index caches each file by a content hash (size + modified time), so a file whose contents hadn't changed was skipped on re-index. After the indexer itself was upgraded (e.g. to capture exported `const`/`type`/`interface`/`enum` symbols), previously-indexed files kept their old symbols and a plain re-index couldn't repair them. The cache key now includes a parser version, so bumping the parser invalidates every file on the next re-index. Also added a `force` option to the `codebase_reindex` tool to drop the cache and re-parse everything on demand.
