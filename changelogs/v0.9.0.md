# v0.9.0 — Notes overhaul

A focused release on the notes experience: richer markdown rendering, image support, subfolder organisation, and a set of small UX tweaks that make the editor faster to navigate.

---

## Images

Paste or drag an image file directly into a note — it uploads into the workspace's `assets/` folder and inserts a Markdown image reference automatically. Images are stored content-addressed (SHA-256 filename), so duplicate files are deduplicated on disk. External `https://` images are also rendered inline and wrapped in a link that opens in the system browser.

A **Show Assets Folder** button in **Settings → Data** reveals the folder in Finder.

## Subfolders

Notes can now be organised into subfolders. The Notes sidebar grows a collapsible folder tree — create a folder with the `+` button next to any folder node, or move an existing note via **Move to folder** in the note's action menu.

Subfolders are stored as slash-separated paths (e.g. `research/papers`) in the database and as frontmatter in the `.md` file. The file watcher tracks notes recursively to depth 10.

AI agents (chat and MCP) can also create notes in subfolders — pass `folder: "path/to/folder"` to `create_note` or `ensure_note`.

## Markdown extensions

### Callouts

Obsidian-style callout blocks are now rendered:

```
> [!note] Optional title
> Content with **formatting**.

> [!warning]+ Collapsible callout
> Starts open, can be collapsed.

> [!danger]- Collapsed by default
> Click to expand.
```

Eight types with distinct icons and colours: `note`, `info`, `tip`, `warning`, `danger`, `success`, `question`, `quote`.

### Math (KaTeX)

Inline and display math via KaTeX:

- Inline: `$e^{i\pi} + 1 = 0$`
- Display: `$$\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}$$`

Display math blocks show a **source toggle** — hover the block and click the `</>` button to switch between the rendered formula and the raw LaTeX. Click the `Σ` button to switch back.

### Highlights

`==text==` renders as a highlighted mark, using the workspace accent colour at 22% opacity.

### Footnotes

Footnote references (`[^1]`) and definitions are fully linked — clicking a superscript scrolls to the footnote definition at the bottom of the note, and clicking `↩` scrolls back to the reference. The footnotes section is rendered with a visual separator and subdued styling.

## Sidebar

Clicking a collapsed project in the sidebar now expands it automatically, in addition to making it active. Previously a second click on the chevron was needed.

## MCP binary

A standalone `cairn-mcp` binary is now built alongside the app (`npm run build:mcp-binary`). This lets the MCP server run without a local Node.js install — useful for connecting Cairn to Claude Desktop or other MCP hosts on machines where Node is not in the PATH.

## Technical

- **DB migration v8**: `folder TEXT NOT NULL DEFAULT ''` on `notes`
- **`asset://` Electron protocol**: content-addressed image serving from `<workspace>/assets/`; `img-src` CSP updated to allow `asset:` and `https:`
- **Unified pipeline**: single post-katex rehype pass replaces three separate full-tree traversals, ~16% faster on large notes
- **27 pipeline benchmark tests** added (`markdown-pipeline.bench.test.ts`) covering each stage individually and end-to-end across small / medium / large fixtures
- **`INSERT OR IGNORE` + `UPDATE` upsert** in `upsertNoteFromFile` eliminates a race condition that could produce `UNIQUE constraint failed` errors during file-watcher sync
