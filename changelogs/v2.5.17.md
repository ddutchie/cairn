## Fixes

- **Image attachments now reach every chat model.** The vision gate previously guessed vision support from a hardcoded model-name allow-list (`gpt-4o`, `claude-3`, `gemini`, …), so images were silently stripped for any model whose id didn't match — including custom OpenAI-compatible endpoints (e.g. a local proxy serving `playground-claude-opus-4-8`) and vision-capable on-device models like Gemma. Cairn now always forwards attached images to the model and lets it decide — a non-vision model simply says it can't see them. Images also now flow through the subagent dispatch path, which previously dropped them.
- **Changing the chat model now applies to the very next message.** A background re-hydrate (triggered after write-tool turns and on every `db:changed` event) could read a stale backend settings cache and silently revert a model you'd just picked — the "have to clear chat twice for the new model to take effect" bug. Refresh hydrates now prefer the live in-memory config over the cache, so a model change sticks immediately.
- **Qwen/DeepSeek/GLM-style reasoning now shows in the thinking panel on desktop.** The desktop agent stream parsers only read `delta.reasoning`, but these models emit their thinking on `delta.reasoning_content` (and `message.reasoning_content` on non-streaming responses). Cairn now reads `reasoning_content ?? reasoning` in the chat loop, the coding-agent loop, and the subagent dispatch loop — matching mobile — and strips `reasoning_content` before re-sending assistant messages (re-sending it triggers 400s on DeepSeek).
- **Token counting no longer inflates the context ring for image attachments.** The prompt-token breakdown stringified the whole multimodal message — including the image's base64 data URL — so a single screenshot could add tens of thousands of phantom tokens to the "conversation" segment and spike the context gauge. Images now contribute a flat per-image estimate; only the text parts are tokenised (matching mobile).
