## Features

- **Choose your accent color.** A new accent-color picker — in both Settings → General and the topbar Quick Settings popover — offers ten curated presets: Sage Moss (the new default), Cairn Teal, Terracotta, Amber Gold, Obsidian Indigo, Slate Blue, Rust Coral, Deep Plum, Pine Green, and Copper Bronze. Each preset ships a separate light- and dark-theme trio tuned for Cairn's warm-neutral surfaces, and every foreground pairing meets WCAG AA contrast. Your choice persists across restarts, follows theme switches (including System auto light/dark), and even tints the launch splash. The mobile app gets the same ten presets from a new Appearance screen (opened from the Projects tab, right of Sync). The default accent is now Sage Moss instead of the old Obsidian-style indigo.

## Fixes

- **Task-list checkboxes inside table cells now render as real checkboxes.** GFM only parses inline content inside table cells, so a checklist crammed into a cell — `- [ ] install - [x] configure`, or a multi-line cell using `<br>` like `- [ ] Create account<br>- [ ] Verify email<br>- [x] Set password` — previously showed the raw `[ ]` / `[x]` text. Cells now recover every checkbox token (optionally dash-prefixed, whether separated by spaces or `<br>`), rendering each as a checkbox in document order. In the note preview they're clickable and toggle the underlying markdown source; in read-only contexts (card previews, chat, PDF) they render as static checkmarks.
- **PDF export renders table checkboxes too.** Desktop PDF inherits the fixed note-preview DOM automatically; mobile PDF now recovers cell checkboxes as print-safe checkbox glyphs (with in-cell line breaks preserved), matching desktop.
