# v1.5.0

## What's new

### Features

- **Obsidian Vault Compatibility** — Cairn is now fully compatible with Obsidian vaults! You can point a Cairn workspace directly to any existing Obsidian vault. Cairn works seamlessly side-by-side with Obsidian without interfering with vault configuration, ensuring full interoperability for markdown notes and frontmatter.

- **Eliminated `notes/` Directory Nesting** — To achieve standard Obsidian folder layout compatibility, the intermediate `notes/` subdirectory has been dropped. All workspace projects are now placed directly at the workspace root (e.g. `<workspace-root>/<project-slug>/`), and note files reside directly within their respective project subfolders. The background file watcher has been updated to watch the root workspace folder, excluding Obsidian config directories (`.obsidian/`, `.trash/`) and metadata databases.

- **Smooth Workspace Migration System** — Introduced a robust, extensible migration runner with a beautiful UI modal (`MigrationModal`) that triggers automatically upon startup if a workspace requires layout migrations. The first migration (`v1.5-drop-notes-dir`) safely migrates existing non-vault workspaces by copying notes and projects from `notes/<project>` to `<project>` at the root, verifying file integrity, and cleanly deleting the old folders. App interactions are safely blocked while migrations run, and progress is visually displayed with progress bars.

- **Obsidian-style Double Bracket Embeds (`![[image.png]]`)** — The note rendering pipeline now supports rendering Obsidian double-bracket image embeds natively. A custom `remarkObsidianEmbeds` Remark plugin parses syntax like `![[image.png]]` and `![[image.png|width]]` and converts them into standard HTML image nodes with absolute widths. This is supported in both the markdown note preview and note editor reading mode.

- **Vault-Aware Asset Upload and Paste** — Pasting or uploading images in note editors now respects the Obsidian environment. In vault mode, images are saved into the workspace's `attachments/` folder (or the custom folder path configured in `.obsidian/app.json`) using their original filename instead of generating random hashes. The editor automatically inserts `![[filename.png]]` syntax rather than HTML `<img>` elements.

- **Intelligent `asset://` Resolution Protocol** — The custom `asset://` secure protocol has been redesigned to support vault structures. It dynamically scans candidate paths (root `assets/`, `attachments/`, custom Obsidian attachment folders, and recursive lookup fallback) to find matching media files, caching their physical filesystem paths to guarantee fast, sub-millisecond future load times.

- **Preservation-focused Frontmatter Merging** — Note synchronization between SQLite and markdown files now utilizes a merge-not-replace frontmatter strategy. Modifying note content or attributes in Cairn preserves other existing YAML frontmatter fields (such as Obsidian aliases, tags, or dates) untouched.

### Fixes

- **Migration modal state updates** — Fixed a lint warning (`Calling setState synchronously within an effect`) in `MigrationModal.tsx` by setting the initial state to `"none"` and updating inside an asynchronous microtask, ensuring stable, ripple-free render cascades.

### Changes

- `electron/migrations.ts` — new file; defines the core migration types, `WorkspaceMigration` registry, `.cairn-migrations.json` persistence tracker, and the `v1.5-drop-notes-dir` migration.
- `src/components/layout/MigrationModal.tsx` — new file; responsive React modal with glassmorphism aesthetics, handling migration progress indicators, logs, and blocking interactions until done.
- `src/lib/markdown/pipeline.tsx` — added `remarkObsidianEmbeds` Remark plugin to parse double-bracket `![[filename]]` embeds.
- `electron/notes-files.ts` — updated workspace directory resolution to drop the intermediate `/notes` segment; updated directory synchronization logic to ignore folders like `.obsidian`, `assets`, and `attachments` when scanning for projects; updated save logic to merge frontmatter YAML values instead of replacing them.
- `electron/file-watcher.ts` — updated watcher workspace path target to the root workspace directory; added exclusions for `.obsidian/`, `.git/`, `.trash/`, and other non-project database files.
- `electron/ipc/handlers.ts` — added IPC handlers for `app:checkMigrations` and `app:runMigration`; removed unused `crypto` import; updated `uploadAsset` IPC call to dynamically parse `.obsidian/app.json` for attachment settings, write assets to the specified folder with original filenames, and return Obsidian `![[...]` embed strings when inside a vault.
- `electron/preload.ts` — registered new IPC channels `checkMigrations`, `runMigration`, and listener bridge `onMigrationProgress`.
- `electron/lib/protocol.ts` — refactored the secure `asset://` handler to resolve files sequentially through candidates (e.g. `assets/`, `attachments/`, custom folders, and workspace-wide lookup) and added a fast-path cache.
- `src/components/notes/note-editor.tsx` — imported and added `remarkObsidianEmbeds` to the preview and reading mode markdown pipelines.
- `src/components/notes/NoteMarkdownPreview.tsx` — added `remarkObsidianEmbeds` support.
- `src/components/notes/markdown-editor.tsx` — updated the image paste handler to detect Obsidian double-bracket Syntax (`![[`) and insert it as raw text directly into the editor instead of wrapper markup.
- `src/app/page.tsx` — imported and placed the `<MigrationModal />` at the root layout wrapper.
- `electron/mcp/db.ts` — updated internal database project path structure to drop the `/notes` subfolder suffix.
- `electron/obsidian-compat.test.ts` — new file; includes comprehensive automated test coverage for migration runners, frontmatter merging, `asset://` file path resolution strategies, and watcher folder exclusions.
