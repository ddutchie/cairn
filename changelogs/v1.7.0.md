# v1.7.0

## What's new

### Features
- **Rebranded Local LLM Integration (`localllm`)** — Replaced the legacy, macOS-restricted `apple-fm` (Apple Foundation Models) provider with a fully cross-platform `localllm` engine. The new engine routes all on-device inference to a local `llama-server` process running offline.
- **Automated Native Prebuilt Engine Downloader** — Implemented an automated 1-click native `llama-server` binary downloader. It dynamically checks system platform and architecture, fetches the latest stable release asset from `ggml-org/llama.cpp`, unpacks tar.gz/zip archives natively, recursively grants execution permissions to all files, and clears macOS Gatekeeper quarantine tags to prevent loading crashes.
- **High-Speed Global CDN Mirror** — Added a 1-click CDN toggle that alternates engine and GGUF model download requests between official sources (GitHub/Hugging Face) and high-speed regional mirrors, bypassing network constraints in restricted regions.
- **Self-Healing XML & Tool Completion Parser** — Engineered a self-healing output parser for streaming local completions. It intercepts and repairs malformed or incomplete tool execution JSON blocks generated by smaller quantized local models, ensuring robust tool execution.
- **Zero-Config Startup State Migration** — Integrated an automatic Zustand state migration block. Upon app startup, existing user settings with `apple-fm` are seamlessly translated to `localllm` configuration variables to guarantee smooth backward compatibility.
- **Interactive Default Startup Model Toggle (Star Indicator)** — Built a persistent "Set Default" Star toggle next to downloaded models in settings. Users can now explicitly choose which model weights are automatically booted when starting a chat without manually loading a model first.

### Fixes
- **Verified Gemma 4 E2B Q4 GGUF Model Downloader** — Fixed a failing model download URL by rerouting Gemma-4 E2B Q4 downloads to Unsloth's verified repository on Hugging Face, resolving redirect crashes and 404 errors.
- **Local Server Health Check Protocol Mismatch** — Corrected health check execution from HTTPS to standard HTTP, preventing socket hang-up errors during local server status checks.
- **dyld Dynamic Library Loading Issues** — Configured prebuilt macOS engine installers to recursively apply executable rights to both `llama-server` and its helper dynamic library (`libllama-server-impl.dylib`) before boot.

### Changes
- `electron/lib/llama-server.ts` — Added `default-model.json` persistence, manifest tracking, model locking, automated downloader, and Unsloth routing for E2B Q4 quants.
- `electron/lib/local-llm.ts` — Created rebranding module to replace dynamic koffi FFI bridges with offline llama-server routes.
- `electron/ipc/handlers.ts` — Registered rebranded `"ai:localLLMStatus"` and `"llama:server:setDefault"` handlers.
- `electron/ipc/chat.ts` — Updated streaming completions route to execute `streamLocalLLMChat` with self-healing XML tool parsers.
- `electron/ipc/pi-agent.ts` — Migrated coding agent guard checks to `"localllm"`.
- `electron/preload.ts` — Swapped `appleStatus` bridge signature with `localLLMStatus`, exposed `setDefault` method, and updated status typings.
- `src/store/slices/ui.ts` — Updated typing definition for AI provider values.
- `src/store/index.ts` — Added backward-compatibility startup migration translator.
- `src/components/settings/AISettings.tsx` — Rendered interactive Star toggle button to choose/change default local model in the local model manager list.
- `src/components/onboarding/StepAISetup.tsx` — Updated illustrations and onboarding copy to highlight the new offline Local Engine.
- `src/components/chat/chat-panel.tsx` — Renamed title badges to refer to Local Gemma 4 (Llama).
