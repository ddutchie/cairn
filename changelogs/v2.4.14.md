## What's new

### Improvements

- **See exactly what differs in a sync conflict.** When the same note was edited on two devices at once, the conflict-resolution dialog used to show the current note and the conflicted copy as two plain blocks of text side by side — leaving you to spot the difference by eye. It now shows a unified diff: lines only in the conflicted copy are highlighted green (+), lines only in your current note are highlighted red (−), and unchanged lines are dimmed, with a summary of how many lines changed. If the two bodies are actually identical (the conflict was in metadata only) it says so instead of showing an empty diff. Applies to both desktop and mobile.
- **Multi-word search now finds what you mean.** Search (⌘K, the notes filter box, and the AI assistant's note/task search) previously required your whole query to appear as one exact phrase — so "auth flow" would miss a note titled "Authentication flow" or one saying "flow for auth". It now matches when every word in your query appears somewhere in the title or body, in any order. Single-word and exact-phrase searches are unchanged.

### Fixes

- **Custom header secrets stay masked.** In the Tools settings (custom HTTP service headers), a header value marked as a secret is now masked as a password field as soon as it's flagged — previously a placeholder secret was shown in plaintext until it had been saved as a stored `secret://` reference.
- **Note preview checkboxes update when the note changes.** Task-list checkboxes in the read-mode note preview (including checkboxes inside table cells) now reflect the current note content live — e.g. after a sync updates the note or you toggle another box — instead of keeping the state they had when first rendered.
- **Correct heading anchors for styled headings.** A heading containing inline markdown (e.g. `# **Release** notes`) now gets the right anchor id, derived from its plain text, so its table-of-contents link scrolls to it correctly instead of to a malformed `[object Object]`-based id.
- **Deleted files show the right colour in the Agent Git panel.** A file deleted but not yet staged (git status `" D"`) now shows in the danger colour like a staged deletion, instead of the generic "changed" colour.
- **Failed model download no longer sticks.** In the on-device Llama server console, if a model download fails to start, its progress row now clears instead of hanging on a stuck "downloading" state.
- **Live download speed in the model list.** The on-device model download list now shows the current download speed from live progress events rather than falling back to a stale value.

### Accessibility

- The Agent Git panel's changed-file rows and section headers are now keyboard-operable (focusable, toggle with Enter/Space), and their hover actions also appear on keyboard focus.

### Under the hood

- Scoped the codebase-symbol folder filter's `LIKE` pattern to escape the path separator, so folder-scoped codebase searches match descendant files correctly on Windows (where the separator is also the SQL `LIKE` escape character); the symbol search query now also escapes `%`/`_` in the query text so they match literally.
- Task-card embedding reindex now treats an explicitly-empty id list as "no cards" (returns nothing) rather than falling through to re-embedding every active card in the workspace; only an omitted argument selects all cards.
- Split the note + task embedding queries out of the 1,950-line database-query module into their own file. Purely internal reorganisation — every existing import keeps working via a re-export; no behaviour change.
- Also split the codebase semantic-indexing queries (files, symbols, relations, and the Architecture/Module-Map rollups) into their own file, the same way. Purely internal; no behaviour change.
- Split the Tools settings panel (MCP servers + custom HTTP services) — its header editor, connection tester, OAuth sign-in control, add/edit forms, list row, and per-server tool checklist now live in their own files, sharing one helpers module. Purely internal; the settings screen looks and behaves exactly the same.
- Split the Agent's Git panel — its file-section, changed-file row, inline-diff renderer, and git status-mapping helpers now live in their own files. Purely internal; the Git view looks and behaves exactly the same.
- Split the note editor's read-mode preview renderer (the ReactMarkdown component overrides — links, wikilinks, callouts, math, checkboxes, tables, footnotes, etc.) into its own module. Purely internal, with the same referential-stability guarantees preserved; the rendered note looks and behaves exactly the same.
- Split the AI settings panel's on-device Llama server console (model manager, server controls, engine installer/updater, download progress) into its own component. Purely internal; the settings screen looks and behaves exactly the same.
- Fixed the mobile unit tests failing in CI with `[TSCONFIG_ERROR] Tsconfig not found`. The mobile test project's transform was walking up to `mobile/tsconfig.json`, which `extends "expo/tsconfig.base"` — a path that only resolves when `mobile/node_modules` is installed, whereas CI installs only the root dependencies. The Vitest mobile project now uses a self-contained inline tsconfig for its transform, so mobile logic tests run in CI without needing the Expo toolchain installed. No runtime behaviour change.
