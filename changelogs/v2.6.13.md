## What's new

### Added

- **Paste a writing style directly.** In Settings → Writing Style you can now skip the guided questionnaire entirely: hit **Paste a style directly** and drop in a style guide you already have (or had another AI write). A one-click **Copy prompt** button gives you a ready-made prompt for ChatGPT/Claude etc. that produces a guide in Cairn's canonical 12-section format, so the pasted result is immediately usable by chat and the coding agent. Pasting writes the guide verbatim (no LLM call needed), and the same view lets you **Optimize** it into the canonical format or **Generate a cheat sheet** before saving.

- **A "set up your writing style" prompt appears when the AI can't match your voice.** When chat or the coding agent calls `get_user_writing_style` and no writing style is configured yet, a chip appears under the tool call with a **Set up writing style** button that pops the setup modal directly — so you know why the draft doesn't sound like you yet and can fix it in one click.

### Fixed

- **Writing-style wizard usage now shows up as "Writing style" in the Usage view.** The streaming generation path (the default in the guided wizard) previously recorded no usage row at all — it's now attributed with the `writing-style` source like the one-shot fallback, instead of being missing or bucketed under Chat.

- **Dropdowns inside modals no longer close the modal.** A `Select`/dropdown open inside a dialog (e.g. the context picker in the Writing Style wizard) is portaled to the page root, which Radix treats as "outside" the dialog — so clicking it used to dismiss the whole modal. The dropdown now opts into the same `data-dialog-portal` escape hatch the date/time pickers use, so interacting with it (or clicking outside it, back into the modal) keeps the modal open.

- **The provider & model picker no longer traps you while the model list is open.** The model dropdown (a modal Radix menu by default) disabled pointer events and trapped focus on everything outside its own content — so with it open you couldn't click a different provider or click away without the whole picker closing. It's now non-modal, so clicking outside dismisses the model list and the provider list stays clickable.
