# v0.4.4

## Mermaid diagram rendering

Notes and AI chat messages now render ` ```mermaid ` fenced code blocks as SVG diagrams.

- Mermaid is loaded dynamically (no SSR penalty, no bundle size impact until first use)
- Theme-aware: diagrams use Cairn's dark/light colour tokens (`--surface`, `--border`, `--text-primary`) so they match the active theme automatically
- Invalid diagram syntax shows a styled inline error block rather than throwing
- Supported diagram types: flowcharts, sequence diagrams, class diagrams, ER diagrams, Gantt charts, pie charts, and all other Mermaid v11 types

## Mermaid full-screen popout

- Hovering a diagram reveals an expand button (top-right corner)
- Clicking opens a full-screen modal: blurred backdrop, centred panel, SVG rendered at unconstrained size (fixed `width`/`height` attributes stripped so large diagrams fill the panel)
- Close with `Escape` or clicking the backdrop

## Syntax-highlighted code blocks

Fenced code blocks now render with VS Code-style syntax highlighting via `lowlight` (highlight.js grammars, tree-based, no DOM manipulation).

- Two colour palettes: One Dark-inspired for dark mode, softer muted tones for light mode — both using the same token categories (keywords purple, strings green, numbers orange, functions blue, comments grey)
- Header bar with language label (top-left) and Copy/Copied button (top-right)
- 37 languages bundled: JS/TS, Python, Go, Rust, SQL, Bash, JSON, YAML, CSS, HTML, C/C++, Java, Ruby, PHP, Swift, Kotlin, and more
- Unrecognised languages fall back to unstyled monospace
- Inline code (backtick, no language) is unchanged
- Applied in both note read pane and AI chat messages

## Table of contents + heading anchors

Notes in read mode now support document navigation.

- **Floating TOC panel** — auto-generated from h1/h2/h3 headings, appears to the right of the content column when there is sufficient room. Hidden when the note has fewer than 2 headings.
- **Heading indentation** — h2 is indented, h3 is further indented and slightly smaller
- **Anchor links fixed** — existing notes with manual TOC links like `[Section](#section-name)` now scroll correctly within the note pane. Previously the `#hash` href had no matching element to land on.
- **Scroll behaviour** — both TOC clicks and inline anchor clicks use `scrollIntoView({ behavior: "smooth" })` scoped to the note's overflow container, not the page

Heading slug algorithm matches GitHub's convention (lowercase, spaces → hyphens, non-alphanumerics stripped) so manually authored anchor links in existing notes work without any content changes.

## TOC overlap fix

The TOC panel uses a `ResizeObserver` + `getBoundingClientRect()` to measure actual DOM positions rather than a fixed pixel threshold. It hides with a 150ms fade the instant the gap between the content column's right edge and the TOC's left edge drops below 24px — pixel-exact regardless of sidebar state or window size.

## Note preview width

Content column in read mode widened from 680px to `max-w-4xl` (896px). Title input and tag bar updated to match. Reduces the amount of empty space on wide windows.

## Windows title bar fixes

- **Colour mismatch fixed** — the native min/max/close button overlay was using the window `backgroundColor` (`#0d0d0d` / `#f5f4f1`) instead of the rendered title bar's `--surface` colour (`#141414` / `#ffffff`). The overlay now matches the `TitleBar` component exactly.
- **Height clipped 1px** — `height: 40` overshot by 1px due to Windows' 1px window border. Reduced to `height: 39` in both `createWindow()` and `setTitleBarOverlay()` so the `border-b` line beneath the title bar is no longer clipped.
