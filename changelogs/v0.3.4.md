# v0.3.4

## What's new

### Archived cards — view and restore
Archived cards no longer disappear silently. Each column now shows an "N archived" toggle below its card list. Expand it to see archived cards and restore any of them with a single click.

### Archived notes — view and restore
Archived notes are now accessible in the notes list. An "N archived" section appears at the bottom of the list when there are archived notes. Expand it to restore notes or permanently delete them.

### Overview column pills deep-link to the board
Clicking a column pill in the project overview now navigates to the board **and** scrolls directly to that column, which briefly highlights so you can spot it immediately.

### Note editor — word count and reading time
The editor header now shows a live word count and estimated reading time (words ÷ 200, minimum 1 min). Both update as you type and reset when switching notes.

### Project due date warning in sidebar
Projects with a `dueDate` now show a small coloured dot next to their name in the sidebar. Amber = due within 7 days, red = overdue. Hover for the exact date or days remaining.

### Card quick-create with due date and assignee
The inline add-card form in each column now has optional Assignee and Due Date fields below the title, so time-sensitive cards don't require opening the detail modal immediately after creation.

### Card — move to different project
Card detail now has a "Move to project" action in the sidebar. Expand it to pick any other project in the workspace — the card lands in that project's Backlog column.

### MCP + Chat — update_task tool
`update_task` was already implemented in the MCP executor but was missing from the tool registry advertised to agents, and was entirely absent from the in-app chat. Both are now fixed: the tool is listed under `write` in `get_cairn_context` for both surfaces, and the chat executor can update title, description, priority, dueDate, columnId, and assignee.

## Fixes / internals
- `restoreCard` and `restoreNote` store actions added (set `archivedAt` to `null` in SQLite and `undefined` in state)
- `getArchivedColumnCards` and `getArchivedProjectNotes` selectors added to store
- `cairn:scroll-to-column` custom event wired between overview and board
- Column wrapper refs tracked in `board.tsx` for programmatic `scrollIntoView`
