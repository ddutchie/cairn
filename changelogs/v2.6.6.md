## What's new

### New

- **Usage view — see every LLM and agent call.** A new **Usage** tab (next to Insights in the sidebar) records tokens, cost, and request volume across chat, the Cairn Agent, subagents, automations, and the one-shot AI features (PRDs, commit messages, PR descriptions, explain-code, Idea Flow summaries, compaction, tool builder). A daily chart overlays input and output tokens (with a Cost / Requests view and hover breakdowns), a "by model" list shows where spend is going, and a per-call history table lists the exact time, model, input/output/reasoning tokens, provider, and cost of each request. Cost is shown whenever the provider reports it (e.g. NeuralWatt) or it can be recovered from your account credits; when neither is available the cost is estimated from models.dev pricing (marked with a `~`). Token data is always recorded, locally, on every call.
- **Calls are labelled with your saved provider's name.** Usage rows now use the name you gave the provider (e.g. "Go", "DeepSeek") instead of a generic slug, resolved from the active endpoint.
- **Switch providers from the chat quick-settings.** The in-chat settings popup now has a Provider dropdown listing your saved providers (plus on-device Llama), so you can change endpoint right where you're chatting instead of jumping to Settings.
- **The database no longer balloons after heavy changes.** Cairn now switches its SQLite database to incremental auto-vacuum and reclaims free space automatically — so embedding reindexes, compaction, and cleared history no longer leave the `.db` file stuck at a large high-water mark; it stays close to its real size.
