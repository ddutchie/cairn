## What's new

### Bug fixes

- **Column `+` button** — was permanently invisible due to a missing `group` class on the column header; now appears on hover as intended
- **Workspace name in Settings** — changes were silently discarded; now saves on blur or Enter
- **Note title saves debounced** — was firing an IPC call on every keystroke; now batched at 300ms like content saves
- **Search debounced** — `searchAll` now runs at 150ms instead of synchronously on every keystroke
- **Active project persisted** — the last-opened project is now restored across app restarts instead of always defaulting to the first project
- **Project delete dialog** — replaced `window.confirm()` with the app's own modal, consistent with the data-reset dialog in Settings

### Column management

- **Rename** — double-click any column name to edit inline, or use the `···` context menu → Rename
- **Delete** — `···` menu → Delete column; confirmation dialog shows the card count before you commit

### Tag management

- New **Tags** section in Settings — lists all workspace tags with inline rename (click the name) and a delete button
- Deleting a tag cascades: removes the tag from all notes and cards automatically

### Search improvements

- **Deep-links** — clicking a note result now opens that specific note in the editor; clicking a task result opens the card detail modal directly
- **Grouped results** — results are now split into Notes and Tasks sections with headers

### Overview deep-links

- Clicking a note anywhere in the project overview (recent notes, pinned notes, activity feed) opens it directly in the editor
- Clicking an in-progress card or any card in the activity feed opens its detail modal

### AI Chat

- **New chat button** — pencil icon in the chat panel header creates a fresh thread for the current project, without losing history
- **`update_task` tool** — the AI can now update a task's title, description, priority, due date, and column (previously it could only create or move tasks)
- **Token limit raised** — `max_tokens` increased from 1,024 to 4,096 per round
- **More tool rounds** — maximum tool-call rounds raised from 5 to 8 for complex multi-step operations

### MCP server (5 new tools)

| Tool | Description |
|---|---|
| `update_task` | Update task title, description, priority, due date, column, tags |
| `update_project` | Update project name, description, status, priority |
| `delete_project` | Delete a project and all its data, including `.md` files |
| `list_notes` | List all notes in a project (no search query needed) |
| `list_tasks` | List all tasks in a project grouped by column |

### Settings

- **MCP → Project context** — the project-scoped config snippets panel (system prompt, Claude Desktop config, Cursor config, project IDs) is now visible in Settings → MCP Server

### Performance

- `savePersisted` is now debounced at 200ms — rapid mutations (e.g. typing) no longer trigger a localStorage write on every character

### Keyboard shortcuts

All shortcuts listed in Settings → Shortcuts are now implemented:

| Shortcut | Action |
|---|---|
| `⌘N` | New note (when in notes view) |
| `⌘1` | Switch to Overview |
| `⌘2` | Switch to Notes |
| `⌘3` | Switch to Board |
| `⌘\` | Toggle sidebar |
| `⌘K` | Open search |
| `⌘/` | Toggle AI chat |
