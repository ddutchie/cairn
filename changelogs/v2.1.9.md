## What's new

### Features

- **Markdown rendering on board cards**: Kanban card descriptions now render as full markdown — checkboxes, lists, code blocks, tables, callouts, math, and wikilinks all render inline. Long descriptions are collapsible: a "More"/"Less" chevron toggle expands the content with a scrollable `max-h-48` container, and collapsing resets scroll to top so re-expanding starts at the beginning.

- **Links panel in graph detail**: Selecting a note node in the knowledge graph now shows a **Links** section with two subsections — **Wikilinks** (outgoing `[[Title]]` links from the note body plus graph-derived wikilink edges, deduplicated) and **Semantic** (embedding-cosine-similarity edges sorted by weight, each showing a similarity percentage). Clicking any link navigates to that note node in the graph. The section is collapsible and pinned to the bottom of the panel.

- **Linked tasks & notes panels**: The graph detail panel now shows collapsible **Linked tasks** (for note nodes) and **Linked notes** (for card nodes) sections, listing the actual linked items by name with click-to-navigate. Previously these were just plain-text counts in the meta fields.

- **Open in Board deep-links**: Clicking "Open in Board" from a graph card node now scrolls to and highlights the containing column, and opens the card detail modal — matching the existing `cairn:open-card` and `cairn:scroll-to-column` deep-link pattern used elsewhere in the app. Events are deferred via `requestAnimationFrame` so the board mounts its listeners first.

- **Badge size variant**: `Badge` component now supports a `size="xs"` variant with tighter padding (`px-1 py-0.5`) and `text-[0.643rem]` for compact UI areas like kanban card tags.

### Fixes

- **DatePicker portal clicks no longer dismiss dialogs**: The date picker popover is portaled to `document.body`, making it a sibling of `RadixDialog.Content`. Two issues were fixed: (1) Radix modal dialogs set `document.body.style.pointerEvents = "none"` while open, so the portaled popover inherited `pointer-events: none` and silently swallowed every click/hover — fixed by adding `[data-dialog-portal] { pointer-events: auto }` to `globals.css` (CSS spec allows descendants to override a parent's `pointer-events: none`). (2) `DialogContent.onInteractOutside` now reads the real target from `event.detail.target` (not `event.target`, which is wrong for Radix's `CustomEvent`) and calls `preventDefault()` when the target is inside a `[data-dialog-portal]` element. The `onInteractOutside` prop is destructured before `{...props}` spread so consumer handlers can't clobber the override.

- **Consistent markdown rendering everywhere**: Five components that had hand-rolled or incomplete markdown pipelines now use the shared `NoteMarkdownPreview` component (same full pipeline as the note editor's read mode — callouts, math, wikilinks, embeds, code blocks, tables, GFM checkboxes, mermaid, footnotes):
  - `MDPreviewPanel.tsx` — was a ~70-line duplicate of the full pipeline
  - `AboutSection.tsx` — was bare `ReactMarkdown` with only `remarkGfm` + `remarkBreaks`
  - `board.tsx` archive view — was rendering `card.description` as plain text
  - `card-detail.tsx` — was using the chat renderer (`MarkdownContent`), causing inconsistencies with the board card
  - `AiSummaryNode.tsx` — was rendering AI summaries as plain text with `whitespace-pre-wrap`

- **Graph snippet length increased**: Note and card snippets in the knowledge graph increased from 120 → 600 characters so more content is visible.

### Changes

- **Kanban card tags moved to bottom**: Tags are now rendered at the bottom of the card (below due date / blockers / linked notes), separated by a divider border. Up to 3 tags are shown with a `+N` overflow indicator. Tags use the new `xs` badge size for a more compact look.

- **Graph detail panel layout restructured**: The panel body is now a flex column — title and meta fields are `flex-shrink-0`, and the markdown snippet uses `flex-1 min-h-0` so it stretches to fill all available vertical space between the header and the pinned collapsible sections (linked tasks, linked notes, links). Three collapsible sections are pinned at the bottom above the footer, each with expand/collapse chevron toggles defaulting to expanded.

- **`data-dialog-portal` attribute added** to `DatePicker` popover and `WikilinkPicker` so the dialog's `onInteractOutside` handler and CSS `pointer-events` override can target portaled children generically.
