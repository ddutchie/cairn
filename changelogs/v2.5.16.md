## Improvements

- **Point Cairn at an existing Obsidian vault and see your notes.** When you open a workspace folder (or copy a folder of notes into an existing workspace), Cairn now auto-creates a project for every top-level folder that contains notes and imports the `.md` files inside — recursively, preserving subfolder paths. Previously the scan only imported notes into projects you had already created by hand, so pointing at an Obsidian root imported nothing. Loose `.md` files sitting directly in the vault root are gathered into a catch-all project named after the vault folder. Dot-folders (`.obsidian`, `.git`, `.trash`) and infra folders (`assets`, `attachments`) are skipped, and re-scanning is idempotent.
- **Onboarding recognises Obsidian vaults.** If the folder you pick contains a `.obsidian` directory, the workspace step now shows an "Obsidian vault detected" hint, and once the vault is imported the wizard shows a summary of the projects it found — with note counts — instead of asking you to create your first project from scratch.
- **Change a project's code directory from Project Settings.** The code-directory folder — previously only editable from the project Overview — is now a first-class field in Project Settings, including the Settings gear inside the Agent view. Type or paste a path, click **Browse** to pick a folder, or **clear** it entirely, without leaving the coding workspace. The control appears both in the Agent view's Project Settings modal and the main Settings → Project section.

## Fixes

- **Editing a note no longer renames its file (protects Obsidian wikilinks).** Obsidian resolves `[[wikilinks]]` by filename, and vault notes often have a `title` property that differs from the filename. Cairn now keeps a note's on-disk filename stable when you edit its content, tags, pin state, or links — and when importing a vault note whose title differs from its filename. Only an explicit **rename** changes the filename, and that already rewrites inbound wikilinks in your other notes. Previously a title edit (or the first save of an imported note) could silently rename the file and break every link pointing at it.
- **Copying a notes folder into a workspace now creates a project live.** The file watcher discovers the new folder, creates its project, and imports the notes without needing a restart.
- **Architecture tab header no longer overlaps on narrow windows.** In the Agent view's Architecture tab, the stats (files / symbols / references) and the Map · Matrix · Graph · List view toggle plus Reindex button could collide and render on top of each other when the panel was narrow. The header now wraps cleanly — the toolbar drops onto its own line instead of overlapping the stats — and grows in height as needed.
