## What's new

### Features
- **See what sync did, and undo a deletion from another device.** Device Sync now records how each incoming change was resolved — applied, kept as a conflict copy, or overridden by a deletion — and Settings → Sync shows the recent decisions by note title, with a click through to the note itself. If another device deleted a note, it's listed with a one-tap **Restore** that brings it back everywhere: the restore proves it saw the deletion, so peers accept it instead of re-deleting the note on the next sync. Restore is deliberately not offered where it couldn't work — tombstones whose content never reached this device, notes whose project was also deleted, conflict copies, and deletions you performed yourself — and any refusal says why rather than silently doing nothing.
- **Preview and filter existing Markdown vaults before import.** Onboarding now scans selected Obsidian vaults and Markdown folders without modifying them, shows the projects and note counts Cairn will adopt, and lets you exclude top-level folders before any frontmatter is written. Templates, attachments, infrastructure folders, and `*.excalidraw.md` files are skipped automatically; folder choices persist for startup scans and file watching. The preview also explains Cairn's first-touch frontmatter and recommends a backup or git commit first.
- **Recent automation runs on the Overview.** A new "Recent runs" section on each project's Overview surfaces the latest automation run results — status, relative time, errors, and clickable chips for notes/tasks the run created (parsed from the run's scratch JSON). Section is project-scoped (workspace-scoped automations stay on the Automations view), collapsible like the other Overview sections, and links out to the Automations view for full history. Backed by a new `db:automation:recentRuns` IPC channel + `listRecentAutomationRuns` query joining `automation_runs` to `automations` so no N+1 lookup is needed per row.
- **Board priority filters + search.** The Board now has a persistent filter toolbar (KG-style): tap the Urgent/High/Medium/Low chips to show only those priorities (multi-select, toggle off to clear), and a search box to filter cards by title or description. Filters combine, a match count shows in the toolbar, and a clear button resets everything. ⌘F still focuses search.
- **Connector-aware automations.** Automations can now use your attached MCP servers and HTTP services. Community recipes can declare the connectors they need (`requires: [{kind, name}]`), and picking one pre-fills the form with those requirements. When a connector-aware automation runs, the project's attached external tools are offered to the agent, and every external call is gated behind the approval inbox by default — external side effects are never auto-approved, even in Auto mode.
- **Pick connectors for custom automations.** The New/Edit Automation form now has a "Connectors (optional)" section listing your installed connectors — tick the MCP servers and HTTP services an automation may use, and it gets their tools on each run (with external calls still waiting for your approval).
- **Required-connector guard at setup.** The recipe browser shows per-connector chips (installed and attached / installed but not attached / not installed) against the selected project, plus a clear warning and an "Open connector browser" shortcut when something is missing. The form and automation cards show a "needs: Linear, GitHub" badge so dependencies are visible at a glance.
- **Ask for keys at connector install.** Installing an OAuth connector (e.g. Linear, GitHub, Slack) from Browse Community now prompts you to sign in right after install, instead of leaving the connector disabled with no hint. Header-based API keys were already prompted at install and stay stored in your OS keychain.
- **Community recipes that use connectors.** New recipes in the cairn-community catalog — Linear sprint digest, GitHub PR digest, and Slack daily summary — fetch read-only summaries from their connector and draft a note (they never edit external state).
- **Collapsible Project Overview.** Every section on the Overview can now be collapsed by clicking its header, and each project remembers which sections you folded (sections start expanded). Collapsed sections keep a one-line widget — Health shows a thin stacked bar of your per-column task percentages plus notes/done/open/overdue counts, Due soon/Pinned/Notes/Activity show counts, and Tools shows how many are attached. Expand again with a click.
- **Triage-first Overview order.** The page now leads with what needs attention — pending approvals, then due/overdue tasks, health, and content — with per-project tools moved to the bottom. The stats and Board snapshot fold into Health (one column view instead of three), pinned notes are now compact accent-bar rows matching Recent notes, and a new always-visible gear in the header opens a Project Settings dialog (icon/description/status/priority, the agent code directory, and a shortcut to manage tools & connectors).
- **Health de-duplicated.** The Health section dropped its overlapping stat cards and duplicate column views. It now shows a slim notes/overdue meta line, a single "Task flow" list (proportional bars + counts + the top card titles per column, clickable to jump to that column), and the priority grid — no more columns or counts shown twice.

### Fixes
- **Deleted notes stay deleted after stale devices reconnect.** Device Sync now keeps durable delete metadata outside note rows and requires exact proof that a device observed a deletion before allowing it to revive the note. Higher wall-clock timestamps alone can no longer resurrect stale content; rejected divergent edits are preserved as conflict copies, and legitimate edits made after observing a delete still restore normally.
- **First-time sync no longer makes old rows look newly edited.** Device Sync backfill now preserves each row's existing logical timestamp. Legacy rows without one use a deterministic timestamp derived from their saved update or creation time, so reconnecting an old installation cannot leapfrog a real deletion with a freshly minted wall-clock value.
- **Deep-linking a note now reveals it in the sidebar.** Clicking a note from the Overview (pinned/recent) or a search/backlink result now expands any collapsed folder that contains it, scrolls the note into view in the Notes hierarchy, and clears an active filter/tag so it's not hidden.
- **Reasoning-model recovery for on-device chat.** Local reasoning models (Qwen3.5-9B, Bonsai-27B, partly Gemma-4) can spend the entire token budget on chain-of-thought and return an empty answer with `finish_reason: "length"`. The on-device chat path now ships a `max_tokens` floor of 4096 (matching the cloud path) and, when a reply comes back empty due to length exhaustion, makes one continuation call asking the model to emit only the final answer. If that still yields nothing, the captured reasoning is surfaced as the reply instead of a blank message — so reasoning models can finally be shipped as on-device options without intermittently returning empty replies.
- **Connector-aware automations skip cleanly when a connector is missing.** A run whose required connector is no longer installed or attached is recorded as skipped with a connector-specific message instead of silently running without its tools.
- **Vault import never fails open.** If the saved import-exclusion file is corrupted or conflict-marked, Cairn keeps using the last valid exclusions (or halts the scan) rather than importing folders you previously excluded. The file is now written atomically.
- **Unread-notification bell wobbles in the title bar.** Instead of a cramped count badge, the bell fills solid accent and gives a gentle swing every few seconds while you have unread notifications — the count still lives inside the Notifications panel.
