## What's new

### Features
- **Connector-aware automations.** Automations can now use your attached MCP servers and HTTP services. Community recipes can declare the connectors they need (`requires: [{kind, name}]`), and picking one pre-fills the form with those requirements. When a connector-aware automation runs, the project's attached external tools are offered to the agent, and every external call is gated behind the approval inbox by default — external side effects are never auto-approved, even in Auto mode.
- **Pick connectors for custom automations.** The New/Edit Automation form now has a "Connectors (optional)" section listing your installed connectors — tick the MCP servers and HTTP services an automation may use, and it gets their tools on each run (with external calls still waiting for your approval).
- **Required-connector guard at setup.** The recipe browser shows per-connector chips (installed and attached / installed but not attached / not installed) against the selected project, plus a clear warning and an "Open connector browser" shortcut when something is missing. The form and automation cards show a "needs: Linear, GitHub" badge so dependencies are visible at a glance.
- **Ask for keys at connector install.** Installing an OAuth connector (e.g. Linear, GitHub, Slack) from Browse Community now prompts you to sign in right after install, instead of leaving the connector disabled with no hint. Header-based API keys were already prompted at install and stay stored in your OS keychain.
- **Community recipes that use connectors.** New recipes in the cairn-community catalog — Linear sprint digest, GitHub PR digest, and Slack daily summary — fetch read-only summaries from their connector and draft a note (they never edit external state).
