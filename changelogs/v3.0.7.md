## What's new in Cairn 3.0.7

### Fixed

- **Chat history now actually persists on Windows.** The session-durability logging added in 3.0.6 surfaced a real bug it didn't fix: bundling the `koffi` native module (used transitively by the session-persistence backend) into `main.js` broke its runtime lookup of its own prebuilt binary, so every session flush failed with "Cannot find the native Koffi module" and chats vanished on reload. `koffi` is now kept external to the Electron bundle, like the other native deps (`scripts/compile-electron.js`).
