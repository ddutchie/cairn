## What's new in Cairn 3.0.6

### Fixed

- **Knowledge Graph now refreshes when your data changes.** Previously the graph only loaded when you opened the Graph or Insights views and then went stale — edits to notes, tasks, and tags left it frozen until a manual refresh, and the chat assistant's graph context was silently empty unless a graph view had mounted first. The graph now reloads (filters preserved) on every database change and loads on first read (`src/store/slices/graph.ts`, `src/hooks/useGraphData.ts`, `src/app/page.tsx`).
- **Destructive confirms are inline two-step buttons instead of blocking system dialogs.** Deleting archived tasks, uninstalling plugins, discarding git changes, updating community commands, and clearing AI chat threads now arm in place ("Confirm delete?") and auto-disarm after a few seconds — no more OS modal stealing focus (`src/components/ui/confirm-button.tsx`).
- **Chat-history write failures are no longer silent.** Session flushes were best-effort and swallowed every error, so a machine where transcripts could never reach disk (empty sessions folder, chats lost on restart) showed no symptom until relaunch. Every flush failure is now recorded to the persistent debug log with a consecutive-failure count, the app probes session-folder writability at boot, and a health accessor exposes the streak for diagnostics (`electron/cordis/plugins/session-durability.ts`, `electron/main.ts`). Also fixed two session-path strips that only recognised forward slashes, so Windows `\sessions` roots resolve correctly (`electron/cordis/run-cordis-loop.ts`, `electron/ipc/chat-session.ts`).

### Changed

- **Theme-correct text on accent surfaces in dark mode.** Buttons, pills, and chat bubbles rendered on the accent colour now use the theme's accent-foreground token instead of hardcoded white, matching the design system's own button variant (most visible with green accent presets on the default dark theme). Adds a `--danger-fg` token used by the danger button (`src/app/globals.css`, `src/components/ui/*`).
