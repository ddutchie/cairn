## What's new

### Added

- **AI requests now use the OpenAI Responses API when it's available.** Chat, the coding agent, one-shot generation (writing style, PRDs, commit messages, explanations), context compaction, and subagent mode all route through `/v1/responses` for providers that support it — OpenAI and Azure OpenAI today, plus anything else that speaks the format. Every other provider keeps using Chat Completions, with a one-time capability check per connection that caches the result and falls back automatically (including a live downgrade if a provider drops the endpoint mid-session). This keeps Cairn on the wire format OpenAI and the Open Responses ecosystem are standardising on.
- **Condensed reasoning summaries in the Thinking panel.** When a model returns a reasoning summary, the collapsed "Thought process" panel now shows a concise summary instead of a truncated slice of the raw trace — expand it to read the full reasoning. (Requires a model that emits summaries, e.g. OpenAI GPT-5.x.)
- **Image and PDF attachments work over the Responses API**, translated to the native image/file input items so vision and document questions behave the same on Responses-based providers.

### Changed

- **Note bodies are no longer stored twice.** The derived `content_text` mirror column (a stripped plain-text copy of every note, kept for search and embeddings) is gone from the `notes` table on both desktop and mobile. Search now uses an FTS5 full-text index (`notes_fts`) over title + body — faster keyword matching with prefix support — and plain text for embeddings, snippets, and knowledge-graph relationships is derived on read via `stripMarkdown` from the single authoritative `content`. Because the column no longer exists, it also disappears from the Device Sync oplog payload, roughly halving the note-body size replicated to paired devices.

### Fixed

- **Writing Style settings now wrap instead of overflowing on narrow windows.** The Manage row's action buttons (Edit / Regenerate, Paste style, Regenerate cheat sheet, Clear) previously sat in a non-shrinking slot, so they clipped off the edge of the page rather than wrapping. The row now lets the buttons flow onto multiple lines when the settings pane is narrow.
- **A provider that drops the Responses endpoint mid-session is now handled gracefully.** If a provider 404s/405s `/responses` (or the probe mis-identified it), chat, the agent, subagents, one-shots, and context compaction automatically downgrade to Chat Completions and retry the request once instead of surfacing an endpoint error — matching the existing chat-loop behaviour across every caller.
- **The Thinking panel renders summary-only reasoning.** A model that returns a condensed reasoning summary but no raw trace (e.g. GPT-5.x) now shows the panel with the summary as its content, on both live and persisted messages.
