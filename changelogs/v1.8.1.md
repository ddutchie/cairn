## What's new

### Features
- **Mobile Companion Service**: Introduce local-network mobile access to Cairn. Scan the QR code or enter the display PIN in Settings to securely access, read, and write notes, manage kanban boards, and chat with AI agents directly from your mobile browser:
  - **Local PIN Authentication**: Secure single-use PIN entry with persistent sessions (`mobile-sessions.json`), so mobile clients stay logged in across app updates.
  - **Automated Configuration Syncing**: AI providers, model endpoints, and API credentials sync instantly from the desktop's main process configuration cache to client browsers on load.
  - **Native PDF Export & Sharing**: Exporting notes on mobile generates a print-layout PDF and presents it directly in the native device **share sheet** (utilizing the Web Share API), falling back to browser downloads.
  - **HMR WebSocket & Proxy Support**: Upgraded dev server route handling and WebSocket proxy pipes to support non-GET routes and Hot Module Reloading (HMR) seamlessly on remote mobile browsers.
- **Mobile Responsive Layouts**: Designed and optimized responsive CSS flex grids across all panels:
  - Sidebar folds into a touch-dismissible slide-over drawer with a backdrop overlay.
  - Breadcrumbs auto-truncate and show a clean viewport-selector dropdown at phone sizes.
  - Chat panel expands to occupy `100vw` / `100dvh` full-screen modal mode, hiding manual resize drag handles.
  - Project Overview tiles stack into 1-column lists with description word-wrapping to prevent layout stretch.
  - Settings navigation converts to a swipable horizontal category strip.
  - Notes view hides notes list panel while reading/writing a note to maximize viewport width.
- **Touch Interaction Parity**: Optimized touchscreen controls specifically for mobile clients:
  - **Kanban Board — Touch Drag-and-Drop**: Added `TouchSensor` (250 ms hold-to-drag, 5 px tolerance) alongside the existing `PointerSensor` so cards and columns can be dragged on mobile without conflicting with native scroll. Added `touchAction: none` to card and column drag-handle elements so the browser cedes pointer ownership to the DnD layer immediately on hold.
  - **Idea Flow — Mobile Interactions**: Long-press on canvas (350 ms, cancelled by movement) opens the add-node picker at the touch position, replacing the desktop right-click context menu. Single tap on a node opens the edit modal directly on touch devices, replacing the desktop double-click that did not fire reliably on mobile. Minimap is automatically hidden on touch screens to maximize viewport estate.

### Fixes
- **Mobile Access Settings**: Resolved a recursive infinite call stack overflow loop in settings initialization where generating the mobile access PIN would repeatedly load and save configurations before writing them to disk.
- **Kanban Board — Drop Zone Positioning**: Archive and Delete drop zones are now anchored to the card scroll area rather than the outer board container, fixing the issue where they rendered behind the Board/Archive tab bar during a drag.
- **Chat — Mobile Live Updates**: Notes and task cards created by the AI chat assistant now trigger a `db:changed` broadcast to all mobile SSE clients, so the board and notes views refresh automatically without a manual page reload.
- **Text Input Double Outline**: Scoped the global `:focus-visible` CSS rule to exclude `input`, `textarea`, and `select` elements, and added an explicit `outline: none` on their `:focus` state. Focus indication on text inputs now comes solely from the border colour change and the parent container's ring where present.
