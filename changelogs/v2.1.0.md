## What's new

### Features

- **Architectural Deep Dive & Cleanup**: A full-codebase architectural review identified and resolved the biggest sources of complexity, duplication, and dead code. Spanning 6 phases (P0–P5), this release removes **4,000+ lines of duplicated or dead code**, fixes **142 silently-accumulating type errors**, and gives the Electron main process + MCP server a single source of truth for SQL.

### Fixes

- **CI Never Type-Checked Electron Code**: The `type-check` job in CI ran `tsc --noEmit` against the renderer-only `tsconfig.json`. The entire `electron/` codebase (main process, IPC handlers, MCP server, DB layer) was never type-checked in CI — 142 pre-existing type errors were silently accumulating. All 142 are now fixed, and CI runs `npm run type-check:all` covering both surfaces.

- **`IpcHandler` Type Was Too Strict**: `IpcHandler` was typed `(event: unknown, ...args: unknown[]) => unknown`. By contravariance, every handler with a destructured typed second arg was rejected — 80 of the 142 errors. Made the type **generic** over the args tuple, and split event typing into `IpcHandleHandler` (`IpcMainInvokeEvent`) and `IpcOnHandler` (`IpcMainEvent`) so `event.sender` accesses are properly typed.

- **Stale AGENTS.md ABI-Boundary Claim**: The docs claimed "mcp-server.ts uses inlined SQL only due to Node ABI boundary." This was **fictional** — `mcp/tools/codebase.ts` already imported `* as q from "../../db/queries"` and worked. The only ABI-sensitive operation is `new Database(dbPath, { nativeBinding })`. Corrected the docs and consolidated all MCP SQL onto the shared query helpers.

- **Inconsistent Priority Colours Across Canvases**: 4 separate definitions of priority colour mappings existed across the 7 analytics canvases — `TimelineCanvas` said `low → var(--success)` while the shared `PRIORITY_COLOR` said `low → var(--text-tertiary)`. All canvases now use the single shared definition.

- **Dead `PRIORITY_WEIGHT` Export**: Was defined in `analyticsUtils.ts` but never imported anywhere — 3 canvases re-defined the same concept locally. Now properly used by `SankeyCanvas`; added `PRIORITY_SORT_ORDER` for ascending-sort canvases.

- **Real Type Bugs Surfaced by Electron Type-Check**: `PiAgentPromptRequest.config` was missing the `provider` field. `CachedConfig.agentConfig` was missing `maxSteps?`/`temperature?` (now also persisted in the agent save branch). `GraphNode.meta` in `graph-queries.ts` was missing `isArchived?`. All fixed.

- **AI Summary Node Validation**: `db:flow:node:summarize` only checked node existence but not whether the node was of type `ai_summary` — any node could receive AI summary data. Now validates type before proceeding.

- **Cross-Flow Edge Creation**: `create_idea_flow_edge` only checked that the target node existed, without verifying it belonged to the same flow as the source — edges between different flows were possible. Now checks `flow_id` match.

- **Phantom Edge IDs in MCP**: `create_idea_flow_node` reported edge IDs to the response array without verifying that `q.createFlowEdge` actually persisted the edge (could be skipped by `INSERT OR IGNORE`). Now only includes confirmed edge IDs.

- **`tasks.ts` `dueDate === null` Branch**: Returned the stale result from `clearCardDueDate` instead of the fully-updated card after the subsequent `updateCard` call. Also bypassed blocker-clearing logic when moving to a done column. Both fixed.

- **Project Delete Order**: `db:project:delete` deleted `.md` files *before* the DB row — if the DB operation failed, the files were already gone. Reversed to DB-first so files survive for recovery on failure.

- **Project Create Not Transactional**: Default column creation in `db:project:create` performed multiple separate DB writes without a transaction — a mid-loop failure could leave some columns created. Now wrapped in a transaction.

- **DatePicker Popover Clipping**: The DatePicker popover was positioned `absolute` inside containers with `overflow-y-auto` (e.g. the card-detail modal sidebar), causing it to be clipped. Radix Dialog's `transform: translate(-50%, -50%)` also created a containing block that mispositioned `position: fixed` descendants. Fixed by rendering the popover via `createPortal` to `document.body` with viewport-aware positioning and `z-[100]`.

- **PDF Export Resource Leak**: `BrowserWindow` used for PDF rendering was not destroyed if `loadURL` or `printToPDF` threw. Wrapped in `try/finally` so the window is always destroyed. Also replaced synchronous `fs.writeFileSync` with async `fs.promises.writeFile`.

- **`config-cache.ts` Silent Data Loss**: `maxSteps` and `temperature` fields were added to the `CachedConfig.agentConfig` type but never persisted in the `saveCachedConfig("agent")` branch. Now written to the cache file.

- **`update_dashboard` Missing `updatedAt`**: Return payload was inconsistent with `create_dashboard` and other update tools. Now includes `updatedAt` from the note object.

- **`app:revealAssets` Wrong Folder**: Opened `assets/` but uploads go to `attachments/` (or the configured Obsidian folder). Fixed to use `attachments/`.

- **`useIpcErrorToasts` Timer Leak**: Evicted toasts had their timers left active, and the cleanup function only removed the event listener without clearing remaining timers. Both fixed.

- **`resolveAiConfig` Error Shape**: Returned a raw error object instead of using `err()` for `IpcResult<T>` consistency. Now wraps in `err()`.

- **Stale `mcp-native/` Folder**: Removed in v0.3.8 but the folder lingered with a stale binary. Deleted.

- **Orphaned Tests Giving False Confidence**: `GraphAIPanel.test.ts` (no matching component — renamed to `graph-ai-utils.test.ts`). `check-tool-parity.ts` + `tool-parity.test.ts` (referenced the removed `TOOL_DEFINITIONS` constant). All deleted or corrected.

- **Hardcoded Colours**: `connectionLineStyle` in flow-view used `#6366f1` instead of `var(--accent)`. `text-white` in several places replaced with `text-[var(--background)]`. Slash-alpha border syntax (`border-[var(--danger)]/30`) replaced with `color-mix` throughout. `text-[10.5px]` pixel font classes replaced with `text-[0.75rem]`.

### Changes

#### P0 — Hygiene & Safety Net

- **Dead code removed**: `mcp-native/` folder, `pkg-native/better_sqlite3_node25.node`, `scripts/check-tool-parity.ts`, `electron/ipc/tool-parity.test.ts`, stale `dist-*/mcp-server.js` artifacts.
- **Native binding setup reconciled**: `vitest-sqlite-shim.cjs` now honours `BETTER_SQLITE3_BINDING` (was hardcoded + ignored the env var). `vitest.config.ts` env var repointed at the correct `vitest-native/` (system-Node ABI, not `pkg-native/` which is Node 22 ABI).
- **`tsconfig.mcp.json` deleted**: Single-file config gave superficial coverage. `tsconfig.electron.json` now covers MCP too. Unused `@shared/*` path alias removed.
- **New npm scripts**: `type-check:electron` and `type-check:all` (renderer + electron). CI `type-check` job updated to run `type-check:all`.
- **esbuild target**: `node20` → `node22` (matches Electron 41 + pkg binary + rebuilt native binding).

#### P1 — SQL Consolidation (−216 LOC MCP, ~400 LOC algorithm dedup)

- All 7 MCP tool files (`tags`, `projects`, `dashboards`, `notes`, `tasks`, `flow`, `graph`) now delegate to `electron/db/queries.ts` + `electron/db/graph-queries.ts` instead of duplicating SQL.
- `mcp/db.ts:getSnapshot` delegates to `q.getFullSnapshot`.
- `queries.ts` gains a governance header documenting single-source-of-truth status.

#### P2 — IPC `handlers.ts` Decomposition (1054 → 170 LOC)

- Split the 1054-line god-file into 12 per-domain registrars + `result-helpers.ts`.
- Extracted inlined PDF HTML template → `lib/pdf-template.ts`.
- Extracted inlined OG scraper → `lib/url-metadata.ts`.
- `handlers.ts` is now a thin orchestrator calling `registerXxxHandlers()`.

#### P3 — Component Extractions

- **`<ModalShell>`** created on `ui/dialog.tsx`; 2 simplest modals migrated (`MoveNoteModal`, `DashboardApiModal`).
- **Shared `CairnRefChip`** + `CAIRN_NOTE_ACTIONS`/`CAIRN_TASK_ACTIONS` extracted from both message bubble files (was byte-identical duplication, ~155 LOC saved).
- **`editorTheme.ts`** moved from `agent/` → `lib/editor-theme.ts` (was a cross-feature dependency: notes importing from agent).
- **`chat-panel/` + `project-overview/`** folder refactors finished (`index.tsx` pattern).
- **`useIpcErrorToasts`** extracted from `page.tsx` inline hook → `src/hooks/useIpcErrorToasts.ts`; mid-file imports fixed.
- **`graphUtils.ts` deleted**; `resolveCssVar` merged into `analyticsUtils.ts` (4 graph helpers → 3).

#### P4 — Analytics Canvas Consistency

- 4 duplicate priority colour/weight definitions → 1 shared `PRIORITY_COLOR` + `PRIORITY_SORT_ORDER`.
- Dead props removed: `containerH?` on `CanvasTooltip`, `plotH` on `SvgTimeAxis`.
- `useRelativePointer(ref)` hook extracted — replaces 3 inline `getBoundingClientRect` calls.
- `useNow()` hook extracted — replaces 3 `Date.now()` calls that needed `eslint-disable react-hooks/purity`.
- `RidgelineCanvas` inlined tick grid → `<SvgTimeAxis>` (−22 LOC).
- Empty states unified: `TimelineCanvas` + `MatrixCanvas` now use `<CanvasEmptyState>`.

#### P5 — God-Component Splits

- **Types relocated**: `PiAgentMessage`, `PiSubagentMessage`, `TerminalSession`, `PiSessionSummary` moved from `store/slices/terminal-sessions.ts` → `types/index.ts` (688 → 620 LOC).
- **`app/page.tsx` cleaned**: `UpdateBanner` + `ErrorToasts` extracted → `layout/app-chrome.tsx` (410 → 341 LOC).
- **`project-overview/index.tsx` decomposed**: 10 sub-components extracted into `primitives.tsx` (69 LOC) + `sections.tsx` (214 LOC). Orchestrator: 664 → 427 LOC.
- **`card-detail.tsx` split**: sidebar metadata extracted → `card-detail-sidebar.tsx` (550 → 232 LOC, −58%).
- **`notes-view.tsx` split**: 5 sub-components extracted (`buildFolderTree.ts`, `NoteListItem.tsx`, `ArchivedNoteListItem.tsx`, `FolderTreeNode.tsx`, `FolderPickerDialog.tsx`). Orchestrator: 1033 → 532 LOC (−49%).
- **`SessionPane.tsx` split**: 6 components + 1 hook + 1 util extracted (`SessionMount.tsx`, `AIChatTab.tsx`, `AgentSessionTab.tsx`, `TerminalTab.tsx`, `AgentEmptyState.tsx`, `useAgentSessionActions.ts`, `sessionUtils.ts`). Orchestrator: 1009 → 269 LOC (−73%).
- **`flow-view.tsx` split**: pure functions extracted → `flow-utils.ts` (group membership, mappers, type registries, constants). 1019 → 862 LOC. Fixed hardcoded `#6366f1` → `var(--accent)`.
- **`note-editor.tsx` split**: 3 sub-components + helpers extracted (`BacklinksPanel.tsx` with `NoteTagBar`, `MDPreviewPanel.tsx`, `note-editor-utils.ts`). 1283 → 932 LOC (−27%).
