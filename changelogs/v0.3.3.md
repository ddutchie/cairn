## What's new

### Project overview redesign

The overview page has been rebuilt from scratch to surface actionable information rather than redundant counts.

**Stats row** — reduced from 4 cards to 3. "Total tasks" and "Completed" have been removed (the progress ring already communicates completion). The third stat is now **Overdue**, shown in red when any cards are past their due date. This is the most important number missing from the previous design.

**Board snapshot** — a new horizontal strip shows every column as a pill with its task count and the top 2 card titles. In Progress columns are highlighted in amber, Done columns in green. Clicking any pill navigates to the board. This replaces the "Recent Activity" feed, which was just a re-listing of tasks already visible on the board.

**Due soon** — a new section shows all open cards with due dates in the next 7 days, sorted by date. Each row has a priority stripe (red for urgent/high, accent for medium), the column name, and a chip showing the time status:
- Red `Xd overdue` — past due date
- Amber `Today` — due today
- Accent `in Xd` — due within the week

The section is hidden entirely when no cards have upcoming due dates.

**Pinned notes** — now rendered as 2-column cards with a snippet, relative timestamp, and tag chips. Previously indistinguishable from the regular note list.

**Recent notes** — plain compact list rows below pinned notes. The visual distinction between pinned and unpinned notes is now clear.

**Header** — priority badge removed. It was low-value metadata on an overview page where the status badge and progress ring already communicate project health. Project description is retained.

**Recent Activity removed** — it duplicated information already visible in the board snapshot and note list, and mixed task and note updates in a way that was hard to parse.
