## What's new in Cairn 3.0.14

### Added

- **The AI can search your earlier chats and coding sessions.** It can now look up past work in the same workspace (for example "what did we decide about the export format last week?") and read the exact messages it finds. It only sees sessions from the workspace you are in, and searching never asks for approval because nothing is changed.
- **Connected MCP servers can share their documents and guidance.** If an MCP server offers resources (files, docs, records), the AI can now list and read them, with the same approval prompt as that server's other tools. Guidance a server publishes for AI clients is now included in the AI's instructions, so connectors behave the way their authors intended.
- **Image-heavy chats keep working when a model's image limit is reached.** If a model refuses a request because the conversation carries too many images, the oldest images are replaced with a short placeholder and the request is retried, instead of the message failing.

### Fixed

- **Long chats compact before they hit the model's limit.** Auto-compaction measured how full a chat was against the model's whole context window, but part of that window is set aside for the reply. With the default settings (128K window, 32K reply), compaction would start at about 102K tokens, while the model already refused anything over about 96K, so long chats and coding sessions could fail with a "maximum context length" error before compaction ran. Compaction now starts at 80% of the space actually left for the conversation (about 76K tokens with the defaults), and adjusts when you change model or context settings.
- **Large tool calls no longer slow the app down while they stream.** When the AI wrote a big file or sent a long tool input, Cairn re-read the whole input from the start every time a new piece arrived, so the app could stall for seconds on large writes. It now reads the input once, when it is complete.

### Changed

- **Updated the agent runtime to DeepSeek Harness 0.1.7.** This brings the upstream fixes since 0.1.5. Workflows in coding sessions now run on the new, sturdier script runtime, and the jobs dock and reminders use the updated background-job and schedule services.
- **Saved sessions are upgraded to a new format the first time they open.** This is one-way: after opening a session in this version, an older version of Cairn can no longer open it.
- **Reminders set before this update are not carried over.** Reminders now live in their own store instead of the session history, so any reminder that was still pending needs to be set again.
