## What's new in Cairn 3.0.14

### Fixed

- **Long chats compact before they hit the model's limit.** Auto-compaction measured how full a chat was against the model's whole context window, but part of that window is set aside for the reply. With the default settings (128K window, 32K reply), compaction would start at about 102K tokens, while the model already refused anything over about 96K, so long chats and coding sessions could fail with a "maximum context length" error before compaction ran. Compaction now starts at 80% of the space actually left for the conversation (about 76K tokens with the defaults), and adjusts when you change model or context settings.
- **Large tool calls no longer slow the app down while they stream.** When the AI wrote a big file or sent a long tool input, Cairn re-read the whole input from the start every time a new piece arrived, so the app could stall for seconds on large writes. It now reads the input once, when it is complete.
