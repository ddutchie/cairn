# v0.5.0 — Quality & Polish

This release focuses on closing trust gaps, fixing real bugs, and closing the gap between "feels like a beta" and "feels like a tool I'd pay for."

## Bug fixes

- **Reset data now actually resets data.** `Settings → Data → Reset` previously only cleared localStorage. It now wipes all SQLite tables (workspaces, projects, notes, cards, columns, tags, threads, messages) before relaunching — a complete wipe as advertised.
- **Fixed MutationObserver leak on theme toggle.** Every switch to the `system` theme was adding a new `prefers-color-scheme` listener without removing the previous one. The observer is now properly stored and disconnected before re-creation.
- **Card priority bar no longer overlaps the card border.** Added `overflow-hidden` to the card container so the priority indicator is correctly clipped to the card's rounded corners. Widened from `w-0.5` to `w-1` for better readability.

## Kanban improvements

- **WIP limits are now enforced.** Columns with a `card_limit` set now show a `n/limit` badge in the header (amber when at capacity). The "Add card" button and footer action are disabled when the limit is reached, with a clear "WIP limit reached (N)" message.
- **Right-click context menu on cards.** Right-clicking any card opens a context menu with Open card, Archive, and Delete actions — no need to open the detail modal first.
- **Column delete dialog now shows accurate card count**, including archived cards.

## AI Chat improvements

- **Stop generation button.** A red stop (◼) button replaces the send button while the AI is streaming. Clicking it aborts both the in-flight HTTP request (main process) and the SSE stream, leaving any partial response visible.
- **Copy + Retry on messages.** Hovering any message reveals a copy icon. User messages additionally show a retry (↩) button to re-send the same content, disabled while generation is in progress.
- **Thread title editing.** Thread list items now show a pencil icon on hover. Click it to rename the thread inline; press Enter or blur to save, Escape to cancel.

## Notes

- **Delete confirmation dialog.** Deleting a note now requires confirmation, showing the note title and a warning that the action cannot be undone. Consistent with the existing project-delete pattern.

## Search

- **Type filter.** A pill toggle (All / Notes / Tasks) appears above search results, letting you narrow results to one type.
- **Project filter.** In multi-project workspaces a row of project pills appears; clicking one scopes results to that project. An active filter shows as a dismissible chip.

## Project overview

- **Edit project icon and description from UI.** A pencil button appears on hover next to the project name in the overview header. Clicking it opens an inline popover with an emoji field and description textarea — previously only settable via MCP or AI chat.

## Settings

- **Tag color picker.** The color swatch next to each tag in `Settings → Tags` is now clickable. A 14-colour palette popover lets you reassign any tag's color without deleting and recreating it.

## Dashboard theming

- All four built-in dashboard templates now use CSS custom properties throughout (`var(--background)`, `var(--text-primary)`, `var(--accent)`, etc.) so they correctly reflect the active theme including dark mode.
- `buildThemeStyle()` now sets `html, body { background-color: var(--background) }` so all AI-generated dashboards also inherit the theme background automatically.
