## What's new

### Light mode & theming

- Full light mode with a complete token set
- Three-way theme toggle: Light / System / Dark in Settings → General
- Theme persists across restarts — stored in both `localStorage` and a `theme.json` sidecar so the window background colour is correct before the app paints
- No flash on load: a `beforeInteractive` script applies the saved theme before React hydrates

### AI Chat persistence

- Chat history now survives app restarts — messages and threads are stored in SQLite
- History is loaded on first launch and preserved across `db:changed` refreshes

### Project management

- **Rename projects** — hover a project in the sidebar and click the `···` menu → Rename (inline input, confirm with Enter)
- **Delete projects** — same menu → Delete project (confirmation dialog, cascades to notes, tasks, columns, and `.md` files on disk)

### Note tags

- Assign tags to notes from a tag picker in the note editor, below the title
- Create new tags inline — type a name and press Enter or click the Create prompt
- Remove tags by clicking the `×` on any assigned tag badge
- Filter the notes list by tag — tag chips appear below the search box when any note in the project has tags

### Card due dates

- Overdue cards now show the due date in **red** with an "Overdue" prefix
- Cards due today show in **amber** with "Due today"
- Upcoming due dates remain neutral

### Reveal in Finder / Explorer

- Right-click (or `···` menu) any note → **Reveal in Finder** opens the `.md` file in Finder (macOS) or File Explorer (Windows)
