# v0.7.4 — Insights view & font scaling

## Insights view

A new dedicated **Insights** section splits the analytics canvases out of the Knowledge Graph into their own view, accessible via the sidebar or `⌘6`.

**New canvases**

- **Ridgeline** — PSR B1919+21-style joy plot of task activity over time. Per-row normalisation (each project scales to its own peak), scroll-wheel zoom (8%/notch), drag-to-pan, mode toggle (ridge / flat / 3d), zoom slider, and reset-to-data-range button.
- **Beeswarm** — Tasks plotted on a shared time axis, one lane per project. D3 force collision prevents overlap; dot radius encodes priority.
- **Bullet** — Project health dashboard: completion bars with urgency bands, overdue marker, today tick, and time-remaining indicator.
- **Sankey** — Task flow through the pipeline (Backlog → To Do → In Progress → Review → Done). Click a column node to open its task detail panel.

**Shared infrastructure**

- `analyticsUtils.ts` — `PRIORITY_COLOR`, `PRIORITY_WEIGHT`, `floorHour`, `floorDay`, `truncateName`, `CANVAS_PAD`, `HOUR_MS`, `DAY_MS`
- `analyticsHooks.ts` — `useContainerDims(ref)`, `useScopedData(nodes)`, `useFontScale()`
- `AnalyticsShared.tsx` — `<CanvasEmptyState>`, `<CanvasTooltip>`, `<SvgTimeAxis>`
- `graphUtils.ts` — `resolveCssVar()` consolidated from ForceGraphCanvas + RadialTreeCanvas

**Knowledge Graph simplified**

`KnowledgeGraphView` now contains only the **Force** and **Radial** layouts. All analytics canvases, their toolbar controls (table search, ridgeline mode/zoom, type toggles in table mode), and their imports have been removed. `GraphLayoutMode` narrowed to `"force" | "radial"`.

## Font scaling

A new **Font size** setting in **Settings → General** scales the entire UI.

- Five steps: **XS** (×1.0 · 14px), **S** (×1.1 · 15.4px), **M** (×1.2 · 16.8px, default), **L** (×1.3 · 18.2px), **XL** (×1.4 · 19.6px)
- `--font-scale` CSS custom property set inline on `<html>` by `applyFontScale()`
- Root `font-size: calc(14px * var(--font-scale))` drives all `rem`-based Tailwind classes (`text-xs`, `text-sm`, etc.) proportionally
- All 196 arbitrary-pixel Tailwind classes (`text-[10px]`, `text-[11px]`, etc.) converted to `rem` equivalents so they scale with the root
- SVG canvas `fontSize` attributes multiplied by `useFontScale()` (BulletCanvas, SankeyCanvas, RidgelineCanvas, BeeswarmCanvas, ForceGraphCanvas)
- Preference persisted to `localStorage` and restored on both web hydration and Electron hydration paths
