## What's new

Device Sync now keeps each workspace's changes in its own file, so several workspaces can share one sync folder without mixing.

### Fixes

- **Wikilinks render as clickable links again**: `[[Note]]` links in the note preview were showing as literal `<wikilink …>` text instead of inline, clickable links. They now render correctly (and dimmed when the target note doesn't exist).
- **Faster note preview**: The rendered note preview no longer re-parses and re-renders the whole document (including math) on every unrelated change elsewhere in the app — editing or syncing other notes no longer makes the open note's preview stutter.
- **Escape closes modals from anywhere**: Pressing Escape now closes the search panel (and the date picker and note tag picker) no matter where your cursor is — previously it only worked while the text field was focused.

### Workspace-scoped sync

- **Sync files are now per-workspace**: Each device now publishes its Device Sync changelog as `oplog-<device>-<workspace>.ndjson` instead of a single per-device file. The workspace identifier in the filename marks which *source* the changes belong to, so a device only reads the files for its own workspace and ignores the rest. This is the groundwork for the mobile app to hold several workspaces in one shared folder and switch between them, while keeping each workspace's data cleanly separated — one workspace's notes and tasks can never leak into another that happens to share the same folder.
- **Nothing to do on the desktop**: The change is transparent. Your desktop stays on its single workspace; on the first sync after updating it simply republishes its full state under the new filename. Older leftover sync files are ignored and can be removed from the folder if you want to tidy up.

### Under the hood

- The sync transport validates both the device and workspace identifiers in each filename and matches files by an exact workspace suffix (never by naively splitting the name), so identifiers containing dashes can't misroute a read. Legacy unsuffixed sync files remain readable for a smooth transition.

- Desktop and mobile now share a single implementation of the note section-splitter (used to chunk notes for semantic search) and the vector-similarity math, so the two apps index and rank identically and can't drift apart.
- The note preview's React component map is now referentially stable, so ReactMarkdown only re-parses when the open note actually changes — not on every store update. The markdown-pipeline benchmarks were also corrected to measure the real render path (they previously omitted `rehypeRaw` and the unknown-tag escaper), and a regression test now guards that `[[wikilinks]]` and callouts survive the escape pass as elements.
