## What's new

### New

- **See what's new in a note at a glance.** When a note is changed behind your back — by the AI assistant, the MCP server, or a sync from another device — the changed lines are now highlighted with a fading accent wash the next time you open it, and a banner at the top tells you how many lines changed since you last looked. The highlight works in both Write and Read (preview) mode — in preview it tints the affected paragraphs, headings and list items — and fades on its own after a few seconds, or you can dismiss the banner. Your own edits are never flagged.

### Improvements

- **Consistent resize-handle glow.** Every drag-to-resize divider in the app — the chat and preview panels, the notes sidebar, and the coding-agent file-tree / terminal splitters — now shares the exact same accent glow on hover, instead of each using a slightly different treatment.
- **Faster note rendering.** Notes without any math now render markdown roughly 40% faster (a large note drops from ~23ms to ~13ms) because the LaTeX/KaTeX rendering stack is skipped entirely when a note contains no `$` math — previously it ran on every note, math or not. Notes that do use math are unaffected. The plugin setup is also reused across re-renders instead of being rebuilt each time, and the chat assistant skips wikilink processing on messages that contain none (helps most while a reply is streaming in).
- **Lighter startup: syntax-highlighting grammars load on demand.** Cairn ships ~37 code-highlighting language grammars. These used to all load and register up front (whenever anything that could show a code block mounted), adding a fixed cost to startup and note rendering. Now each grammar loads lazily the first time a code block of that language actually appears — so opening a note with no code, or only JavaScript, no longer pays for Python, Rust, SQL and the rest. The first-ever code block of a given language may flash briefly unhighlighted while its grammar loads, then colours in. Applies to notes, chat, and the coding-agent diff viewer.
- **Snappier archived-tasks view.** The archive grid rendered the full markdown pipeline for every archived card's description just to show a 2-line truncated preview. It now shows a plain-text preview (like the board cards and note list already do), so opening the archive with many cards is noticeably faster.

### Fixes

- **The AI assistant no longer gets stuck retrying a failed note edit.** When the assistant tried to patch a note but the target text wasn't found (or the note id was stale), the tool replied with a terse message like "oldString not found" or "Note not found" that gave the model nothing to act on — so it would blindly repeat the exact same failing call over and over. The patch-note tool now returns actionable errors that steer the assistant to recover: re-read the note with `get_note` and copy the exact current text before retrying, search for the correct note id when the id is stale, or use `append_to_note` to add new content — and explicitly tells it not to retry the same call. The mobile assistant, which previously returned no reason at all on failure, now surfaces the same guidance.
- **Coding-agent pane resizing works after connecting a codebase.** Dragging the file-tree and terminal dividers in the agent workspace did nothing if the workspace was first opened without a code directory connected — the drag handlers were wired up before those panes existed and never re-attached. They now attach as soon as a codebase is connected.
