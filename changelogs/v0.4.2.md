# v0.4.2

## Windows improvements

- **Native title bar on Windows** — `titleBarStyle: "hidden"` + `titleBarOverlay` renders the OS min/max/close buttons at 40px height, colour-matched to the active theme. Theme switches update the overlay colour in real time via `win.setTitleBarOverlay()`.
- **Windows title bar layout** — app name is left-aligned with 12px padding; 138px right clearance keeps clicks reaching the native overlay buttons; no left clearance needed (no traffic lights).
- **NSIS installer: Program Files** — `perMachine: true` + `allowElevation: true` installs Cairn to `C:\Program Files\Cairn` with a UAC prompt instead of per-user AppData.
- **MCP config: Windows path fix** — Claude Desktop config on Windows now uses `{ "command": "cmd", "args": ["/c", "<path>"] }` so paths containing spaces (e.g. `C:\Program Files\...`) are not split by `cmd.exe`. OpenCode config (`command: [path]` array) was already safe.

- **Keyboard shortcuts panel** — Settings now shows `Ctrl+K`, `Ctrl+N`, etc. on Windows instead of the macOS `⌘` symbol.
- **Windows Toast notifications** — `app.setAppUserModelId("com.cairn.app")` called before `app.whenReady()` so MCP notifications appear correctly in the Windows Action Center with Cairn's identity.
- **Tray icon DPI** — Windows now loads `tray.ico` (multi-resolution 16/32/48 px) instead of a resized 16×16 PNG, keeping the tray icon crisp at 125% and 150% display scaling.
- **NSIS installer branding** — `installerIcon` and `uninstallerIcon` set to `build-resources/icon.ico` so the setup wizard shows Cairn's icon instead of the default electron-builder branding.
- **Workspace folder dialog** — removed macOS-only `message` property from `showOpenDialog`; description text moved into `title` so it renders on all platforms.
- **Font fallback** — `--font-display` stack now includes `"Palatino Linotype"` and `Palatino` before `Georgia`, giving Windows users a closer serif match to the macOS "New York" display font used on the onboarding screen.

## Internals

- `window.electron.platform` exposed in preload — renderer components read this to make platform-specific decisions without IPC round-trips.
- `registerAppHandlers` accepts optional `win?: BrowserWindow` — used by `app:setTheme` to call `setTitleBarOverlay` on Windows.

## New MCP tool: `import_note_from_file`

- Agents can now import a local file (e.g. `README.md`) as a note by passing just `{ projectId, filePath }`. The MCP server reads the file from disk — no need to inline large content as a tool argument.
- Title defaults to the filename without extension; pass `title` to override.
- Available in both MCP and the Cairn AI chat.
- Fixes the pain point where agents (Cursor, Claude) would time out or hit context limits trying to inline large markdown files as `create_note` content.

## MCP tools (README + settings panel updated)

- Tool list updated to 25 tools: added `list_notes`, `list_tasks`, `update_project`, `move_note`, `bulk_update_task_status`, `delete_project`, `import_note_from_file`.
- README table descriptions updated for `get_note`, `get_task`, `get_project_summary`, `update_note`, `update_task_status`.
