## What's new

### Features

- **Dynamic Chat Layout Morphing**: Added support for morphing the AI Chat panel between a right-docked Sidebar Mode and a centered, full-width Workspace Mode. Switch layouts smoothly with the header maximize/minimize controls.
- **Side-by-Side Context Previews**: Integrated a right-side Preview Pane inside the central chat view. Clicking note cards, task references, or cairn schema links in chat responses opens them side-by-side on the right for instant editing or previewing.
- **Direct Workspace Navigation**: Integrated "Go to board" and "Go to notes" shortcut actions in the preview pane header to jump straight to the parent section of the previewed card or note.

### Fixes

- **Unified Smooth Sidebar Transitions**: Refactored the left sidebar layout into a single, persistent `<aside>` element with hardware-accelerated CSS transition boundaries. Toggling the sidebar collapsed state now smoothly morphs the layout without unmounting DOM trees, keeping the main workspace and chat panel perfectly in sync.
- **Fluid Morphing Coordinates**: Resolved layout coordinate conflict during central chat transitions by dropping explicit CSS width properties in Sidebar Mode. The chat panel width is calculated dynamically from `left` and `right` constraints, preventing panel "side swapping" or snapping layout stutters.
- **Navigation Path Restorations**: Restored Overview (`⌘1`) and Notes (`⌘2`) navigation shortcuts as dedicated icons in the collapsed left sidebar to maintain quick navigation access when working in compact layout modes.
- **Header Action Button Shifts**: Locked the chat header Close (`X`) button's position across all panel layout states, preventing action button shuffling when transitioning between central and sidebar modes.
- **Underlying View persistence**: Configured the central chat layout to keep the previous content view (e.g. Overview or Notes) mounted underneath the chat panel rather than unmounting it. This completely resolves background screen flashes when morphing.
