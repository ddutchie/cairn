## What's new in Cairn 3.0.3

### Changed

- **LLM requests now identify as Cairn.** The DSH chat/agent loop (`dsh-llm`/`dsh-llm-pi-ai`) previously sent `User-Agent: deepseek-harness/...`; it now sends `cairn/<version> (+https://github.com/ddutchie/cairn)` via a shared `APP_IDENTITY` mutation (`electron/cordis/session-runtime.ts:11`, `electron/lib/cairn-identity.ts:1`). Direct one-shot calls (`electron/lib/llm.ts:272`, `electron/lib/llm-transport.ts:159`) also carry the same header, so providers and gateways can attribute traffic to Cairn.
