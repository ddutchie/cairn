## What's new

### Added

- **The coding agent can now track its work with a live todo list.** A new `todowrite` tool lets the agent create and maintain a structured task list for the current session (3+ steps triggers it; `pending` / `in_progress` / `completed` / `cancelled`, one `in_progress` at a time). Above the input a collapsible dock shows progress — a compact `[2/5 todos · current task]` summary line that expands to the full checklist. Todos persist per session and are restored when you resume one, and the dock updates live as the agent marks items done.

### Fixed

- **Tool calls with `<arg_value>`-style placeholder arguments no longer break the agent's turn.** Some models/gateways emit a template placeholder token (e.g. `<arg_value>`) where the opening quote of a string value should be, then dump the real content right after it — producing tool-call arguments that aren't valid JSON at all. The parser now recognises known placeholder tokens at a value-start position, substitutes the missing opening quote, and recovers the intended arguments (the model's own closing quote ends the value). The recovered arguments are canonicalised back into the conversation history, so the raw malformed string is never replayed to the provider — which previously caused the next request to fail with a 400 and the whole turn to stall.
