## What's new in Cairn 3.2.1

### Changed

#### Chat

- **Cairn's own tool calls look like connector calls.** Notes, tasks, projects, idea flow, writing style and the rest of Cairn's data tools now show as a "Cairn · action" card with labelled Arguments and Result panels, the same as MCP and HTTP service calls, instead of a bare chip with a raw JSON dump.
- **Tool calls show what changed.** Adding to your writing style shows the added line under its section; task updates list each field as `from → to`; note edits show a diff; idea-flow changes are summarised with the new ideas as chips; searches list their top hits. Writes open automatically and keep the raw call under "Raw call". Failed calls still show the error.
- **Approval cards show the pending change.** For Cairn's own tools the card previews the diff or field changes about to happen rather than truncated JSON.
- Task and note updates now report which fields changed (old and new value), and `update_user_writing_style` no longer returns your whole style guide in its reply.
