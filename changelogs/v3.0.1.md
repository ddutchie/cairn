## What's new in Cairn 3.0.1

Patch release focused on correctness and polish on top of 3.0's unified Cordis runtime. No migration required.

### Fixed

- **Usage: cached 311% → clamped.** `extractCacheTokens` deduped equal cache fields before summing (provider duplicates `cached_tokens` across `prompt_tokens_details` + top-level); `Usage` view + `ContextRing` now `Math.min(pct,1)` (`electron/lib/usage-recorder.ts:192`, `UsageView.tsx:181`, `ContextRing.tsx:337`).
- **Context ring: conversation 0 on small prompts.** Vendored harness `token-meter` estimator (`CHARS_PER_TOKEN=4` + `BLOCK/ROLE_OVERHEAD=4`) into `dsh-context-ring` and kept `rawConversation = conversationChars/4` as floor (`dsh-context-ring#f20fb4b`, `src/projection.ts:162`). Short chats no longer collapse to `0`.
- **Token throughput live.** `shared/session-stats.ts` (client-safe, no `node:module`) + `useSessionConversation.ts:137` fallback fold at `turn/end` so `TTFT · tok/s · out tokens` appears immediately on streaming, not only after `loadSessionMessages` reload (`electron/cordis/session-replay.ts:361`).
- **Workspace context now includes IDs.** `cairn:workspace` snapshot injects `Workspace: name (id)` / `Project: name (id) — desc` via `workspaceId`/`projectId` (`plugins/workspace-context.ts:10`, `chat-session-runner.ts:223`, `run-cordis-coding.ts:194`); agents can call `get_project_context_pack` without a discovery round-trip.
- **Coding throughput live wiring.** Same `f9174d3e` fix noted above; `session-stats.test.ts` now passes for `block-start` (completions) and `text-delta` (streaming) first-token anchors.

### Changed

- **Rail polish.** Project card title now above `open`+radar (less cramped), shorter (`p-2`/`mt-1.5`/`size 52` in `DockSidebar.tsx:160`), overview radar left padding `pl-6`/`pl-2` (`radar.tsx:42`), header search pill shows `Ctrl+K` on Win/Linux (`UnifiedRail.tsx:148`, `CalmShell.tsx:43`).
- **Adopted harness commands.** Added `@deepseek-ai/dsh-command-compact` (`cordis-context.ts` mounts `dsh:command-compact` after `commands`, eager `apiMode`-pinned `ensureAgentAiAdapter` in `session-agent.ts`; removed hand-rolled `cairn-commands.ts:92` `/compact` — `compactChatSession` kept for `chat:compactThread`).
- **Adopted harness pruner.** Added `@deepseek-ai/dsh-compaction-tool-result-pruner` (`cordis-context.ts` after `token-meter`, `prune-hook.ts` + `session-turn.ts` idle/pre-compaction hook, `prune-replay.test.ts`).
- **Adopted session title.** Added `@deepseek-ai/dsh-session-title` + `first-prompt-llm` (`cordis-context.ts` composes after `session-projection`, inherits chat route), `plugins/session-title.ts` bridge `foldSessionTitle→session:projection:title`, `session-replay.ts:358` + `chat-session.ts:35` + `session-projection.ts` + `chat.ts:projectedTitles` → `AIChatTab.tsx:148` auto-title, `renameTitle` pins `user`.
- **Crash durability.** `plugins/session-durability.ts` flushes `ctx.sessions.flush` on `tools/execute` top-level (`parent===undefined`) and at turn end (`session-turn.ts:51`, `chat-session-runner.ts:386`) — closes the `200ms` write-behind window for retained agents.
- **Vendored `dsh-context-ring# f20fb4b`** (`package.json:133`) so harness and Cairn share the same `CHARS_PER_TOKEN` heuristic; `file:../dsh-context-ring` used for local dev, pinned to `f20fb4b` for CI.
