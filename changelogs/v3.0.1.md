## What's new in v3.0.1 — Polish

Small polish on top of 3.0 — no new features, just the review nits we deferred from the 3.0 branch so the major could ship clean.

### Lint is 0/0

- **`useTilt` no longer thrashes.** `active` no longer invalidates `onMove` every hover; `rAF` is cancelled on unmount and `clientX`/`clientY` are captured before the frame (fixes React pool). `will-change: transform` is now conditional (`active ? 'transform' : undefined`) instead of permanent on 5 cards.
- **`search-panel` debounce is stable.** `notes`/`projects` are read via `notesRef`/`projectsRef` so `e.search` no longer restarts on every note mutation; `semanticScores` reset and the empty-query guard are `queueMicrotask`-guarded.
- **`ProjectOverview` memo is honest.** `notes`/`columns`/`allCards`/`today`/`dueCards`/counts are `useMemo` on `metrics`; `overdue`/`today`/`upcoming` + `attentionQueue` are memoised on `dueCards`/`today`; `focusCounts` and `bottleneck` are `useMemo` so `Focus` bar and horizon bars don't re-render on `focus` toggle alone.

### Shell and a11y

- **Dock + CalmRail are keyboard-readable.** Collapsed dock Health now `aria-label="Project health"`; all 13 collapsed icon buttons expose `aria-label` (Search/Chat/Overview/Notes/Board/Flow/Agent/Automations/Calendar/Graph/Insights/Usage/Settings/Expand) and hidden branches are `inert` + `aria-hidden` so they don't stay tabbable behind `opacity-0`. `CalmRail` NAV uses `aria-current="page"` + `aria-label`.
- **Focus bar is a `group`, not a `toolbar`.** `role="toolbar"` requires roving tabindex + arrow keys; the bar is now `role="group" aria-label="Focus filters"` with the existing `aria-pressed` pills.
- **Search is a dialog.** Outer `fixed` now `role="dialog" aria-modal="true" aria-label="Search notes and tasks"`; input is `aria-label="Search notes and tasks"`; Type/Project filter rows are `role="group"` with `aria-pressed` on chips.
- **Settings is a tablist.** 8 parents and the 3 sub-tablists (AI/Extensions/System) are `role="tablist"` with `role="tab" aria-selected` + `aria-controls="settings-panel"` / `tabpanel`.
- **Radar respects `fontScale`.** Labels are `10*fontScale` / `8*fontScale` via `useFontScale()` and the chart is `w-full max-w-[280px] aspect-square` (was fixed 280, overflow at 320px).
- **Dock transition is `width,transform,opacity`** (was `all`), duplicate `rounded-md` removed.

### Security (follow-up)

- **`plugin-installer` local `src` containment.** `id` rejects `"."`/`".."`, `destDir` sep-aware contained, `src` must be directory and not `/` or `$HOME` and is `verbatimSymlinks:false`.
- **`codebase-index` lstat.** `walkDir` + `reindexFile` use `lstat` and skip `isSymbolicLink()` + `resolveWithinRoot` (was `stat`, followed `src -> /etc`).
- **`protocol:asset` cache.** `fileCache` is module-scope and `clear()` on `setAssetWorkspacePath` (was closure, never cleared → cross-workspace leak); `realpathSync` + `resolveWithinRoot` on final `filePath`; FIFO eviction at 500.
- **`uploadAsset` allowlist.** `ext` allowlist (`.png/.jpg/.jpeg/.gif/.webp/.svg/.avif/.pdf`), 10 MB cap, `baseName` sanitized `[^A-Za-z0-9._-]` → `"image"`, `attachmentFolderPath` via `resolveWithinRoot`.

### Tests

- `tests/fixtures/ipc-mock` now mirrors `screenshot-fixture` session (`onEvent`/`onProjection`/`runningIds`/`isRunning` shape) so `useSessionConversation` no longer throws `onEvent is not a function`; `test:e2e` 19/19 (was 6 failed), `test:e2e` smoke 17/17.
