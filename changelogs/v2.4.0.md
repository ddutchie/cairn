## What's new

This release introduces the **Cairn mobile companion app** and the desktop-side **Device Sync** that connects the two. The mobile app is an offline-first iOS/Android client (Expo) you build yourself today, with the App Store as a possible future path.

### Features

- **Cairn mobile companion app**: A new offline-first mobile client for your workspace — notes, tasks, a drag-and-drop board, folders, tags, and an AI chat/assistant. Markdown rendering has parity with the desktop (syntax highlighting, task-list checkboxes, callouts, KaTeX math, and Mermaid diagrams). Everything works offline; changes reconcile with the desktop when connected.
- **Device Sync (desktop)**: New **Settings → Device Sync** panel to connect a shared cloud folder (iCloud Drive, Dropbox, or Syncthing) that your phone also points at. Sync is offline-first and file-safe — only append-only oplog files ever transit the folder, never your database. On first connect, your entire existing workspace is seeded to the folder; after that only changes are exchanged, in the background.
- **Conflict-safe reconciliation**: Concurrent edits to the same note on two devices are resolved with last-writer-wins plus a preserved **"conflicted copy"** note, so an edit is never silently lost. Note edits arriving from the phone are re-projected to their `.md` files on disk, keeping the desktop's dual-write parity.
- **Pluggable mobile AI backend**: Mobile chat runs through a provider abstraction — a built-in endpoint for first-party builds, or any **OpenAI-compatible** endpoint (OpenAI, Azure OpenAI, OpenRouter, Together, Groq, LM Studio, Ollama, …) that you configure in-app with a base URL, model (with a "fetch models" picker), and an API key stored in the device keychain.

### Changes

- **Shared "one brain" core**: Note formatting, markdown transforms, folder-tree building, the syntax palette, and the offline-first sync engine were hoisted into a shared, framework-agnostic package used by both desktop and mobile — so the two apps stay behaviourally identical from a single source of truth.
- **Device Sync stays idle until enabled**: The desktop only builds and drains its sync oplog while a sync folder is connected. If you never enable Device Sync, no oplog is accumulated — there's zero overhead for desktop-only users.

### Requirements & notes

- **Device Sync requires the mobile app.** It exchanges changes with your phone, not with another desktop — the Settings panel now states this explicitly. The mobile app is currently a build-it-yourself companion (see the mobile README); there's nothing to sync with until it's installed on your device.
