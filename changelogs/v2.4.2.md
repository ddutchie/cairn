## What's new

A small fix release for the note "Spawn tasks" action.

### Fixes

- **Chat input no longer gets stuck after "Spawn tasks"**: Using the **Spawn tasks** button on a note could leave the AI chat input disabled, so you couldn't type until you reloaded. The note's task-spawning ran on the same streaming channel as the chat panel, and the panel mistook the spawn's completion for its own — leaving it in a permanent "loading" state. Streaming events are now tagged with the thread they belong to, so the chat panel ignores background spawn activity and its input stays usable throughout.
