## What's new

A small fix release covering the note "Spawn tasks" action and Project Overview polish.

### Fixes

- **Chat input no longer gets stuck after "Spawn tasks"**: Using the **Spawn tasks** button on a note could leave the AI chat input disabled, so you couldn't type until you reloaded. The note's task-spawning ran on the same streaming channel as the chat panel, and the panel mistook the spawn's completion for its own — leaving it in a permanent "loading" state. Streaming events are now tagged with the thread they belong to, so the chat panel ignores background spawn activity and its input stays usable throughout.
- **"Due today" tasks no longer show as "0d overdue"**: On the Project Overview, a task due today was labelled **0d overdue** instead of **Today**, and it was also counted in the Overdue stat. Overview now uses the same timezone-safe date logic as the board, so due-today tasks read **Today** and the Overdue count excludes them.
- **Overview scrolls clear of the bottom bar**: The Project Overview's pinned chat bar (shown when the chat sidebar is closed) could hide the last of the content, which couldn't be scrolled into view. The page now reserves space matching the bar's actual height — growing as the input expands — so everything scrolls fully above it.
