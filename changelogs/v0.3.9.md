# v0.3.9 — Live Dashboards

## New Features

### AI-Generated Live Dashboards
- **Create dashboards** via the AI chat or MCP server using `create_dashboard` — produces a fully rendered, interactive HTML page inside Cairn's Notes panel
- **Live data bridge** — dashboards use `window.cairn.query(tool, args)` to fetch real-time project data (tasks, notes, summaries) directly from the local database; no static snapshots
- **Sandboxed iframe** — dashboards render in a `sandbox="allow-scripts"` iframe via `srcdoc`; no external network access, no same-origin escalation
- **Reload button** — refresh the dashboard at any time from the panel header
- **`update_dashboard`** — update an existing dashboard's HTML via AI chat or MCP
- Available query tools inside dashboards: `get_cairn_context`, `get_project_summary`, `list_tasks`, `list_notes`, `list_recent_activity`, `search_tasks`, `search_notes`

### Dashboard UI
- "New Dashboard" button in the Notes sidebar (grid icon)
- Dashboard notes shown with a grid icon in the notes list to distinguish from regular markdown notes
- Empty-state prompt guiding users to ask the AI to generate dashboard content

### Chat & MCP Awareness
- System prompt updated to explain the dashboard capability and `window.cairn.query()` API
- `get_cairn_context` (chat + MCP) updated with `create_dashboard` / `update_dashboard` in the write tools list and a `dashboards` conventions entry
- `create_dashboard` and `update_dashboard` added to the chat tool definitions and executor

## Database
- `notes.type` column (`TEXT NOT NULL DEFAULT 'note'`) — values: `note` | `dashboard`
- Automatic `ALTER TABLE` migration applied on startup for existing databases
