# v0.3.9 — Live Dashboards

## New Features

### AI-Generated Live Dashboards
- **Create dashboards** via the AI chat or MCP server using `create_dashboard` — produces a fully rendered, interactive HTML page inside Cairn's Notes panel
- **Live data bridge** — dashboards fetch real-time project data on every load via a sandboxed `window.cairn` API; no static snapshots
- **Sandboxed iframe** — dashboards render in a `sandbox="allow-scripts"` iframe via `srcdoc`; no external network access, no same-origin escalation
- **Auto-refresh** — dashboards automatically reload when the database changes (MCP writes, task moves, etc.) with a brief "⚡ live" indicator
- **Error overlay** — JS errors, unhandled promise rejections, and `console.error` calls from dashboard code are surfaced in a visible error bar above the iframe with file/line info
- **Reload button** — manually refresh the dashboard at any time from the panel header
- **`update_dashboard`** — update an existing dashboard's title or HTML via AI chat or MCP

### Dashboard API (`window.cairn`)
Typed helpers injected into every dashboard — no hardcoded IDs needed:
- `window.cairn.projectId` / `window.cairn.workspaceId` — active context, always set
- `window.cairn.getProjectSummary(projectId?)` — columns, task counts, tasks
- `window.cairn.listTasks(projectId?)` — all tasks grouped by column
- `window.cairn.listNotes(projectId?)` — note list with metadata
- `window.cairn.listRecentActivity(opts?)` — recent notes and tasks
- `window.cairn.searchTasks(query, projectId?)` / `window.cairn.searchNotes(query, projectId?)`
- `window.cairn.getContext()` — full workspace/project structure

### Dashboard UI
- "New Dashboard" button in the Notes sidebar (grid icon)
- Dashboard notes shown with a grid icon in the notes list
- Empty-state prompt guiding users to ask the AI to generate dashboard content

### Project Overview — Health Section
- New **Health** section in the Project Overview between stat cards and the board snapshot
- **Column bar chart** — proportional horizontal bars per column, coloured to match the board, each clickable to scroll the board to that column
- **Priority breakdown** — 4-cell grid (Urgent / High / Medium / Low) showing open task counts, cells highlight with priority colour when non-zero

### Chat & MCP Awareness
- System prompt documents the full `window.cairn` helper API with exact return shapes
- `get_cairn_context` (chat + MCP) lists `create_dashboard` / `update_dashboard` in write tools and includes dashboard conventions
- `create_dashboard` and `update_dashboard` added to chat tool definitions and executor
- Settings → MCP Server tools list updated with `create_dashboard` / `update_dashboard`

## Bug Fixes
- `db:mcpQuery` IPC handler response shapes now match what dashboard JS naturally expects: `get_project_summary` returns `columns[].taskCount`, `list_tasks` returns `{ tasksByColumn }`, `list_recent_activity` returns `{ recentNotes, recentTasks }`

## Database
- `notes.type` column (`TEXT NOT NULL DEFAULT 'note'`) — values: `note` | `dashboard`
- Automatic `ALTER TABLE` migration applied on startup for existing databases
