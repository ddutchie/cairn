## What's new

Sync no longer piles up duplicate `oplog-…-2.ndjson` files on Windows.

### Fixes

- **Duplicate sync files on iCloud Drive for Windows.** On Windows, each sync would leave a fresh numbered copy of this device's oplog file (`oplog-…-2.ndjson`, `-3`, …) instead of updating the existing one in place. This was iCloud's Windows client resolving a conflict: Cairn published its oplog by writing a temporary `.tmp` sibling inside the synced folder and renaming it over the existing file, but iCloud tracks that file as a placeholder (and often holds it open), so the rename-over-existing was rejected and iCloud minted a numbered copy instead — and the transient `.tmp` got synced too. Cairn now stages the temporary file in the OS temp directory (outside the synced folder, so iCloud never races or uploads it) on first creation, and overwrites the existing oplog file *in place* on every subsequent write, so iCloud sees an ordinary edit of the file it already tracks. No more accumulating `-2`/`-3` duplicates.
