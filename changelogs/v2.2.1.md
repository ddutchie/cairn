## What's new

### Fixes

- **ContextRing token inflation with thinking models**: The chat tool loop accumulated `prompt_tokens` across all rounds (`+=`), so a 3-round tool call would show ~3× the actual context usage. With Gemini 3.x's stateful thinking, previous reasoning tokens are also included in each round's prompt, compounding the inflation. `promptTokens` now uses assignment (`=`) instead of accumulation — the last round's value is the true current context size. Completion and reasoning tokens still accumulate correctly.
