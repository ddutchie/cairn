## What's new

### Features

- **Semantic Codebase Indexing & Query Tools**: Introduced an AST-free, regex-based semantic indexer to map files, symbol definitions (classes, functions, interfaces), and call graph relations. Connected this search engine natively to the integrated MCP server to enable deep codebase context query capabilities for external AI agents.
  - **Incremental Indexer**: Recursively scans workspaces, comparing MD5 hashes to perform incremental indexing. Supports Python (classes, functions, methods), Go (structs, interfaces, methods, functions), Rust (structs, enums, traits, functions), C++ (classes, structs, functions, and methods), Java & C# (classes, interfaces, structs, records, and methods), Ruby (classes, modules, and methods), and Shell scripts (functions) parser matching.
  - **MCP & Coding Tools integration**: Bound 5 new tools (`codebase_reindex`, `codebase_search_symbols`, `codebase_get_symbol_definition`, `codebase_get_references`, and `codebase_get_file_symbols`) into the main process chat executor and the standalone MCP server, enabling local directory indexing by path query.
- **Dynamic Plan/Execute Mode Toggle**: Allows users to toggle active Coding Agent (`pi`) sessions dynamically between **Plan** and **Execute** mode directly in the UI.
  - Plan mode runs with a lowered LLM temperature for deterministic outline generation, preventing accidental file writes.
  - Added an interactive Badge/Button in the agent panel header to let users toggle the mode in real time.
- **Interactive Tool Execution Confirmations**: Implemented a security gate that forces the Coding Agent to pause before running modifying/write tools when automatic approvals are turned off.
  - Added an `autoApprove` setting in the store, settings interface, and config caches.
  - Supports mobile-desktop cached settings sync, where mobile sessions correctly inherit the cached `autoApprove` setting set on the desktop.
  - Renders inline **Confirm** / **Deny** buttons directly within the tool chips inside the message history for pending tool calls.

### Fixes

- **Store Hydration Fallback**: Added `autoApprove` to migrated configurations and fallback values in `src/store/index.ts` to prevent missing property errors during hydration.
- **Tool Parity Parity Checks**: Added the new codebase tools to the documented list in `tool-parity.test.ts` to pass strict MCP/chat cross-executor parity validations.
- **Linter Warnings**: Resolved unused parameter warnings in the main process agent session listener signatures.

### Changes

- Upgraded version target to `v2.0.0` with enhanced agentic features.
- Unit and integration tests added in `electron/lib/codebase-index.test.ts` validating AST-free recursive regex scanner, caching, and reference mapping.
