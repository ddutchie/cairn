## What's new in Cairn 3.2.3

### Fixed

#### Chat

- Locally configured MCP servers (for example a stdio server that isn't in the community registry) now get the same connector card as registry connectors, with a generic MCP icon, instead of raw JSON. Registry branding still applies when there is a match, and cards no longer depend on the registry having loaded.
- **Tool cards stay collapsed, with a button to open what they touched.** A call that created or changed a note or task no longer opens itself; a small button beside the chip opens that note or task directly. Click the chip itself for the change view.
- **Searches say what they found.** "Searched notes for “a phrase”" is gone: a finished search reads "Found 3 notes for “login”" or "No notes matched “login”", and folder, tag and filter listings say what they listed.
- Coding sessions show an "Asked 2 questions" chip for the agent's questions instead of a generic tool name.
- **"Send now" no longer loses the running turn's tool calls.** Sending a queued message while the assistant was working stopped the turn and discarded its tool calls and partial reply before they were saved. They are now kept in the transcript, and the stopped turn no longer leaves an empty message behind.
- Connector and tool results open one level deeper by default, so a nested list such as a day's meetings shows its items without extra clicks.

### Changed

#### Sync

- **Get your devices ready for People.** This version adds the storage for an upcoming People feature (people, meetings and who attended them) and raises the sync version. Nothing changes on screen yet. Devices still on an older version of Cairn now show the "needs updating" hint, so update them before People arrives.
