## What's new

### Features
- **Heartbeat automations (foundation).** Cairn now ships the scheduling engine for background agent tasks: a main-process heartbeat scheduler that polls a durable `automations` table and fires due runs while the app is open. Includes cron / "every N unit" / "once" schedules with timezone-aware next-run calculation, run-once catch-up on launch, skip-on-overlap (a slow run never stacks), and per-run history in a new `automation_runs` table. Runs execute through the data-only knowledge-work agent (no bash / file edits), and completion is surfaced through the existing in-app notifications.
- **Automations view.** A dedicated Automations section (sidebar) lets you create, edit, run now, enable/disable, and delete scheduled automations — instructions, schedule, project scope, timezone, and an optional run cap.
- **Durable approval inbox (foundation).** A persisted human-attention queue that will back approve/deny for background runs — resolve-once, idempotent per run+tool+args, fail-closed expiry sweep. UI + runner integration land in a follow-up.
