## What's new

### Features
- **Heartbeat automations (foundation).** Cairn now ships the scheduling engine for background agent tasks: a main-process heartbeat scheduler that polls a durable `automations` table and fires due runs while the app is open. Includes cron / "every N unit" / "once" schedules with timezone-aware next-run calculation, run-once catch-up on launch, skip-on-overlap (a slow run never stacks), and per-run history in a new `automation_runs` table. Runs execute through the data-only knowledge-work agent (no bash / file edits), and completion is surfaced through the existing in-app notifications. The automation authoring UI and community sharing land in follow-ups.
