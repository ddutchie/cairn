## What's new

### Fixed

- **Projects buttons no longer pile onto the tab rail on short displays.** On the folded Duo (and landscape iPhones) the sidebar's Capture / Sync / Appearance buttons docked into the same side rail as the tab bar with no shared compression, cramming seven items in and breaking the tab highlight. The sidebar column now keeps a horizontal bar there — only the open note/task (detail column) docks into the rail, as Apple intends. Backed by a new local `duo-bars` native module exposing the Duo vertical-bar APIs (`toolbarVerticalBehavior`, `toolbarVerticalCompressionBehavior`) that Expo doesn't ship yet.

- **The Chat model name no longer spills over the header.** Long model ids overflowed the centred title slot and painted over the context ring, looking off-centre. The title now caps to the space between the header items and truncates with an ellipsis.

- **Quick Capture's buttons stay reachable while typing.** The input footer (dictate, Paste, Save as note, File it) and the proposal footer (Back, Confirm) sat at the window bottom behind the keyboard. They now ride above it, like the note editor's toolbar.
