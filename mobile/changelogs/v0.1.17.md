## What's new

### Fixed

- **Search works with the new bottom search tab on iOS 27.** The search field now takes the keyboard when you open the tab, and the header no longer disappears. The All / Notes / Tasks control now sits in the header, next to the semantic and info buttons, instead of under the search field.

### Changed

- **Removed the unused native search-scope module.** Search no longer needs custom native code.
