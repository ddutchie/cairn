## What's new

### Added

- **Workspace and Project widgets for the iOS Home Screen.** The Workspace widget shows your overall progress, the day's overdue and due-today tasks, and your project and note counts. The Project widget shows one project's progress with its start and target dates; long-press it and choose **Edit Widget** to pick the project, and add it more than once to keep several projects in view. Both match the Overview's progress card, follow light and dark mode and your accent colour, refresh when the app opens, syncs or goes to the background, and open the workspace or the project when tapped. Small, medium and large sizes are supported.

- **A Quick capture widget and app-icon shortcuts.** The Quick capture widget (Home Screen, or a circular Lock Screen widget) opens the capture sheet in one tap. Long-pressing the Cairn icon now offers **Quick capture** and **Search**.

- **A working indicator that follows what the assistant is doing.** While a reply is in flight the chat shows an animated loader below the message: one for waiting on the model, one for thinking, one for writing the answer and one while a tool runs. The tool chips use the same loader.

- **Chat replies render on the native text engine.** Tables scroll sideways instead of squashing, code blocks are syntax-highlighted natively, math draws without a web view, and long replies stream more smoothly. Wikilinks, callouts, synced images, Mermaid diagrams and colour literals (`#ff0000`) keep working.

### Fixed

- **The back button after following a link from chat now says "Back"** instead of "(tabs)".

- **Chat retries a flaky connection.** A busy provider, a rate limit or a dropped connection no longer ends the reply straight away: before anything has streamed, chat now retries a few times with a short wait, as desktop does, and only then shows the connection message. Bad keys, quota and billing errors still fail immediately.

- **Switching apps mid-reply no longer loses the answer.** If iOS cuts the connection while Cairn is in the background, chat quietly restarts the reply when you come back (only when no tool had started, so nothing runs twice). Otherwise the text that had already streamed is kept, with the error note underneath.

### Removed

- **The built-in Rork AI endpoint is gone.** Rork is retiring it, so chat and the note AI actions now use Apple Intelligence (where the device supports it) or your own OpenAI-compatible endpoint and key under Settings → AI. If you were on the built-in endpoint you'll land on the OpenAI-compatible setup: add a base URL and key to keep chatting.
