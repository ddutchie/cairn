## What's new

### Changed

- **The Chat header now shows the provider name with the model beneath it.** The title is the active provider (e.g. "OpenAI") with the model id in smaller text below and the same menu chevron.

- **Clearer Projects header icons.** Quick capture is now a compose glyph instead of the inbox tray (which read as "download"), and Appearance is a palette instead of a gear (which read as general Settings). Applies to both the standalone header and the split-view sidebar.

- **Sync moved into the workspace menu, shown as a ring around the Cairn icon.** The Projects header's separate sync button is gone. The logo now has a sync ring: a spinning arc while syncing, an amber ring with pending changes, grey when offline, and a faint ring when everything is synced. Its menu lists your workspaces plus a "Sync · Synced / N pending / Syncing… / Offline" row that opens sync details. This frees a slot on the right (the folded Duo rail drops from three buttons to two). Applies to the standalone header and the split-view sidebar.

- **Pull down to sync in the split-view Projects sidebar.** Dragging the project list down now forces a sync and refreshes progress and workspaces, like the other panels.

### Fixed

- **The project view switcher no longer jumps when you change views.** Overview | Notes | Board | Calendar was redrawn inside each view's own column, so every switch destroyed and recreated the native segmented control. It now lives once in a persistent project column and only the content below swaps, so the selection slides natively.

- **The Chat model picker is centred on iPhone 17 again.** A long model id made the header push the picker flush-left. The title now reserves equal space on both sides of the screen centre, so it stays centred and truncates instead of shifting.

- **iPhones are locked to portrait again.** Orientation had been unlocked (v0.1.12) for the iPhone Duo's foldable poses, which also let regular iPhones rotate into landscape. The portrait lock is back; the Duo's inner screen still rotates on its own, so nothing is lost there.
