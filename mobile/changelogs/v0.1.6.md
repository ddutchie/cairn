## Fixes

- **A "device needs updating" hint when a paired device is on an older sync version.** Device Sync records each device's sync-protocol version, so if one of your devices reports a lower version — one that may not honour deletions correctly — the Sync screen tells you. Until it's updated, a note you delete can reappear from it. Devices on the same version see nothing new.
- **A note deleted on another device is no longer offered for restore twice.** When another device deleted a note you had edited offline, the Sync screen used to show both a "deleted on another device" restore prompt and a sync conflict for the same note — and restoring left two identical copies. Your edit is already kept as a conflict copy, so Cairn now sends you to the Conflicts screen to resolve it instead of offering a redundant restore. Notes deleted with no competing edit still offer Restore as before.
- **Reasoning ("thinking") models no longer stall out.** Chat replies are no longer capped at a fixed token budget, so a reasoning model can think as long as it needs and still write its answer instead of stopping empty. And if a reply ever does get cut off, an empty assistant turn can no longer break your next message.
