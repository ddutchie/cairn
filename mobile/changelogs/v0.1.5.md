## Fixes

- **Deleted notes stay deleted after a stale device reconnects.** Mobile sync now keeps delete metadata in its own table (a new schema migration, applied automatically on first launch) and requires exact proof that a device observed a deletion before it may bring the note back. A device with a faster clock can no longer resurrect content you deleted elsewhere, and an edit that loses this race is kept as a conflict copy instead of being dropped. Update your other devices too — the protection only applies on devices running this version or newer.
- **Malformed sync entries are skipped instead of applied.** Incoming oplog entries are now structurally validated before reaching the sync engine, so a truncated or corrupt line in a cloud-synced file can no longer be applied as if it were a real change.

## Improvements

- **Branded connector messages.** Mobile chat now renders installed MCP servers and HTTP services as branded cards with registry logos, connector labels, and bounded tool results.
- Use the canonical MCP connector mark for mobile fallback logos.
- Connector tool cards are now collapsed by default and expandable to show the called tool and result.
- Connector tool details now hide internal connector IDs and pretty-print structured results.
- Expanded connector results now show up to three discovered links with a Show more control.
- Redact sensitive connector arguments before they enter persisted mobile chat history.
