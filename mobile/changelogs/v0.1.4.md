## What's new

A guided first-run setup that walks you through connecting your phone to your desktop.

### New

- **Guided sync setup on first launch**: The first time you open Cairn (before any workspace is connected), you now get a step-by-step guide instead of a bare "connect a workspace" screen. It makes the non-obvious ordering clear: opening the app is what *creates* the shared iCloud folder (`iCloud Drive › Cairn › sync`) — which the guide confirms live — then tells you exactly where to go on your computer (**Settings › Device Sync › Choose folder…**) and to point it at that same folder. The guide then watches iCloud on its own and, the moment your desktop publishes a workspace, shows a **Connect** button you tap to open it — no manual refreshing needed. It also detects when iCloud isn't signed in and tells you how to fix it. This replaces the old static four-step list (which listed the steps in the wrong order and gave no live feedback about whether anything was working).
- **Archive or delete a task by dragging it**: Long-press a card on the board to lift it and an **Archive** and **Delete** drop zone slide up at the bottom — drag the card onto one to archive it or delete it, mirroring the desktop board. The zones light up as you hover them (and the card outline turns amber for archive / red for delete); Delete asks for confirmation first (and the removal syncs to your other devices). You can also **delete a task from its detail screen's ⋯ menu**, alongside Archive. This is the first way to *delete* a task on mobile — previously you could only archive one.
- **Liquid Glass app icon on iOS**: Cairn now ships an Icon Composer app icon, so on iOS 26 the Home Screen icon picks up the system's Liquid Glass treatment — including automatic light, dark, tinted, and clear appearances — instead of a flat image.
- **Detailed context-usage breakdown**: Tapping the context ring in the chat header now opens a native popover with a colour-segmented bar and a clean two-column breakdown of where your prompt tokens are going — system prompt, tool definitions, connected MCP servers & services, conversation, and tool outputs, with each count right-aligned and tinted to its category colour — plus an output section (answer / thinking tokens) once a turn completes. Previously the ring only showed the overall percentage and total tokens; this brings mobile to parity with desktop and makes it clear how much of your context window connected MCP tools are consuming. (On other platforms it falls back to a summary dialog.)
- **See what a message costs**: When your provider reports the USD cost of a call in its usage (`usage.cost` — Neuralwatt's energy accounting does), the context ring now shows a **Cost** row alongside the token breakdown, so you know what each turn cost. Remaining-credit badges also extend beyond OpenRouter: community providers can advertise a dedicated balance endpoint, and Neuralwatt's `GET /v1/quota` now feeds the balance shown in AI settings (with the same live endpoint check shared with desktop's catalog).
- **Pick your accent color**: A new Appearance screen — opened from the gear button to the right of Sync on the Projects tab — lets you choose from ten curated accent colors: Sage Moss (the new default), Cairn Teal, Terracotta, Amber Gold, Obsidian Indigo, Slate Blue, Rust Coral, Deep Plum, Pine Green, and Copper Bronze. Each is tuned for both light and dark, applies instantly everywhere, and is remembered across launches. The default accent is now Sage Moss instead of the old indigo.
- **Browse community AI providers**: A new **Browse Providers** screen (from **Settings → AI**) lets you install ready-made OpenAI-compatible providers — OpenAI, Anthropic, Gemini, DeepSeek, Groq, Together, Fireworks, OpenRouter, Pollinations, and more — from the cairn-community catalog with one tap. No more hunting for the right base URL: each preset ships its endpoint (and a "Get a key" link), so you just paste your API key, which is stored securely in the device keychain (never synced). Added providers join your saved-providers list (the same one AI settings manages) but aren't auto-selected — pick one there to use it. The catalog is fetched from a separate `providers.json` manifest, cached on-device so it works offline, and refreshable; re-installing a preset updates the existing entry instead of duplicating it, and shows an **Update** button when a provider's endpoint or default model changes upstream.

### Fixes

- **Semantic search now indexes every note (one bad note no longer stalls the rest)**: The on-device index could get stuck reporting something like "209 of 212 items indexed" and never finish. A single note whose text the embedder couldn't process threw an error that aborted the *entire* indexing pass — so that note **and every note after it** were left unindexed. Each note (and task) is now indexed in isolation: if one can't be embedded it's skipped and the rest carry on, so the index reaches completion. Empty notes (no body text) are also no longer counted in the total, since there's nothing to embed.
- **See why an item isn't indexed**: The "items indexed" readout on the Search tab (and the Sync screen's index card) now has an info button when something isn't fully indexed. Tap it for a plain explanation and the list of notes involved — whether they're empty (nothing to index) or have content that couldn't be embedded (usually a body of only symbols, links, or an image), with guidance to add some text and reindex.
- **Task-list checkboxes render inside table cells**: A checklist crammed into a table cell — `- [ ] install - [x] configure`, or a multi-line cell using `<br>` — used to show the raw `[ ]` / `[x]` text. Cells now render each token as a checkbox (tappable in a note to toggle the source, static in PDF export), with in-cell line breaks preserved, matching desktop.
- **Knowledge graph auto-fits on open**: The force-directed graph now automatically zooms to frame the whole graph once its layout settles — after the nodes have spread out from the centre — so you land on a fitted view instead of an overlapping clump. If you start panning or zooming before then, the auto-fit backs off.
- **Knowledge graph stays legible under any accent**: Project nodes now use a fixed violet instead of the accent colour, so they no longer blend into the green Card nodes when a green accent (Sage, Pine, Teal) is selected. Semantic-connection edges likewise switched to a neutral dashed line, keeping the node types and edges cleanly distinguishable regardless of your accent.
- **Calendar text no longer clips at large text sizes**: With the iOS Text Size (Dynamic Type) setting turned all the way up, the task chips in day cells and the Unscheduled tray — plus the day numbers, weekday header, and "+N more" labels — had their text cropped, because the calendar's tight grid used a fixed line height that didn't grow with the font. Those elements now scale cleanly (bounded so they still fit their fixed-size grid cells), so the whole calendar stays legible at any device text size.
