## What's new

### Added

- **Choose a font for your note text.** Pick between Sans (the default), Serif, or Mono for note content — the editor, the preview, and PDF exports all use the chosen font. UI chrome stays on the system font. Set it in Settings → Appearance ("Note font"). System font stacks are used throughout so exports render identically on every platform.
- **Chat themes.** Re-skin the chat surface with full distinct looks — each theme bundles its own chat font, a background treatment (solid, gradient, or scanline pattern), a bubble style (filled, glass, or outlined), and a dark/light palette. Five built-in themes ship out of the box (Default, Paper, Terminal, Midnight, Aurora), and more arrive over time from the cairn-community catalog — no app update needed. Pick one in Settings → AI → Tuning ("Chat theme"). Accent colour and note font are independent of the chat theme.
- **Richer chat themes.** Every theme now also sets its text weight (regular/medium), letter-spacing, and line-height, a named background pattern (scanlines, dots, grid, crosshatch, diagonal, or noise), a bubble corner radius (small, medium, or pill), and a bubble shadow — so community themes can go beyond the built-ins' looks. Gradients can use any number of colour stops, and AI-bubble text colour is now always explicit. The community catalog's themes (Ocean, Glacier, Matcha, Noir, Synthwave, Twilight, Ember, Forest) are updated to the richer shape.
- **Temperature and max steps for mobile chat.** Tune how the assistant replies — sampling temperature (Auto lets the model decide, or pick 0.1–1.0) and the tool-call round budget per message (10–∞). Both apply live and carry to whatever provider you're using. Set them in Settings → AI → Tuning.
- **Attach photos, camera shots, and files to a chat.** Tap `+` in the chat composer. The button opens a menu with Camera, Photos, and Files, and the menu expands into a full-screen photo grid or a live camera. Pick a photo and it flies into the composer, where you can remove it before you send. The camera supports front/back and flash.
- **Stacked toasts.** Several notifications now stack instead of replacing each other, with up to three visible at a time. Drag a toast down to dismiss it, or leave it and it clears itself.

### Changed

- **AI settings are now three tabs.** The screen is reorganized into Setup (provider + model — what runs your chat, saved on Done), Tuning (temperature, max steps, personality, tools, chat theme — applies live), and Usage (token/cost tracker inline). The native segmented control keeps the layout tidy on both platforms.
- **The chat theme moved** from Settings → Appearance to Settings → AI → Tuning, so it lives with the rest of the chat surface settings. Appearance now holds accent colour + note font.
- **The assistant now remembers its reasoning across turns.** Multi-turn conversations and agent tasks round-trip the model's chain-of-thought between requests — reasoning items on the Responses API, and the `reasoning_content` field on DeepSeek/OpenRouter-style Chat Completions — so follow-ups continue from the prior thinking instead of starting over. Longer conversations and multi-step requests stay more consistent as a result.

### Fixed

- **Deleting a checklist note on one device no longer resurrects it as a conflict on the other.** While the desktop was closed, deleting a note with many `- [ ]` checkboxes on mobile would read the desktop’s stale snapshot and keep it as a live “conflicted copy”, so the delete appeared to fail. The engine now only preserves a divergent body when the losing `put` is *newer* (higher HLC) than the winning `delete`; an older snapshot is discarded and both devices converge to deleted. Bodies are also compared after `CRLF → LF` + `trimEnd` so a `gray-matter` trailing newline no longer looks like a divergent edit.
- **Pattern backgrounds now render on mobile.** The scanline/pattern chat themes (Terminal, Ember, Matcha) previously fell back to a flat colour on iOS/Android — the pattern overlay is now drawn with the same named patterns as the desktop.
- **The chat agent no longer stops after its first tool call on the Responses API.** A turn that ended on a function call was reported as "finished", so the model's follow-up reasoning over the tool result never ran. It now continues the loop, and falls back to Chat Completions if the endpoint doesn't actually serve `/responses`.
- **Thinking blocks match desktop.** Reasoning auto-collapses the moment the answer starts streaming (instead of staying expanded for the whole turn), renders when the model returns only a condensed summary, and is ordered tools → thinking → answer like the desktop chat.
- **Copy on a chat reply copies just the answer text**, matching the desktop copy button.
- **The image-attach button respects the model on Responses providers too.** When chat runs through `/responses` with a catalog model that doesn't accept images, the attach button is hidden just as it is for the Chat Completions provider.
- **AI settings inputs no longer hide behind the keyboard.** The sheet now keeps the focused field 32 pt above the keyboard (including the inline model search and the Saved Providers / personality sheets) so Base URL, API key, and Context window stay visible while typing.
- **Fix massive Hermes memory regression.** Bumped Expo SDK `57.0.12 → 57.0.18` (React Native `0.86.2 → 0.86.3`) to pick up the Hermes V1 fix for the memory regression that shipped in RN 0.85/Hermes V1 (and through early SDK 57). Apps importing `react-native-worklets`/`reanimated` could see RAM roughly double (see [expo/expo#46519](https://github.com/expo/expo/issues/46519) / [Expo SDK 57 changelog](https://expo.dev/changelog/sdk-57#known-regressions) — `57.0.9` fixed the main leak via RN 0.86.2, `57.0.17` fixed a remaining dev-startup leak via RN 0.86.3). Also aligned all SDK 57 packages to their `57.0.18` expected versions (`expo-constants` 57.0.16, `expo-file-system` 57.0.6, `expo-router` 57.0.17, `expo-updates` 57.0.19, etc.).
