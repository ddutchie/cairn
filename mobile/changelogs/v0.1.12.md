## What's new

### Added

- **Jump-to-latest button in Chat.** When you scroll up away from the newest message, a small glass button fades in above the composer; tap it to snap back and keep following the reply. It rides the keyboard with the composer and stays hidden while you're at the bottom.

- **Switch model from the Chat header.** A new model menu next to AI settings lists your saved providers and the active provider's models (favorites first, current model checked) so you can change model without opening Settings. It appears when Chat is using an OpenAI-compatible provider and is disabled while a reply is running.

### Changed

- **Smoother streaming replies.** The reply text now streams through a lightweight store (about 30 updates a second) instead of re-rendering the whole Chat screen on every token, so long replies stay responsive. Chat bubbles also use stable keys rather than their list position.

- **Expo SDK 58 stable with React Native 0.88 final.** The app was on the SDK 58 beta-era packages (Expo 58.0.7, React Native 0.88 release candidate). It now tracks the stable release (Expo ~58.0.11, React Native 0.88.0 final) with all matching Expo packages. No app code changes were needed.

- **Wide-window tabs drop their titles into the side rail (Chat treatment everywhere).** On wide iOS windows Search, Knowledge Graph and Calendar no longer show an in-content title — like Chat already did. Their controls dock into the side rail instead: Search's index-info + semantic toggle, Graph's layout + label-density menus (the labels menu moves off the left), Calendar's Today + Month/Week (Today gains a calendar symbol so it docks into the rail when wide; narrow keeps the text label). The rail semantic toggle remounts on mode change so its tint stays correct while the search field is focused, and the Graph/Calendar bodies paint surface-white behind the transparent header so the toolbar runs to the top edge.

- **Exporting a note as PDF now previews it first.** On iOS the PDF opens in-app with Quick Look, which carries its own share and print actions. On Android it opens in an installed viewer app. The share sheet is still the fallback where preview isn't available.

### Fixed

- **No more deep import into expo-router internals.** Two screens reached past the package boundary for `useHeaderHeight`. It now comes from the public `expo-router/react-navigation` subpath.

- **Unlock orientation for iPhone Duo.** The app was locked to portrait, which fights the foldable poses (laptop/book/tent) and the inner display's free rotation. Orientation is now `default` so the window can resize/rotate across open, half-folded, and Split View states.

- **Chat composer keeps off the fold in book pose.** Half-folded with a vertical crease, the message input and send button used to straddle the fold. They now sit wholly on the far half; the transcript still scrolls full width, and with a note or task open beside the chat nothing shifts.

- **Bottom sheets avoid the fold.** The due-date, tag and wikilink pickers (and the AI settings sheets) could rest on the crease when half-folded. With a vertical crease the sheet now takes the far half; with a horizontal one (laptop pose) it stays within the flat bottom half.

- **Chat tools move to the bottom half in laptop pose.** Half-folded in portrait, the context ring, clear-chat and AI settings buttons no longer sit in the header in the upright top half. They dock into glass capsules either side of the tab bar on the flat bottom half (ring + clear on the left, settings on the right), with or without a note open above, and return to the header in every other pose.

- **Calendar uses both halves in book pose.** Half-folded in landscape, the month grid, overdue tray and toolbar sit wholly before the crease while the selected day and the Unscheduled tray sit wholly after it, instead of cells and chips straddling the fold. Other poses are unchanged.

- **Empty states stay off the crease.** The Cairn empty state (Search, Chat, Graph, Projects) now centres within the wider side of a vertical crease instead of across it.

- **One wide-layout breakpoint.** The 700pt wide/compact threshold was copied in five places (side preview, Projects split view, Projects tab, Search, and the native size-class override). It is now a single shared constant, so a window can no longer count as wide for one screen and compact for another.

- **Toolbar buttons carry a title as well as an icon.** Chat's Clear chat and AI settings, the Projects tab's Sync status and Appearance, the Projects split view's sidebar and focus toggles, Search's semantic and index-status buttons, and the Tools and Providers Done buttons were icon-only, so the system had no title to show when the iPhone Duo's side rail overflows. They now supply both (the icon still wins in the bar). The Cancel and Done buttons on the tag, due-date, note and wiki-link pickers were text-only, which kept a horizontal bar on the outer display; they now have an ✕ and a ✓ so they move into the side rail.

- **Side preview sizes from the crease, not the hinge status.** The note or task pane beside Chat, Graph and Calendar used "half the window" whenever the hinge read half-open, which is wrong in a Split View window that only touches the crease at its edge. It now starts on the actual crease when one runs through the window, and otherwise takes the larger share. Unit-tested.

- **Chat attachment panel follows the composer in book pose, and no longer runs off the screen.** With the composer on one half of a vertical crease, the attachment menu, Photos grid and Camera sheet now open from the `+` and stay on that half instead of spanning the window across the fold. The menu is also kept above the bottom edge when the keyboard is down, where it used to cut off Files.
