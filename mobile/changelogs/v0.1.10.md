## What's new

### Changed

- **Upgraded to Expo SDK 58 stable: `58.0.0-preview.7 → 58.0.7`.** React Native `0.88.0-rc.1 → rc.4`, and every Expo package aligned to its SDK 58 release (`expo-router` 58.0.17, `expo-updates` 58.0.15, `@expo/ui` 58.0.15, `expo-image` 58.0.13, …), plus `@shopify/flash-list` 2.3.2 and `@shopify/react-native-skia` 2.13.1. `expo-doctor` passes all checks.
- **Native libraries updated:** `react-native-reanimated` 4.7.1, `react-native-gesture-handler` 3.3.0, `react-native-screens` 4.29.0, `react-native-safe-area-context` 5.10.1 and `react-native-keyboard-controller` 1.22.7.

### Added

- **iPad: project buttons share the tab bar's row.** In the wide Projects layout, the focus toggle and the list's add button sit left of the floating tab bar, and the open note's or task's buttons (close, more, edit / save) sit right of it. The lists start straight under the bar instead of below an empty band.

- **iPad: projects in the sidebar, like Mail's mailboxes.** The tab bar's sidebar lists every project under a Projects section, each with its Overview, Notes, Board and Calendar. Picking one opens it from any tab, and the sidebar highlights where you are.
- **iPhone Duo and iPad: one adaptive Projects layout that morphs on fold.** A single split view (tree | view | open item) collapses to one column when folded and expands when open — unfolding with a note open keeps it open instead of restarting the layout. The collapsed column follows your depth (projects → project → item) with a native Back button; opening a note or task never yanks the view out from under you.
- **iPhone Duo and iPad: the projects tree is a real sidebar column.** Workspace switcher, sync status and settings sit in its bar (title, menu, icons); it is the projects entry in every posture, including folded. It replaces the slide-over panel and its folder button.
- **Tasks open beside the board, notes beside their list — from any view.** Opening a task or note from the Board, Calendar or Overview shows it in the right-hand column while the view stays put. With nothing open that column hosts a per-view action panel (New note / New task / View board) instead of sitting empty.
- **The project Overview fits its column.** It measures its own width: two even columns where there is room (≥600pt), one stack below — instead of sizing from the window and clipping inside narrower columns.
- **One dismiss button, never two.** Folded, the system Back is the only way out of an open note or task (the column ✕ only shows unfolded, where there is no Back). While editing a note, Cancel (drop the edits, stay on the note) replaces the ✕ in every posture.
- **iPhone Duo side rail follows Apple's order.** Close sits at the top, then the prominent Save/Done, then the rest; New note / New task and sync status are the last to fold into overflow. The note and task "⋯" menus are now the system overflow menu, and Calendar's Today and Month/Week buttons are icons so they dock into the rail.
- **New tasks compose beside the board too.** On wide layouts (and folded Duo) the board's + and a column's "New task" open the composer in the detail column instead of a modal parked on the left page. On iPhone it pushes like any open item, so Back discards it — and it survives unfolding.
- **A chat preview survives folding the Duo.** With a note or task previewed beside the chat, folding shows the preview full-window (unsaved edits intact); its ✕ returns to the conversation (straight back, no half-width slide). Folded, tapping a note or task chip opens the same preview full-screen instead of a separate page, so unfolding moves it beside the chat. The preview's buttons now join the side rail instead of standing in a second column beside it. Unfolded flat it takes the larger share like the Notes split view, and sits on the fold when half open. The note's table-of-contents button no longer floats too high in columns and previews. While a preview is open the chat's clear / AI-settings buttons step aside, so there is one set of buttons, not two.
- **The open note or task is marked in its list.** On wide layouts the note open beside the notes list is tinted, and the task open on the board is outlined on its card.
- **New notes compose beside the list.** On wide layouts the + opens the composer in the note column — a modal would park on the wrong page — with the list staying visible beside it. Save opens the note in place; close discards. On iPhone it pushes like any open item (Back discards).

- **Images in synced notes now show up.** `![[photo.png]]` embeds from the desktop appear in the note instead of a text placeholder. Images download from iCloud on demand and show a small "waiting to sync" line until they arrive.
- **Add images to a note from the phone.** A new image button in the note editor toolbar lets you pick from your photo library, take a photo, or paste an image from the clipboard. The image is shrunk to a sensible size, saved to your iCloud sync folder and embedded in the note, so it shows up on your desktop after the next sync. An image only syncs when you add it to a note. Requires iCloud. (This adds two native modules — rebuild the app.)

### Fixed

- **New note is reachable on a folded Duo.** The notes list's + had moved into the (hidden) note column's bar; it now stays on the list unless both columns are on screen.
- **No photo-access prompt at launch.** Cairn asks for your photo library the first time you open the chat's attachment panel, not as soon as the app starts.
- **The workspace switcher has its own symbol.** It used the folder icon, the same as the Projects tab and every project row.

- **Screens no longer run under side-edge system chrome.** On the iPhone Duo (and anywhere iOS reports a left/right safe-area inset), the status bar, navigation buttons and tab rail sit along the side of the screen. Tab screens now inset their content so nothing is hidden behind them.
- **The project Overview / Notes / Board switcher no longer sits on a band that stops short of the screen edge.**
- **No stray header band beside a side tab rail.** On the iPhone Duo, screen headers take the page colour instead of a surface band that stopped short of the rail.
- **Modals now clear the Duo's side rail too.** The native modals (AI settings, Sync, new note/task, pickers) and pushed detail screens take the same side safe-area padding as tab screens, so nothing hides under the tab rail on an unfolded iPhone Duo.

- **A note's title no longer appears two or three times.** Reading a note showed the title in the top bar, again as the big heading, and once more when the note's text began with a heading repeating it. The bar title is now empty while reading (it still says "Edit note" when editing), and a leading `# Title` heading that just repeats the note's title is hidden in the reader. The note's saved text is not changed, and ticking a checkbox keeps that heading.

- **iPhone Duo / iPad: closing a note or task no longer opens the sidebar.** Closing an item from a focused view used to pop the projects sidebar open over your list. It now leaves the sidebar as it was.
- **iPhone Duo / iPad: switching panels closes the open item.** Going from Overview to Notes (or Board, or Calendar) no longer carries the open note or task along, so a task can't stay selected inside the Notes panel.
