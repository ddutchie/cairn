## What's new

### Fixed

- **The Chat model menu now actually appears.** In 0.1.12 the menu never rendered: the native header toolbar only accepts its own button/menu elements as direct children, so the wrapper component was silently dropped.

### Changed

- **Model picker is now the Chat header title (iOS).** The current model name sits in the header with a chevron; tap it for a native menu of your saved providers and models (checkmark on the active ones). It shows when Chat uses an OpenAI-compatible saved provider and can't be changed while a reply is running. On Android, and on wide windows where the header title is hidden, it stays a menu in the right toolbar.

- **Favorite models get their own section in the Chat model menu.** Starred models now appear under a "Favorites" heading above the rest of the list, instead of being mixed in after the current model.

- **No more automatic "OpenAI" provider.** A fresh install no longer creates a default OpenAI provider; one is only migrated in when you already had an endpoint, model or API key saved.
