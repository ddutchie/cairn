## What's new

### Added

- **Quick capture that files itself.** A new Capture button on the Projects tab (and the `cairn://capture` link) opens a sheet where you can type or paste anything. Cairn finds where it belongs using your own notes: it picks the project, decides between a note and tasks, pulls out due dates and tags, and links related notes, then shows one confirm card you can adjust (change project, untick tasks, rename). A toast offers Undo. If AI isn't available, you're offline, or it's slow, the capture is saved as a plain note in the most likely project instead of failing. A project with no board columns gets its tasks as a checklist in the note.

- **Dictation in Chat and Capture (needs the new build).** When the message field is empty the send button becomes a mic, like WhatsApp. Tap it to start and tap again to stop, or press and hold to talk only while held, or slide left and release to cancel. Your words appear in the field as you speak, with punctuation, and stay there so you can fix anything before sending; nothing is ever sent automatically. It prefers on-device recognition (private, works offline), listens for your project and note names so they are spelled right, and shows a live ring that swells with your voice. The Capture sheet has the same mic. The first use asks for microphone and speech-recognition permission; if you decline, a toast offers to open Settings.

### Fixed

- **The Chat model menu now actually appears.** In 0.1.12 the menu never rendered: the native header toolbar only accepts its own button/menu elements as direct children, so the wrapper component was silently dropped.

### Changed

- **Model picker is now the Chat header title (iOS).** The current model name sits in the header with a chevron; tap it for a native menu of your saved providers and models (checkmark on the active ones). It shows when Chat uses an OpenAI-compatible saved provider and can't be changed while a reply is running. On Android, and on wide windows where the header title is hidden, it stays a menu in the right toolbar.

- **Favorite models get their own section in the Chat model menu.** Starred models now appear under a "Favorites" heading above the rest of the list, instead of being mixed in after the current model.

- **No more automatic "OpenAI" provider.** A fresh install no longer creates a default OpenAI provider; one is only migrated in when you already had an endpoint, model or API key saved.

- **The Knowledge Graph is now drawn natively.** The Graph tab no longer runs inside a web view: Force and Radial layouts are rendered with Skia, so pan, pinch and node dragging follow your finger at full frame rate, you get a light haptic when you grab a node, the graph can no longer go blank after the app has been in the background, and it pauses itself when you leave the tab. The search field, filters and toggles now float over the graph as Liquid Glass controls on iOS 26 (a solid surface elsewhere), so the graph fills the whole screen instead of sitting under a white header bar. Search, type filters, label density, hulls and semantic links behave as before.

- **Chat header is now glass (iOS).** The conversation and its chat theme run behind the header, which turns into Liquid Glass on iOS 26 (a system blur before that), so messages scroll under it like they already do under the composer. Fold layouts that reserve the top half for a preview keep the solid header.
