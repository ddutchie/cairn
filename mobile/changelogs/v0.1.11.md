## What's new

### Changed

- **The chat's tool trail reads like the desktop transcript.** Each chip now says what happened in plain words ("Read note Cairn Roadmap", "Moved Ship it to done") instead of the raw tool name ("Get item", "Update tasks"), and still opens the note or card on tap.

### Fixed

- **Sending a chat message with Apple Intelligence no longer crashes the app.** The 0.1.10 TestFlight build offered Private Cloud Compute without the permission it needs, and the first message crashed inside Apple's framework. Builds without that permission now fall back to the other providers instead.
- **OpenCode requests now always identify Cairn.** Loading the model list and checking credits sent the phone's generic network agent instead of Cairn's own, and skipped the OpenCode session ID. OpenCode asks clients for both and watches for unidentified traffic. Every request to your provider now sends them.
- **OpenCode models that need the Responses API now work.** OpenCode serves each model over exactly one API, so models like muse-spark, GPT and Grok failed with "Model does not support this protocol". Cairn now picks the API per model. Models that only speak Anthropic's or Google's API (Claude, Qwen, MiniMax, Gemini on OpenCode) now get a clear message asking you to pick another model.
- **Provider errors now include the provider's reason.** A failed request shows the provider's message (for example "HTTP 400: Model does not support this protocol.") instead of a bare status code.
- **Choosing the Responses API now takes the model into account.** For providers other than OpenCode, Cairn checks whether the selected model is served over the Responses API instead of only checking the URL, so a model that isn't served there no longer gets sent the wrong request.
