## What's new

Sync several workspaces from one iCloud folder and switch between them, plus Apple Intelligence chat on iOS 27.

### Multiple workspaces, one folder

- **Sync more than one workspace**: Point your Mac and PC at the same iCloud Cairn folder and each one shows up in Cairn on your phone as a separate *source* you can choose. On first launch you pick which workspace to open; you can switch to another at any time from the Sync screen.
- **Switch workspaces from the Projects header**: A workspace switcher now sits in the top-left of the Projects screen, with the active workspace's name as the header title. Tap it to jump straight to another synced workspace without opening the Sync screen.
- **Each workspace is fully separate**: Every source lives in its own local database on the phone, and Cairn only reads the sync files for the workspace you've selected. One workspace's notes and tasks can never appear in another — switching sources swaps the whole app (board, notes, chat, and the AI assistant's tools) to that workspace.
- **Pick a source to get started**: When no workspace is selected yet, Cairn scans the shared folder and lists the workspaces your desktops have published. Choose one and it syncs down; if nothing shows up, connect a desktop to the same iCloud folder and refresh.

### Apple Intelligence (iOS 27)

- **Private Cloud Compute chat, no API key**: On iOS 27 and eligible devices, Cairn's AI assistant can run on Apple Intelligence via Private Cloud Compute — a stronger, privacy-preserving server model with a larger context window and no key to configure. It uses the full Cairn tool set, so it can read and update your notes and tasks directly.
- **Constrained tool calls**: Tool arguments are generated against each tool's schema natively, so the assistant is constrained to produce valid actions rather than free-text that has to be parsed — fewer malformed calls, more reliable edits.

### Notes for the only user (you)

- On the first launch of this build, the old single-workspace phone database is removed once and Cairn shows the source picker. Everything is re-synced from your desktop, which holds the source of truth — nothing is lost as long as your desktop was synced first.

### Fixes

- **Every desktop workspace is now discovered**: Some workspaces published by a desktop weren't appearing in the source picker or the switcher because of how their id was read from the sync filename. All published workspaces now show up reliably.
